## 2. まだ測っていないもの

精度を上げるには、これが要る。次の練習で測ってほしい。

```
□ 身長
□ リーチ（両手を水平に広げた指先間）
□ 脛骨長（膝の関節裂隙から床まで）   ← 足関節のリスク計算に直結する
□ 前腕長（肘から手首）
□ 体脂肪率（推定でよい）             ← 必要カロリーの計算に要る
□ 出場予定の階級リミット
□ 平均睡眠時間（1週間の実測）
□ いまの摂取カロリー（3日間の実測）
□ ハンドボール時代の肩の故障歴       ← §5で説明する
```

### 祖先に関する情報について

「ハーフだから骨が強いかもしれない」という話があったが、
**この文書では祖先から身体特性を推定しない**。
骨密度などに集団平均レベルの差の報告はあるものの、個人差が集団差を大きく上回るため、
個人の処方には使えないからである。【C】

そして、より重要なことがある。
**低エネルギー可用性（食べていない状態）は骨の健康を損なう。**【A】
つまりあなたの骨に対する現実的なリスク因子は、祖先ではなく**小食**のほうである。
これは [15_からだを作る](15_からだを作る.md) で扱う。

一方、指導者の「軸と体幹が良さそう」という観察は非常に有用な情報なので、そちらを使う（§5）。

## 3. 階級 — いちばん大きな取りこぼし

主要なMMAの階級と、あなたの位置関係は次のようになる。

| 階級 | リミット | あなたとの差 |
|:---|:---:|:---|
| ストロー級 | 52.2 kg | −3.1 kg（減量が必要） |
| **フライ級** | **56.7 kg** | **+1.4 kg の余裕（減量はほぼ不要）** |
| バンタム級 | 61.2 kg | +5.9 kg の余裕 |

一見すると「減量が要らなくて楽」に見えるが、これは**最大の損失**である。

```
  相手（フライ級の標準的な選手）
    平常時 60〜61 kg → 計量で 56.7 kg → 試合当日は 60 kg 前後に戻す

  あなた
    平常時 55.3 kg → 計量で 55.3 kg → 試合当日も 55.3 kg

  試合当日、相手より約5kg 軽い状態で戦っている。体重の約9%にあたる。
```

クリンチ、テイクダウン、押し合いのすべてで一方的に不利になる。

### 処方は減量ではなく増量

平常時の体重は、階級リミットの5〜8%増しに収めるのが目安になる（1週間で戻せる範囲だから）。

| | 計算 | 値 |
|:---|:---|:---|
| フライ級の +5% | 56.7 × 1.05 | 59.5 kg |
| **推奨する平常時体重** | | **59〜60 kg** |
| **必要な増量** | 59.5 − 55.3 | **除脂肪で +4.2 kg** |
| そのときの減量幅 | (59.5−56.7)/59.5 | 4.7%（5%未満に収まる） |

5%未満に抑えるのは、体重の5%を超える急速減量で
コルチゾールの上昇と免疫機能の抑制が特に重篤になるためである。【A】

> **あなたがやるべきは減量ではなく、除脂肪体重を4〜5kg 増やすこと。**
> 技術習得より速く、確実にリターンが出る唯一の項目である。
> そして手段は [15_からだを作る](15_からだを作る.md) にある。要するに食べることである。

## 4. 長い手足 — 損と得は同じ式から出る

### リーチの効果は、思ったほど大きくない

正直に書いておく。

身長差1cmごとに、決着打がストレート系である確率が10%上がるという分析がある。【A】
一方、UFCの全試合（1993–2021）でリーチが有利な側の勝率は**51.65%**、つまりほぼ五分である。【B】
リーチが18cm以上不利な側の勝率は37.4%まで落ちるので、**大きな不利は効く**が、
小さな有利はほとんど効かない。

そして重要な注記がある。**軽量級では、身長が低い選手のほうがランキング上位だという報告がある。**【A】

つまり「リーチがあるから勝てる」は、あなたの階級では成立しない。
リーチは**使い方を設計してはじめて武器になる**。

使える結論はひとつだけで、**あなたの決着打はストレート系に寄る**ということである。
ジャブとストレートに投資する。フック主体のスタイルは体格の利点を捨てることになる。

### てこの式が、強みと弱みの両方を作る

[02_効く仕組み](../1_読む/02_効く仕組み.md) の式をあなたに当てはめる。

```
  トルク ＝ 力 × 回転軸からの距離

  あなたが極める側のとき
    てこの長さを決めるのは【相手の四肢長】
    → あなたの長い腕・脚が効くのは、トルクではなく「到達距離と巻きつき」

  あなたが極められる側のとき
    てこの長さを決めるのは【あなたの四肢長】
    → 脛骨が長い ＝ 同じ力でより大きなトルクが膝にかかる
    → 前腕が長い ＝ 同じ力でより大きなトルクが肘にかかる
```

> **あなたは、関節技を極めやすく、極められやすい体格である。**
> とくにヒールフックに対しては平均より不利になる。
> ヒールフックが認められたルールでは、これは軽視できない。
> **平均より早くタップする必要がある。これは弱さではなく物理である。**

### まとめ

| 項目 | 判定 | 理由 |
|:---|:---:|:---|
| ジャブ・ストレートの射程 | 有利 | リーチ。決着打がストレート系に寄る【A】 |
| ティープ・オブリークキック | 有利 | 長い脚。質量を必要としない距離管理 |
| カーフキック・ロー | 有利 | 長い脚は末端速度が出しやすい。質量不要 |
| 三角絞 | 有利 | 長い脚が直接効く |
| リアネイキッドチョーク・ダース | 有利 | 長い腕が巻きつきに直接効く |
| ガードの維持 | やや有利 | 長い脚で距離を作れる |
| クリンチの押し合い | **不利** | 質量不足。55.3kgで60kgは押せない |
| テイクダウン防御 | **不利** | 重心が高い【C】 |
| 自分のタックル | やや不利 | レベルチェンジの移動距離が長い【C】 |
| 腕十字・キムラへの耐性 | **不利** | 前腕が長い |
| ヒールフックへの耐性 | **かなり不利** | 脛骨が長い。最優先で対策する |
| クローズドガードでの防戦 | 不利 | 質量差で潰される |
| 50-50 | **かなり不利** | てこの不利が直撃する。避ける |

## 5. ハンドボールという資産

指導者が「軸と体幹が良さそう」と言った出所は、ほぼ確実にここである。

**投げる動作は、ストレートと同じ運動連鎖である。**
股関節 → 体幹の回旋 → 肩 → 肘 → 手という、近位から遠位への順序。
[06_立ち技](../2_やる/06_立ち技.md) で述べた回し蹴りの力学も同じ構造をしている。

ほかにも転移するものがある。
ゼロステップのようなステップワークは、リズムと接地しながらの方向転換の素地になる。
フェイントはハンドボールという競技の中核なので、
**「反応を作ってから入る」という発想を既に持っている**ことになる。
投げながら当たられる中での軸の維持、接触への心理的な慣れ、跳躍と着地、対人の空間認知。

> **あなたは運動未経験者ではない。**
> [01_この競技の構造](../1_読む/01_この競技の構造.md) の5層モデルでいえば、
> **L2（フレームと姿勢）は既にある程度できている**。
>
> つまりボトルネックは動きの質ではなく、燃料・筋量・特定技術の配置である。
> これは良い診断で、動きの質を作り直すのは何年もかかるが、この3つは数ヶ月で変わる。

### 持ち込むべきでないもの

| 項目 | 問題 | 修正 |
|:---|:---|:---|
| 投げっぱなしの腕 | ハンドボールは投げた後に腕を戻す必要がない。パンチは戻さないと打たれる | 「打つ」より「**戻す**」を練習する |
| 上体の過剰な回旋 | 投球は最大回旋が善だが、パンチは回りすぎると体勢を失いタックルをもらう | 打ったら必ず角度を切る |
| 腕の高さ | 投球フォームは腕が高い。格闘技の構えは肘を締める | 肘を体幹に近づける |
| **投球肩** | ハンドボール経験者は肩の障害（腱板・関節唇）を持っていることがある。キムラ・アメリカーナへの耐性に直結する | **§2 で故障歴を確認する。痛みがあれば整形外科へ** |

### 使い方

あなたのストレートは、他の初心者より速く仕上がるはずである。
投球動作の運動連鎖を、そのまま拳に載せ替える作業になる。

そしてこれは §4 の「決着打がストレート系に寄る」という統計とも方向が一致している。
**ジャブとストレートは、あなたの体格と運動歴の両方が支持する。ここに投資する。**

## 6. スタミナの正体

> 「一回限界を知ってから30分休憩してからだと、なんかめっちゃ走ったりできる」

これは気のせいでも精神論でもない。**プライミング効果**という名前のついた、確立した現象である。【A】

事前の高強度運動が、その後の運動における酸素摂取量の立ち上がりを加速させる。
必要な回復時間は9分以上で、回復20分では運動耐容能が対照比で**30%**改善し、
効果は前の運動の終了後**30〜45分**保たれる。

あなたの「30分」は、ほぼ最適域にあたる。自分で発見していたことになる。

> **あなたのスタミナが低いのではなく、ウォームアップが不十分だっただけの可能性が高い。**
> つまりこれまで、試合やスパーの第1ラウンドをウォームアップに使っていた。

具体的な手順は [15_からだを作る](15_からだを作る.md) にある。

ただし、サンドバッグの3セット目で潰れた件はこれだけでは説明がつかない。
**燃料（小食）と呼吸のほうが主因である可能性が高い。** これも [15_からだを作る](15_からだを作る.md) で扱う。

## 7. いま何ができていて、何ができていないか

### 腕相撲に勝てるようになったこと

**これは筋肉が増えたのではなく、神経が変わったのである。**【A】

| 期間 | 何が起きるか |
|:---|:---|
| 最初の2〜4週 | 筋力向上のほぼ100%が神経性。運動単位の動員と発火頻度が改善する。筋の断面積はほぼ変わらない |
| 約6週 | 有意な筋肥大が検出され始める |
| 約8週以降 | 筋肥大が筋力向上の主因になる |

良い知らせとしては、**あなたの神経系は明確に反応している**。トレーニングへの応答性が良い。
冷静な事実としては、**筋肉はまだ増えていない**。§3の増量計画はまだ始まってもいない。

なお、初回のジム体験で2時間は未経験者には量が多すぎる。
筋肉痛と疲労が長引き、次の練習の質を落とす。1回45〜60分で十分である。

### 首が決まらないこと

> 「もっと強くしてください」と何度も言われた

**これは筋力の問題ではない。**

```
  相手が「もっと強く」と言える ＝ 相手は喋れている
                              ＝ 気道にも頸動脈にも乗っていない
                              ＝ 腕がどこにも乗っていない
```

気道に乗っていれば相手は咳き込むので「もっと強く」とは言わない。
頸動脈に乗っていれば数秒で効くので、言う暇がない。

そして**あなたは前腕が長い**（§4）。これはリアネイキッドチョークにおいて有利な条件である。
決まらない理由が筋力であるはずがない。**配置と工程の問題**である。

診断と修正の手順は [12_困ったときの索引](../3_引く/12_困ったときの索引.md) にある。
所要5分の診断ドリルがあるので、次の練習で必ずやってほしい。

## 8. 組み立て

### 設計の原理

```
 使う    リーチ、脚の長さ、投球由来の運動連鎖、絞めの巻きつき、累積型の打撃
 使わない 質量、押し合い、パワー、近距離の力比べ
 守る    膝（てこが不利）、テイクダウン（重心が高い）、頭（姿勢由来のリスク）
```

### 主軸 — 長い武器で削り、下がらせ、背中を取る

```
 ①  ティープ・オブリークキックで距離を止める
       長い脚。質量ゼロで相手の前進を止められる
 ②  ジャブ → ストレートでリズムを支配する
       リーチ【A】＋ ハンドボール由来の運動連鎖
 ③  カーフキック・ローを積む（序盤から）
       長い脚は末端速度が出る。質量不要
 ④  相手が詰めてきたら45度で外す
       押し合いに応じない。真後ろに下がらない
 ⑤  3〜5分後、相手の移動力が落ちる
 ⑥  ストレートか組みを通す。倒すか、相手が背を向ける
 ⑦  長い腕でバックコントロール → リアネイキッドチョーク
       UFC全サブミッションの約39%【B】。あなたの体格が最も活きる決着
```

### 副軸 — 距離を潰してくる相手に

```
 ①  壁を背にしない位置取りを最優先
 ②  組まれたら押し合わず、アンダーフックを1本取って角度を作り離脱
 ③  倒されたら即立つ
 ④  立てなければ、足関節の「脅威」を作って相手を下がらせる
       極めにいかない。抑止力として使う
 ⑤  相手が慎重になった瞬間に立つ
```

### やらないこと

```
 × ボディロックの押し合いに応じる    質量差で負ける
 × 壁際で力比べをする                同上
 × クローズドガードで長居する        潰される
 × 50-50 に入る                      てこの不利が直撃する
 × フック主体のインファイト          体格と運動歴の利点を両方捨てる
 × 真後ろに下がる                    追撃を全部もらう
 × 序盤から一発を狙う                プライミング前で身体が動かない
 × 空腹で練習に行く                  3セット目で潰れる
```

## 10. 検証すること

この章の提案はすべて仮説である。確かめてほしい。

| 検証すること | 方法 | 判定 |
|:---|:---|:---|
| 食事は足りているか | 3日間の実測 | 2,300 kcal 未満なら不足 |
| プライミングは効くか | 有り／無しで同じ3ラウンドのきつさを記録。各5回 | 第1ラウンドが明確に楽なら成功 |
| 増量は正しく進んでいるか | 体重（毎朝）＋主要種目の推定1RM（月1） | 体重も1RMも上がれば筋。体重だけなら脂肪 |
| 首は直ったか | パートナーの3択フィードバック | 「効いてる」が出る位置を再現できる |
| 鉄は足りているか | 血液検査 | フェリチンが50 μg/L 未満なら要相談 |
| 足関節の防御は間に合うか | アシガラミに入られてから抜けた率 | 80%以上で攻撃を解禁 |

記録は毎回3行でいい。

```
[食事]        練習3時間前に食べた：有／無
[プライミング] 有／無・回復時間○分
[通ったこと]
[やられたこと]
[次回試すこと]
```

## この章の弱点

- 身長・リーチ・脛骨長・体脂肪率が未測定である。§4のてこの議論と§3の必要量は推定に依存している
- リーチの優位は軽量級で逆転する報告がある【A】。
  §8の組み立ては「リーチが有利だから勝てる」ではなく「**質量を使わずに戦うため**」の設計として読むこと
- 重心が高いと倒されやすいというのは現場の共通見解であり【C】、MMAの実測データではない
- ハンドボールから格闘技への転移を検証した研究はない【C】。§5は運動連鎖の構造的な類似からの推論である
- 「一度鍛えた筋の再獲得が速い」はヒトでは議論がある【B〜D】
- 増量の目標値は階級リミットからの逆算であり、骨格が支えられる筋量の上限は分からない。進捗を見て修正する
- 祖先に基づく処方は行っていない（§2）。これは意図的な設計判断である
