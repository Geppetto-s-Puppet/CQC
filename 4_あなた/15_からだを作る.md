# 15. からだを作る

> **この章が答えること** — 練習中に吐きそうになるのはなぜか。何をどれだけ食べ、どう鍛えるのか。
> **読了の目安** — 30分
>
> **要約**
> 3セット目で潰れたのは、水でも、たぶん血でもない。食べていないことと、呼吸である。
> ただし鉄欠乏は血液検査でしか判定できないので、並行して調べる価値はある。
> そして小食は、スタミナ不足・筋肉不足・あの症状すべての共通の原因になっている。

---

## 1. まず、あの症状は何だったのか

```
 サンドバッグ3分 × 1分休憩を反復
 3セット目くらいからふらつき、吐き気、意識の混濁
 水は2L持参。レバーは食べない
```

時間の情報が重要である。3セット目ということは、**開始からおよそ12分**にあたる。
この時間帯は**脱水では説明がつきにくい**（2L持参で12分の脱水は考えにくい）。
つまり水は主犯ではない。

候補を可能性の高い順に並べると次のようになる。

| | 候補 | あなたの状況との適合 |
|:--:|:---|:---|
| 1 | **エネルギー不足**（小食、練習前の摂取不足） | 小食を自己申告。12分の高強度は糖質依存が最大。吐き気とふらつきは典型 |
| 2 | **呼吸の乱れ**（息止め、または過換気） | サンドバッグの初心者に極めて多い。意識の混濁と直結する |
| 3 | **ペーシング**（ウォームアップ不足で序盤に飛ばしすぎ） | 既に判明している弱点。1本目から全力なら3本目で枯れる |
| 4 | **鉄欠乏**（貧血の有無を問わず） | 小食＋低体重＋高負荷。症状が完全に一致する。ただし検査が要る |
| 5 | 脱水・電解質不足 | 12分では考えにくいが、2Lは「持参量」であって「摂取量」ではない |
| 6 | 休憩中の血液の貯留 | 1分休憩で座ると立ち上がりに血圧が落ちる |

> **「血が少ないのか、それとも水か」という問いへの答え。**
> 水ではない可能性が高い（時間が早すぎる）。
> 血（鉄）は可能性があるが、検査なしには断定できない。
> **だが最も可能性が高いのは、そのどちらでもなく、食べていないことと呼吸である。**

## 2. 燃料 — 根本にあるもの

### エネルギー可用性という考え方

```
                   摂取エネルギー − 運動で消費したエネルギー
 エネルギー可用性 ＝ ──────────────────────────────────────
                            除脂肪体重 (kg)
```

要するに「運動を引いたあと、身体の維持に残るエネルギー」のことである。
これが低いと、身体は筋の合成、骨、内分泌、免疫、認知を順に切り捨てていく。

国際オリンピック委員会は2023年に、この状態を「スポーツにおける相対的エネルギー不足」として
合意声明を出している。低エネルギー可用性が健康とパフォーマンスの広範な悪化を引き起こすこと、
そして**男性が症状を示す領域はおよそ 9〜25 kcal/kg 除脂肪体重/日**と推定されることが述べられている。【A】
（女性でよく使われる30という閾値には議論がある【D】）

### あなたの必要量

体重55.3kg、体脂肪率を仮に14%とすると、除脂肪体重はおよそ47.5kgになる。
（体脂肪率は未測定なので、実測すれば精度が上がる）

```
 健常域のエネルギー可用性 40 kcal/kg を確保する
   47.5 × 40 = 1,900 kcal   ← 運動を引いたあとに残すべき量

 運動での消費
   格闘技・筋トレ 1回あたり 400〜700 kcal
   週5回 × 550 ÷ 7日 ≒ 400 kcal/日

 必要な摂取量
   1,900 + 400 = 約 2,300 kcal/日   ← 維持の下限

 増量する場合（除脂肪 +4〜5kg 計画）
   + 200〜300 = 約 2,500〜2,600 kcal/日
```

> **目標は1日2,500〜2,600 kcal。**
> 自分を「小食」と認識している人の摂取量は、おおむね1,500〜1,900 kcalのことが多い。
> そうだとすれば**1日あたり600〜1,000 kcal 足りていない**。
> これは症状のすべてを説明できる大きさである。

### 内訳

| | 量 | 55.3kgでの目安 | 役割 |
|:---|:---|:---|:---|
| タンパク質 | 1.6〜2.2 g/kg | 90〜120 g/日 | 筋の合成 |
| **炭水化物** | 4〜6 g/kg | **220〜330 g/日** | **高強度の主燃料。ここを削ると3セット目で枯れる** |
| 脂質 | 残り | 60〜80 g/日 | ホルモン、エネルギー密度 |

### なぜ炭水化物なのか

高強度で断続的な運動の主燃料は筋グリコーゲンで、短時間でも大きく減る。
高強度の間欠運動のあと、筋グリコーゲンは**運動前の約28%**まで低下し、
2時間で39%、5時間で53%、12時間で67%、そして**24時間で102%**まで回復する。【A】

つまり完全な回復には約24時間かかる。
前日の食事が足りなければ、翌日の練習は枯れた状態から始まることになる。
連日練習するなら毎日補充しないと、累積で減っていく。

**あなたの「3セット目から」は、その日のスタート地点が既に低いことを示唆している。**

### 小食の人が食べる量を増やす方法

「もっと食べろ」は解決策ではない。食べられないことが問題なのだから、方法を変える。

**飲む。** これが最も効く。牛乳、豆乳、飲むヨーグルト、プロテインシェイク、スムージー、雑炊やスープ。
液体は満腹感が低い。

**回数を増やす。** 3食を5〜6回に。1回の量を増やさず、回数で稼ぐ。

**密度を上げる。** 料理に油を足す、ナッツ、ピーナッツバター、チーズ、卵、アボカド。

**満腹感の高いものを減らす。** 練習前に大量の野菜や水で腹を膨らませない。食物繊維は満腹感が高い。

**練習直後の窓を使う。** 運動直後は食欲が落ちるが吸収は良い。固形が無理なら飲み物で。

**記録する。** 3日間だけアプリで記録する。推測ではなく実測しないと、何が足りないか分からない。

### 練習日のタイムライン

```
 T−3時間   炭水化物中心の食事（米、パン、麺）＋タンパク質
              ここが最重要。空腹で練習に行かない
 T−60分    軽い糖質（バナナ、おにぎり半分、ゼリー飲料）
 T−45分    プライミング型のウォームアップ開始（§6）
 練習中     水＋電解質。60分を超えるか高強度なら糖質入りの飲料
 T+0〜60分  糖質＋タンパク質（プロテイン＋バナナ、牛乳＋おにぎりなど）
 その日の夜  しっかり炭水化物。翌日の練習の燃料はここで作られる
```

サンドバッグ3分×1分というメニューは、見た目より遥かに高強度で糖質への依存が高い。
**空腹で入って3セット目に枯れるのは、生理学的に正常な反応**である。根性の問題ではない。

## 3. 鉄と血液

### 調べる価値がある理由

**非貧血性の鉄欠乏**、つまりヘモグロビンが正常でも鉄の貯蔵が足りない状態は実在し、
運動耐容能を明確に損なう。【A】

アスリートでは**フェリチンが50 μg/L 未満**が、臨床的に意味のある鉄欠乏の閾値として妥当とされる。
この範囲で疲労、認知機能の低下、運動能力の低下、体温調節の障害が生じる。
そして貧血がなくても運動耐容能を損ない、**自律神経の障害に似た症状を示しうる**。【A】
日本の大学アスリートでも、鉄欠乏かつ非貧血の有病率が報告されている。【A】

あなたのリスク因子は、小食（摂取不足）、低体重、高い運動負荷、そして鉄源をあまり食べていないこと。
**症状も一致している。**

### 検査

```
 依頼する項目
   □ 血算（ヘモグロビン、ヘマトクリット、MCV）
   □ フェリチン          ← 最重要。これがないと判定できない
   □ 血清鉄、TIBC、トランスフェリン飽和度
   □ CRP                 ← フェリチンの解釈に要る
   （余裕があれば）総タンパク・アルブミン、ビタミンD

 タイミング
   激しい練習の直後は避ける。休養日か軽い日の朝に

 解釈の注意
   フェリチンは炎症で上昇する急性期タンパクなので、
   ハードな練習の直後だと見かけ上正常になることがある。
   だからCRPを同時に測り、休養状態で測る
```

### 鉄剤を自己判断で飲まないこと

鉄の過剰は肝臓などに蓄積して有害になる。
**検査で欠乏が確認されてから、医師の指示で**始める。

参考として、非貧血性の鉄欠乏があるアスリートでは元素鉄30mg/日を6週間で是正されたという報告があるが、【A】
これは処方の根拠であって、自己判断の根拠ではない。

### レバーは食べなくていい

鉄源はいくらでもある。

吸収の良いヘム鉄は、赤身肉（牛・ラム）、カツオ、マグロ赤身、アサリ、シジミ、砂肝。
吸収が劣る非ヘム鉄は、小松菜、ほうれん草、大豆製品、ひじき、厚揚げ。

**ビタミンCを同時に取ると吸収が上がる**（柑橘、ピーマン、ブロッコリー）。
逆に食事と同時の濃いお茶やコーヒーは吸収を下げる。

実務としては、赤身肉かカツオを週3〜4回、ビタミンCと一緒に。それだけでかなり変わる。

## 4. 呼吸 — おそらく半分はこれ

打撃の初心者には2つのパターンがある。

**息を止める。** パンチを打つ瞬間に息を止めると、胸腔内圧が上がって静脈の還流が落ち、
脳血流が変動する。頭が重くなる。

**過換気になる。** 苦しくなって速く浅く吸いすぎると、血中の二酸化炭素が下がりすぎる。
すると**脳の血管が収縮して脳血流が落ちる**。
めまい、意識の混濁、手足のしびれ、そして吐き気。

**後者はあなたの症状と特によく一致している。**【B】

修正はこうなる。

```
 1. 打つ瞬間に「シュッ」と吐く。吸うことは考えない
 2. 吸うより吐き切るほうを優先する（吐けば勝手に入る）
 3. 1分の休憩中は座らない。歩きながら鼻から吸って口から長く吐く
 4. 3分のうち最初の1分は7割で打つ。全力は最後の30秒だけ
 5. 苦しくなったら打つのを止めて3呼吸だけ整える。止まるのは負けではない
```

4番は次節のプライミングと同じ話である。

## 5. 水と電解質

2L「持参」は「摂取」ではない。まず一度、発汗量を実測してみるといい。

```
 練習前の体重 − 練習後の体重 + 飲んだ量 = 発汗量

 例：前 55.3kg → 後 54.5kg、飲んだ 0.5L
     発汗量 = 0.8 + 0.5 = 1.3 L／セッション
```

体重の2%を超えて減るとパフォーマンスが落ち始める。あなたなら1.1kgが目安になる。
60分を超えるセッションや大量に発汗する場合は水だけでは足りないので、
ナトリウムを含む飲料を使う。水だけを大量に飲むと、逆に低ナトリウム血症のリスクがある。

## 6. プライミング — ウォームアップの設計

事前の高強度運動が、その後の運動における酸素摂取量の立ち上がりを加速させる。
これがプライミング効果である。【A】

| | 内容 |
|:---|:---|
| 前の運動の強度 | ガス交換閾値と最大酸素摂取量の差の約70% |
| 必要な回復時間 | **9分以上** |
| 効果の大きさ | 回復9分で運動耐容能 +15%、**回復20分で +30%** |
| 効果の持続 | 前の運動の終了後、**少なくとも30〜45分** |

あなたが体感していた「30分」は、ほぼ最適域にあたる。

### 手順

```
 T−45分  一般的なウォームアップ（関節運動、動的ストレッチ、軽いシャドー）10分
 T−35分  プライミング
            「きついが全力ではない」強度で4〜6分連続
            目安：会話が単語単位でしか出ない。主観的強度7〜8/10
            種目：アサルトバイク、ローイング、縄跳び、シャドー、バッグ
            全力（10/10）はやらない。疲労が残って逆効果になる
 T−25分  回復 15〜25分
            完全に止まらず、軽い動きと技術確認。座り込まない
 T−0分   開始
```

大会では開始時刻を自分で制御できない。
「呼ばれてから20〜30分前」を狙うために、進行を見る係を1人決めておくといい。
遅れたら軽いプライミングを再投入する。

**限界について。** 元の研究は自転車とローイングの連続運動を扱っている。
MMAのような断続的な運動への転移は直接検証されていない。【B】
効果量（+15〜30%）も「重強度運動の耐容時間」であって、試合の勝敗ではない。
ただし副作用がなく、コストがほぼゼロで、あなたの体感と一致している。試す価値は高い。

## 7. 筋力

### 何が求められるか

体系的レビューによれば、組み技系で成功する選手はやや長め（数十秒規模）の無酸素性の発揮に優れ、
打撃系で成功する選手は短時間の発揮に優れる。MMAは両方を要求する。【A】

オリンピック競技の格闘技選手を対象にした体系的レビューでは、
筋力トレーニングによって最大の動的筋力・等尺性筋力、パワー、柔軟性、バランスが有意に改善し、
柔道・空手・フェンシング・ボクシングの競技固有の動作でも改善が見られている。【A】

### 組み方

| 目的 | 負荷 | レップ | セット | 頻度 |
|:---|:---|:---|:---|:---|
| 最大筋力 | 85%1RM以上 | 1–5 | 3–5 | 週2 |
| パワー | 30–60%（速度重視） or 75–85%（力重視） | 2–5 | 3–5 | 週1–2 |
| **筋肥大**（あなたは必要） | 65–80%1RM | 6–12 | 3–4 | 週2 |
| 筋持久 | 40–60%1RM | 15–25 | 2–3 | 週1 |

原則が3つある。**失敗するまで追い込まない**（特にパワー種目）。
**筋肥大は階級と相談する**（あなたは余裕があるので必要）。
そして**技術練習の質を落とすフィジカルは、フィジカルとして失敗している**。

### 種目

| 分類 | 種目 | 理由 |
|:---|:---|:---|
| 股関節伸展（両脚） | デッドリフト、トラップバー、スクワット | すべての出力の土台 |
| 股関節伸展（片脚） | ブルガリアンスクワット、片脚RDL | 実戦は常に非対称 |
| 上半身プル | 懸垂、ベントオーバーロウ | 引く力＝組みとコントロール |
| 上半身プッシュ | ベンチプレス、ディップス、OHプレス | 押す力＝フレームと距離 |
| 爆発 | ジャンプ、メディシンボール投げ | 力の立ち上がり |
| 体幹（抗回旋） | パロフプレス、ランドマイン | 力の伝達 |
| 把持 | ファーマーズウォーク、タオル懸垂 | グリップの持久 |

オリンピックリフトは有効だが技術の習得コストが高い。
時間がないならジャンプ系とメディシンボールで代替してよい。【B】

## 8. 持久力

```
 A. 有酸素の基礎（回復速度を上げる）
    週1〜2回、心拍数60〜75%HRmax で30〜45分
    ランニング、自転車、ローイング。関節への負担が少ないものを選ぶ

 B. 試合の再現（本命）
    15秒全力 → 45秒中強度 を5セット ＝ 5分（1ラウンド想定）
    ラウンド間3分休憩 × 3ラウンド
    種目：アサルトバイク、ローイング、サンドバッグ、パートナードリル

 C. 競技特異的（最も転移する）
    ポジショナルスパーやテイクダウンドリルそのものがこれを兼ねる
```

優先順位は C > B > A である。Cが最も転移するが、Aがないと回復できない。**Aは土台、Cが本体。**

長距離走ばかりだと爆発力が落ちるし、高強度インターバルばかりだと疲労が抜けず技術練習の質が落ちる。
そして「追い込んだ感」で評価しないこと。心拍数、出力、タイムで測る。

## 9. 首

等尺性の頸部筋力（太さではなく筋力）が脳振盪のリスク低下と関連するという報告はあるが、
**証拠は混在しており、最適な期間・強度・頻度は未確立**である。【D】

ただし首相撲やグラウンドでの首の制圧、投げられたときの頭部の保護という直接的な必要性がある以上、
やらない理由はない。「首を鍛えたから安全」と考えないこと。

```
 段階1  等尺性（週3、初心者は最低4週）
        前後左右の4方向、手で抵抗をかけて10秒 × 3セット
        ネックブリッジはこの段階では絶対にやらない（頸椎への負荷が高い）

 段階2  徒手抵抗（週2〜3、段階1を4週以上こなしてから）
        パートナーが抵抗、ゆっくり可動域を使って8〜12回 × 2〜3セット

 段階3  ハーネス／マシン（週2）
        10〜15回 × 3セット。軽い重量から

 段階4  ブリッジ（上級・任意）
        段階3まで問題なくこなせてから
```

首に痛み、しびれ、放散痛がある場合は中止して医療機関へ。

## 10. 姿勢と可動域

### デスク姿勢は、KOリスクの話である

深夜までPCの前にいる生活は、健康の話ではなく**戦闘能力の話**になる。

長時間の座位で典型的に起こるのは、頭部が前に出て、肩が前に丸まり、
胸筋と上部僧帽筋が短縮し、深部の頸屈筋と下部僧帽筋が弱化し、
股関節屈筋が短縮して殿筋が弱くなり、胸椎の伸展と回旋が制限される、という一連の変化である。

これが格闘技で何を意味するか。

| 姿勢の問題 | 格闘技への影響 |
|:---|:---|
| **頭部が前に出る** | **顎が上がる → 回転軸からのてこが長くなる → 同じ打撃でトルクが増える** |
| **深部頸屈筋の弱化** | **首の事前収縮が効かない → 予期による角速度−29%の恩恵を取り逃す**【A】 |
| 肩の前方位 | キムラ・アメリカーナへの耐性低下、パンチの肩の安定性低下 |
| 胸椎の伸展・回旋の制限 | ストレートの回旋が出ない、フレームが作れない |
| 股関節屈筋の短縮 | 股関節伸展が出ない＝打撃・蹴り・スプロールの出力低下 |

> **あなたのデスク姿勢は、KOされやすさを直接上げている。**
> これは比喩ではなく、[02_効く仕組み](../1_読む/02_効く仕組み.md) のてこの式から出る帰結である。

### 1日10分

```
 短縮しているものを伸ばす
   □ 胸筋（ドアフレームストレッチ）    30秒 × 2
   □ 股関節屈筋（ランジ姿勢）          30秒 × 左右
   □ 胸椎の伸展（フォームローラー）    1分
   □ 胸椎の回旋（オープンブック）      10回 × 左右

 弱化しているものを鍛える
   □ 顎引き（チンタック）              10秒 × 5   ← 深部頸屈筋。最重要
   □ 首の等尺性 4方向                  10秒 × 3
   □ 肩甲骨の下制・内転（フェイスプル） 15回 × 2
   □ 殿筋（ヒップスラスト）            15回 × 2
```

「顎を引く」は [02_効く仕組み](../1_読む/02_効く仕組み.md) の防御5原則の第2項そのものである。
デスクでもできるので、仕事中やゲーム中に思い出すたびにやるといい。

### 格闘技で実際に必要な可動域

股関節の外転・外旋・屈曲がいちばん重要で、ガード、パスへの対応、
そして**足関節からの脱出**に直結する。次いで胸椎の伸展・回旋、足関節の背屈、肩の外旋。

## 11. 睡眠と回復

| 要素 | 推奨 |
|:---|:---|
| 睡眠 | 7〜9時間。最も費用対効果が高い回復手段 |
| 栄養 | §2のとおり。減量期でもタンパク質は落とさない |
| 完全休養 | 週1日以上 |
| デロード | 3〜6週ごとに1週、負荷を50〜70%に |

睡眠については、格闘技に特有の理由がいくつかある。

**技術の定着は睡眠中に起こる。** 寝ないと練習した技が定着しないので、
[04_うまくなる仕組み](../1_読む/04_うまくなる仕組み.md) の学習設計が無駄になる。【A】
睡眠不足は傷害リスクとも関連する。【A/B】
そして筋の合成にも直結するので、増量計画そのものが進まない。

さらに、深夜型の生活は朝食を飛ばしやすく、1日の食事機会が減るので、
**あなたの「小食」の一因になっている可能性が高い**。【C】

「今日から8時間寝る」は続かないので、現実的にはこうする。

```
 1. 就寝時刻を15分ずつ前倒しする（1週間ごと）
 2. 起床時刻を先に固定する（就寝より起床のほうが制御しやすい）
 3. 朝に食事を1回追加する ← これが小食対策と同時に効く
```

足関節の防御ドリルは段階に関係なく毎回やる。

筋力トレーニングを格闘技と同じ日にやるなら、**格闘技の後**にする。
先にやると技術練習の質が落ちる、つまり学習が劣化する。【C】

## 14. 受診したほうがいい徴候

```
 早めに受診
  ・十分に食べて休んでも、疲労感が数週間続く
  ・立ちくらみ、動悸、息切れが日常生活でも出る
  ・氷を異常に食べたくなる（異食症。鉄欠乏の特徴的なサイン）
  ・爪がスプーン状に反る、舌がつるつるして痛む

 すぐ受診
  ・運動後に褐色から赤褐色の尿が出る（横紋筋融解の疑い）
  ・強い筋痛やこむら返りを伴う極端な運動不耐
  ・胸痛、失神
```

## この章の弱点

- 体脂肪率が未測定なので、§2の必要量は推定である
- 運動によるエネルギー消費（400〜700 kcal/回）は一般的な目安であり、あなたの実測ではない
- エネルギー可用性は現場で正確に測定できないと国際オリンピック委員会自身が述べている【A】。§2は目安である
- 鉄欠乏は仮説であり、検査なしには何も言えない。§3は「調べる根拠」であって診断ではない
- 過換気による症状は、格闘技での直接研究ではなく生理学からの演繹である【B】
- プライミング効果の元研究は連続運動を扱っている。断続運動への転移は未検証【B】
- MMAに特化した縦断的なトレーニング研究は非常に少ない。推奨の多くは他競技からの外挿である【B】
- 頸部トレーニングの脳振盪予防効果は未確定である【D】
- **本章は医学的助言ではない。** 症状があれば医療機関へ
