# 07. 組み技 — 組み手争い、テイクダウン、クリンチ

> **位置づけ**: 打撃（遠）とグラウンド（近）をつなぐ**唯一の橋**。
> 米陸軍MACPの第1原則が **"Close the Distance"** であり、
> 第2原則が **"Gain Dominant Position"** である以上、
> この章はドクトリンの中心そのもの。【A】

---

## 1. なぜ軍系ドクトリンは組みを重視するのか

MACPの教義では、**「訓練を受けていない相手は腕を完全に伸ばせる距離でこそ最も危険」**であり、
だからこそ**パンチレンジを避けて一気に距離を詰める**ことが第一原則とされる。【A】

背景にある構造:
- 打撃は**確率的**（当たるか外れるか、効くか効かないか）
- 組みは**決定論的**（掴んだら掴んでいる。位置は連続的に管理できる）
- 装備・複数・武器移行を前提とすると、**確率に賭けられない**

同じ結論に、まったく別の経路で到達したのがBJJのポジショナルヒエラルキーであり、
コンバットサンボであり、現代MMAのレスリングベース選手の優位性である。【B】

## 2. テイクダウン以前 — 「組む前の技術」が本体

**初心者の最大の誤解: テイクダウン＝タックルの入り方。**
実際には、成否の8割は**入る前**に決まっている。

### 2.1 ハンドファイト（組み手争い）

| 要素 | 内容 |
|:---|:---|
| **ペンメル (pummeling)** | 内側の手（アンダーフック）を交互に取り合う基本運動 |
| **アンダーフック** | 相手の脇の下から差す。**組みにおける最重要の1手** |
| **オーバーフック（ウィザー）** | 上から巻く。防御的・カウンター的 |
| **コリタイ (collar tie)** | 首の後ろを掴む。姿勢を崩す |
| **リストコントロール** | 手首の支配。相手の防御手を殺す |
| **2-on-1（ロシアンタイ）** | 相手の片腕を両手で。強力な支配 |

**原則: アンダーフックを持っている側が、その交換において有利。**
両アンダー（ダブルアンダーフック＝ボディロック）は、クリンチにおける「マウント」に相当する。【C】

### 2.2 レベルチェンジ

**上下動そのものが技術である。**
- 腰を落とす（**背中を丸めない。股関節と膝で落ちる**）
- 落ちた瞬間に前に出る
- **落ちる ≠ お辞儀**。頭が下がった瞬間、ギロチンとフロントヘッドロックの餌になる

**練習法**: レベルチェンジだけを100回。頭の高さは変わるが、背中の角度は変わらないこと。

### 2.3 セットアップ（相手の反応を作る）

```
ジャブ           → 相手の手が上がる → 下が空く → ダブルレッグ
ロー             → 相手が脚を気にする → 上が空く → ボディロック
タックルのフェイント → 相手が腰を落とす → 上が空く → 打撃／首相撲
コリタイで引く    → 相手が引き返す → その力を使ってシングルレッグ
```
[01章 原理10](../1_読む/01_この競技の構造.md)「反応より予測、予測より誘導」の実装。

## 3. テイクダウンのカタログ

### 3.1 レスリング系（MMA適性: 最高）

| 技 | 入る条件 | MMAでの注意 |
|:---|:---|:---|
| **ダブルレッグ（両脚）** | 相手が正対、距離が中〜近 | 汎用性最大。頭の位置は**相手の体側**（正面だとギロチン） |
| **シングルレッグ（片脚）** | 角度がある、壁際 | 完了までの選択肢が多い（ランニング、スイープ、リフト） |
| **ハイクロッチ** | 相手の内側に入れた時 | 上体の支配が付くので打撃を貰いにくい |
| **ボディロック（両アンダー）** | クリンチ成立後 | **MMA最強級**。打撃からの接続が容易で、リスクが低い |
| **スナップダウン → フロントヘッドロック** | 相手が前傾で来た時 | ダースやアナコンダに直結 |

### 3.2 柔道／サンボ系（MMA適性: 中〜高）

| 技 | 備考 |
|:---|:---|
| **大外刈** | クリンチから最も出しやすい。壁際で強い |
| **体落** | 相手の前進力を利用。ノーギでも成立しやすい |
| **小外掛／小内刈** | 崩しの連携用。単体では決まりにくい |
| **背負投** | ノーギでは把握が難しい。背中を向ける＝バックを渡すリスク大 |
| **内股** | 高技術だが、MMAでは体重差と汗で難度が上がる |
| **足払い（出足払・送足払）** | 打撃の隙に刺すと有効 |

**ノーギ／MMAでの柔道技の劣化要因**:
1. **把握点がない**（襟・袖がない）→ 首・脇・手首に置換する必要
2. **汗で滑る**
3. **背中を向ける技はバックを取られる**
4. **投げた後に自分も倒れる技は、上を取られる**

→ **「投げた後に自分が上になる」技を優先する**。【C】

### 3.3 陸自徒手格闘 / コンバットサンボ由来の視点

- 陸自の新格闘（2008年全部隊導入）は、当身技・投げ技（腰投げ・背負投・大外刈）・関節技/絞技（裸絞・十字絞）を
  **武器技術と地続き**で扱う構成。【B】
  → 装備・武器を前提にすると、**「投げてすぐ離れる／すぐ立つ」**判断が入る。純競技とは最適解が違う。
- コンバットサンボは**投げから足関節への直結**を体系化している。
  ヒールフック有りのルールでは、この接続が直接効く。→ [06章](../2_やる/09_足関節.md)

## 4. テイクダウンディフェンス

### 4.1 防御の階層（早い順＝強い順）

```
0. 距離管理で入らせない        ← 最強・最省エネ
1. フレーム／ハンドファイトで頭を止める
2. スプロール（腰を落とし、脚を後方へ飛ばす）
3. ウィザー（腕を巻いて潰す）／クロスフェイス
4. 片脚を取られてから: リンバー、足を抜く、壁に逃げる、ホイールキック
5. 倒された直後の即立ち（ワンダウン・ワンアップ）
```

### 4.2 原則

**原則A: 「倒されない」より「倒されても即座に立てる」。**
100%のTDDは存在しない。倒されること自体は事故ではない。
**倒されたまま3秒以上留まること**が事故。【C】

**原則B: 頭の位置が全て。**
タックルされた瞬間、自分の頭が相手の頭より高い位置にあれば、スプロールが効く。
下になったら、その時点で防御ではなく脱出のフェーズ。

**原則C: 壁／ケージは防御に使える。**
背中を壁に付けると、後方への崩しが効かなくなる。ただし逃げ場もなくなる。**両刃**。

### 4.3 数値目標

エリートMMAで、**テイクダウン成功率25%超**が勝率を有利側に反転させる閾値として抽出されている。【A】
裏返せば、**相手のTD成功率を25%未満に抑えることが防御側の目標**になる。

## 5. クリンチ

### 5.1 クリンチの4形態

| 形態 | 有利な側 | 主な用途 |
|:---|:---|:---|
| **プラム／首相撲**（両手で後頭部） | ムエタイ側 | 膝、崩し。**MMAではタックルを貰いやすい** |
| **オーバー・アンダー** | 五分 | 最も一般的。投げ・テイクダウンの起点 |
| **ダブルアンダー（ボディロック）** | 差した側が圧倒的有利 | テイクダウン、壁押し |
| **ダブルオーバー（ウィザー両側）** | 防御的 | 潰す、離れる |

### 5.2 ムエタイのプラムとMMAの齟齬

首相撲は**ムエタイでは支配的**だが、MMAでは危険が伴う:
- 両手が上＝**タックルに対して完全に無防備**
- 相手にアンダーフックを与える

**MMAでは、首相撲は「短時間・膝を出すためだけ」に使い、長居しない。**【C】
長く支配したいならボディロック。

### 5.3 壁／ケージレスリング

MMA系ルールで壁があるなら、これは**独立した技術領域**。
```
攻め: ボディロック → 壁に押し付ける → 相手の重心を上げる → 足を刈る／持ち上げる
守り: 腰を壁から離す → アンダーフックを取り返す → 角度を作って回る → 頭を外に出す
```
壁際は**打撃も出る**ので、組み手争いをしながら被弾を管理する必要がある。

## 6. テイクダウン後の3秒

**倒した直後の3秒が、その後のラウンド全体を決める。**

```
倒した瞬間の判断:
├─ 相手がガードを取ろうとしている  → パスの準備。ハーフに入れる
├─ 相手が立とうとしている          → 腰を制する／背中を取る
├─ 相手が背中を向けた（タートル）  → バックへ。最良の展開
└─ 相手が脚を絡めに来た            → 警戒。ニーラインを確認 → [06章](../2_やる/09_足関節.md)
```

**ヒールフック有りルール特有の注意**:
テイクダウン直後、相手が**下からアシガラミに入ってくる**のが最も危険な展開。
倒した瞬間に「勝った」と思って前に出ると、脚を取られる。
→ **倒したら、まず自分の脚の位置を確認する。** これを反射にする。【C】

## 7. 練習法

| 段階 | 方法 |
|:---|:---|
| 1 | 動作の分解ドリル（レベルチェンジ、ペンメル、スプロール） |
| 2 | 反復（動かない相手 → 軽い抵抗 → 中程度の抵抗） |
| 3 | **ポジショナルスパー**: クリンチから開始、倒したら／倒されたら止めてリセット |
| 4 | **一方向スパー**: A=倒す係、B=防ぐ係。役割固定で30秒 → 交代 |
| 5 | 打撃込みのスパーで統合 |

**推奨: 3と4に最も時間を割く。**
ポジショナルスパーは**強度を上げても頭部リスクが低い**ため、
[08章](../1_読む/04_うまくなる仕組み.md)の設計上、量を寄せるべき場所。

## 8. チェックリスト

### 段階1
- [ ] 姿勢（背中を丸めない、頭を上げる、腰を落とす）が崩れない
- [ ] ペンメルで、アンダーフックを取り返せる
- [ ] スプロールが反射で出る

### 段階2
- [ ] ダブル／シングル／ボディロックの3つが実戦速度で出る
- [ ] テイクダウン成功率30%以上（試行10回中3回）
- [ ] 打撃からのセットアップが1つ以上ある
- [ ] 倒された直後に立てる（ワンダウン・ワンアップ）
- [ ] 倒した直後、3秒以内に位置を確定できる

### 段階3以降
- [ ] 壁際の攻防を、攻守どちらでも成立させられる
- [ ] 相手のタイプ（レスラー／ストライカー）で組み方を変えられる
- [ ] テイクダウン直後の脚の位置確認が反射になっている
