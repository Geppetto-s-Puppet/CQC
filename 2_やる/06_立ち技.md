# 06. 立ち技 — 距離、足、打撃

> **この章の位置づけ** — 打撃とフットワークをひとつにまとめた。両者は分けて練習できないからである。
> **要約**
> 打撃の8割は「測る」ためと「崩す」ために打つもので、「決める」ために打つのは残りの2割にすぎない。
> フットワークで覚えるべきことは実質ひとつ、真後ろに下がらないことである。
> MMAの構えはボクシングともムエタイとも違う。タックルへの対応が入るからである。

---

## 1. 打撃には3つの目的がある

初心者は「決める」打撃しか打たない。だから当たらないし、当たっても続かない。

| 目的 | 何のために打つか | 代表 |
|:---|:---|:---|
| **測る** | 距離の確認、相手の反応の採取 | ジャブ、ティープ |
| **崩す** | 姿勢・重心・視線を乱す | ロー、ボディ、フェイント |
| **決める** | ダメージを与える、終わらせる | ストレート、フック、肘、膝、カーフ |

エリートMMAの分析で、勝敗を分けたのは有効打の**命中率**であって、
**試行回数の多さは勝利に寄与しなかった**。【A】
これは「たくさん打つ」のではなく「**当たる状況を作ってから打つ**」ということを意味している。

## 2. 構え

MMAの構えは、ボクシングともムエタイとも違う。理由は単純で、**タックルに同時に対応する必要がある**からである。

| 要素 | ボクシング | ムエタイ | MMA |
|:---|:---|:---|:---|
| スタンス幅 | 狭め | 狭め・縦 | **やや広め** |
| 体重配分 | 5:5 | 後ろ足寄り | **5:5前後、変動可能に** |
| 上体 | 前傾・頭を振る | 直立気味 | やや前傾、深く折らない |
| 手の位置 | 高い | 高い＋前手で距離 | やや低め〜中間 |
| 腰 | 高い | 高い | **低め**（レベルチェンジできる高さ） |

ボクシング流の深い前傾はギロチンとタックルの餌になり、
ムエタイ流の後ろ足体重は片脚立ちの瞬間にタックルをもらう。
MMAの構えは、打撃・タックル・タックル防御の3つに同時に対応するための妥協点である。

**確認すること**

- [ ] 顎が引けている
- [ ] 肘が体幹から離れていない（肋とアンダーフックの両方を守る）
- [ ] 膝が柔らかい（レベルチェンジに即応できる）
- [ ] 足が交差していない
- [ ] 視線が相手の胸から肩の中心にある

## 3. 距離 — 3つのレンジ

```
 アウトレンジ   自分の蹴りが届き、相手の拳は届かない
 ミッドレンジ   互いのパンチが届く    ← 最も危険。滞在時間を短くする
 インレンジ     肘・膝・クリンチ・組み
```

原則はひとつ。**ミッドレンジに長居しない。**
アウトから入り、インで仕事をして、アウトに戻る。ミッドは通過するだけの帯である。
これは [01_この競技の構造](../1_読む/01_この競技の構造.md) の
「レンジの移動は必ず危険な通過帯を通る」の実装にあたる。

## 4. フットワーク

### 4.1 三角形という整理の仕方

人が一歩で移動できる方向は、実際には限られている。
フィリピン武術（Pekiti-Tirsia Kali など）は、これを**2種類の三角形**に整理した。

```
【前方の三角形】頂点が相手側にある。踏み込む動き。攻撃的

         前（相手）
           △
          /  \
         A    B      ← ここへ踏み込む
          \  /
           ●         ← いまの自分


【後方の三角形】頂点が後ろにある。外す動き。防御的

           ●         ← いまの自分
          /  \
         C    D      ← ここへ下がる
          \  /
           ▽
          後方
```

核心はひとつ、**真っ直ぐ前にも真っ直ぐ後ろにも動かない**ということである。常に45度。

真後ろに下がると相手の攻撃線上に留まることになり、追撃を全部もらう。
45度に外せば、相手は照準を修正しなければならず、そのぶん時間を奪える。

### 4.2 これは新しいものではない、が整理されている

同じことは各競技に別の名前で存在する。
ボクシングのピボットやサイドステップ、ムエタイの蹴った後の入れ替え、
レスリングのアングルチェンジ、いずれも同じ現象である。

フィリピン武術の価値は発明ではなく、**命名と体系化**にある。
名前がついているものは練習できるので、借りる価値がある。【C】

なお、この体系の素手技術（グンティンと呼ばれる、攻撃してくる腕そのものを潰す技法）は
グローブをつけたMMAでは大半が成立しない。有効性を検証した査読研究もない。【D】
**取るべきは角度の語彙であって、技のカタログではない。**

ただし「攻撃してくる肢そのものを標的にする」という発想自体は生き残っていて、
MMAでは**蹴りのチェック**（相手のローを脛骨で受ける）と**キャッチからのテイクダウン**という形になっている。

### 4.3 内側と外側

相手を「線」で切って考える。

```
             相手
        後ろ手 ●   ● 前手
              \ | /
        外側    \|/    外側
       ←────── 中心線 ──────→
                |
              自分
```

**外側**、とくに相手の前手側の外は、相手の後ろ手（強い手）が届きにくいので最も安全である。ここを取りにいく。
**内側**、つまり相手の両腕の間は最も危険で、両手が届く。通過するだけにする。

フィリピン武術にはこれを表す言い回しがある。
「中心線の内側にいるなら突き抜けて破壊する。外側にいるなら逸らしてから破壊する」。

MMAに翻訳すると、内側に入ってしまったら止まらない（クリンチまで詰めるか、抜けるか）。
外側を取れたら、相手が振り向くまでのわずかな時間ですべてが決まる。

### 4.4 実際に使う10種

| 名前 | 動き | 使いどころ |
|:---|:---|:---|
| ステップイン／アウト | 前後の直線移動 | 常時 |
| 45度前進 | 前足を斜め前へ、後足が追う | 相手が下がるとき |
| 45度後退 | 後足を斜め後ろへ、前足が追う | 相手が詰めるとき |
| ピボット（前足軸） | 前足を軸に体を回す | 打った直後、必ず |
| ピボット（後足軸） | 後足を軸に体を回す | 相手が回り込んできたとき |
| サークリング | 円を描いて横移動 | 常時のデフォルト |
| Lステップ | 前へ入って即座に横へ抜ける | コンビネーションの締め |
| スイッチ | 前後の足を入れ替える | 相手の対応を崩す |
| レベルチェンジ | 腰の高さの上下動 | 打撃と組みの接続 |
| バックステップ＋前進 | 一歩下がって即前進 | カウンター |

### 4.5 絶対原則

```
1. 足を交差させない          交差した瞬間に崩される
2. 真後ろに下がらない        射線に留まる。45度に外す
3. 打った後は必ず角度を変える 打ちっぱなしで止まらない
4. 相手の後ろ手側に回らない   パワーハンドの射程に入る
5. 移動中に重心を高くしない   タックルに対応できなくなる
```

**初心者が最初にやるべきことはひとつだけ、「真後ろに下がらない」。**
これだけで被弾が明確に減る。他は後でいい。【C】

### 4.6 回る向き

相手がオーソドックス（左構え）なら、自分から見て右へ回る。相手の右（強い手）が遠くなる。
相手がサウスポー（右構え）なら、自分から見て左へ回る。

構えが逆同士（オープンスタンス）の場合は、前足の外側の取り合いが勝負になる。
前足を外に取れた側に、後ろ手の直線とローキックが通る。

### 4.7 練習法

床にテープで一辺60〜80cmの三角形を上下対称に2つ貼り、その上を歩く。
前の三角だけ30秒、後ろの三角だけ30秒、合図でランダムに60秒、構えを保ったまま同じことを、最後にシャドーと統合。
1日5分でいい。これは反復で自動化する種類の技術である。【C】

対人では制約を使う。「真後ろに下がったら失点」「打ったら必ず角度を変える」
「前手は常に相手に触れていること」。
制約主導アプローチの研究では、制約を操作した訓練の77.7%が技能習得に肯定的な効果を示している。【A】

## 5. 打撃のカタログ

### 5.1 パンチ

| 技 | 主目的 | MMAでの注意 |
|:---|:---|:---|
| **ジャブ** | 測る・崩す | 最重要。前手で相手のリズムを支配する |
| ストレート（クロス） | 決める | 打った瞬間に重心が前に出る。打ったら角度を切る |
| フック | 決める | 肘が開くとテイクダウンに無防備。コンパクトに |
| アッパー | 崩す・決める | タックルに来る相手の下がった頭に刺さる |
| オーバーハンド | 決める | タックルのフェイントと接続しやすい |
| ボディブロー | 崩す | 遅効性。ラウンド後半に効く |

MMAはグローブが小さいので、ガードの隙間を抜けやすい。
ボクシング的な「腕で受ける」防御は過信できない。**当たらない位置に頭を置く**ほうが安全である。【C】

### 5.2 蹴り

| 技 | 主目的 | 備考 |
|:---|:---|:---|
| **カーフキック** | 崩す・決める | 総腓骨神経を狙う。効くと相手は立てない |
| **ロー（腿）** | 崩す | 相手の前足を破壊してフットワークを奪う |
| ミドルキック | 崩す・決める | キャッチのリスクが最大。打ったら即座に足を戻す |
| ハイキック | 決める | 低確率高リターン。セットアップ必須 |
| **ティープ（前蹴り）** | 測る・距離を切る | 圧力をかけてくる相手への最初の答え |
| オブリークキック | 崩す | 相手の膝・腿の前面。距離を止める |

熟練者の比較研究では、**インパクト時の足の直線速度が衝撃力と中程度に相関**していた。【A】
つまり「体重を乗せて押す」のではなく、**末端の速度を最大にする**のが正しい設計である。
軸足の回転 → 股関節の回旋 → 膝の伸展 という運動連鎖を、遠位ほど速くする。

MMAでの制約は、蹴った瞬間が片脚立ちでタックルに最も弱いこと、
ミドル以上はキャッチされるとそのまま倒されることである。
**蹴りの後の「帰り」が技術の本体**で、蹴り自体より帰りを練習したほうがいい。

### 5.3 肘と膝

| 技 | 使う局面 |
|:---|:---|
| 横肘 | 首相撲から。切れる |
| 縦肘 | 相手が頭を下げたとき |
| テンカオ（直線の膝） | 首相撲、ボディロック |
| 斜めの膝 | 相手の姿勢が崩れたとき、脇腹へ |
| ショートフック／アッパー | 密着状態。組み手争いの合間 |

グラウンド状態の相手への膝と蹴り、後頭部への打撃、肘の可否は
**団体と階級で大きく変わる**。ルールブックの原本を確認すること。

## 6. 防御

コストが低い順、つまり良い順に並べると次のようになる。

```
 1. 距離     そもそも届かない位置にいる。最良
 2. 角度     相手の射線から外れる
 3. 頭の移動 スリップ、ダッキング、ロール
 4. パリー   手で軌道を逸らす
 5. ブロック 腕・脛で受ける。ダメージは通る
 6. 耐える   これは防御ではない
```

**上位ほど脳への負荷が小さい。**
[03_壊れる仕組み](../1_読む/03_壊れる仕組み.md) で見たとおり累積の頭部曝障は不可逆なので、
**ブロックを防御の主軸にしてはいけない**。防御の質は脳の寿命に直結する。

蹴りへの防御は、チェック（脛で受ける）、膝を上げる、**距離を切って前に出る**（蹴りは近づかれると威力が消える）、
そして**キャッチからのテイクダウン**。MMAでは最後が最良の「防御」になる。

### 打撃とタックルの同時対応

これが最も難しい。打撃を防ごうとして手を上げると腰が高くなり、
タックルを防ごうとして腰を落とすと頭が下がる。

答えは、**レベルチェンジのフェイントに反応しない**ことである。
反応せずに距離で処理し、相手が実際に入ってきた重心の移動にだけ反応する。
これは [02_効く仕組み](../1_読む/02_効く仕組み.md) の知覚の議論そのもので、
**四肢ではなく体幹の情報を読む**ことで達成される。【A】

## 7. コンビネーション

良いコンビネーションの条件は4つ。**長さは2〜4発**（5発以上は当たらないうえ姿勢が崩れる）。
**高さを変える**（顔→ボディ→顔）。**軌道を変える**（直線→曲線）。
**最後に角度を切る**（打ちっぱなしで止まらない）。

MMAで本当に重要なのは、打撃どうしのコンビネーションより**打撃と組みの接続**である。

```
ジャブ → レベルチェンジ → ダブルレッグ
ロー → 相手が下がる → 前に詰めてボディロック
オーバーハンド → 相手が下がる → シングルレッグ
タックルのフェイント → 相手が腰を落とす → 上に膝／アッパー
```

純打撃のコンビより、この接続のほうが期待値が高い。【C】

## 8. 練習の順序

| 段階 | 方法 | 目的 |
|:---|:---|:---|
| 1 | シャドー（鏡なし → 鏡あり → 動画） | 運動パターンの形成 |
| 2 | ミット／サンドバッグ | 力の出し方 |
| 3 | 反応ミット（受け手がランダムに合図） | 予測と反応 |
| 4 | 限定スパー（ジャブのみ、前手のみ等） | 特定要素の抽出 |
| 5 | ライトスパー（30〜50%） | 統合。**ここに量を寄せる** |
| 6 | ハードスパー | 週1・短時間・限定的 |

**サンドバッグでは距離感と予測はまったく鍛えられない。**
バッグで上手くなるのは「打ち方」だけである。距離と予測は必ず対人で。【C】

## 9. 到達目標

**段階1の終わりに**

- [ ] 構えが崩れない
- [ ] 前後・左右・角度の4方向に動ける
- [ ] 真後ろに下がらない
- [ ] 自分のジャブが届く距離を身体で正確に知っている
- [ ] パリー・シェル・スリップ・距離の4種を使い分ける
- [ ] 視線が胸から肩の中心にある

**段階2の終わりに**

- [ ] ジャブ・ストレート・ロー・ティープ・膝が実戦速度で出る
- [ ] 蹴った後の帰りの足が崩れない
- [ ] 打撃からレベルチェンジへの接続がひとつある
- [ ] コンビネーションが2〜4発で、最後に角度が切れている
- [ ] ピボットで外側を取れる

**段階3以降**

- [ ] カウンターをひとつ以上、意図的に取れる
- [ ] 相手のタイプに応じて距離戦略を変えられる
- [ ] グラウンドパウンドで位置を失わない

## この章の弱点

- フィリピン武術の素手技術に、有効性を検証した査読研究がない【D】。
  本章は幾何学で説明できる部分に限定した
- 三角形フットワークはフィリピン武術固有の発明ではない。
  本章の主張は「優れている」ではなく「整理の仕方が学習に使いやすい」である
- 一次資料（フィリピン海兵隊の教範）は目次レベルしか確認できていない
- 打撃技術の細部（構えの角度、コンビネーションの長さ）は現場の共通見解であり、実証データはない【C】
