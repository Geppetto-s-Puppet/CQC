# 09. 足関節 — ヒールフックと、その前に読むこと

> **この章は他の技術章と扱いが違う。**
> ヒールフックは、格闘技の技術の中で **「学習の失敗が最も不可逆な損傷に直結する」** カテゴリに属する。
> したがってこの章は **防御 → 安全プロトコル → 攻撃** の順で書かれており、
> **この順序を入れ替えてはいけない**。

---

## 1. なぜ特別扱いするのか — 根拠

### 1.1 疫学

**Piekarski M, Kreiswirth E, Barber Foss K, Jimenez ML, Myer GD, Montalvo AM.
*Knee Injury in Competitive Brazilian Jiu Jitsu Athletes: Implications for Training.* Sports Health 2026.**【A】

| 項目 | 値 |
|:---|:---|
| デザイン | 横断研究 |
| 対象 | 2021年 IBJJF 成年茶帯・黒帯 303名 ＋ マスターズ 455名、2009年 成年 164名 |
| 背景 | IBJJFは**2021年1月1日から、ノーギの成年 茶帯・黒帯部門でヒールフックとリーピングを解禁** |
| **ヒールフック曝露者の膝傷害率** | **26.5 / 1000試合** |
| **非曝露者の膝傷害率** | **2.2 / 1000試合** |
| **相対リスク** | **RR = 12.0（95%CI 1.5 – 96.1, P < 0.001）** |
| 足関節傷害 | 有意差なし |
| 2009 vs 2021 の全体比較 | 膝・足関節の傷害率に有意差なし |

**読み方**:
- 信頼区間 1.5–96.1 は極めて広い。「12倍」という**点推定は精密ではない**
- しかし**下限が1.5 で、区間が1を跨いでいない** → **リスク上昇そのものは有意**
- また **「2021年全体」では傷害率が上がっていない**のに **「曝露者に限れば」上がっている**という構造は、
  リスクが**技術そのものに局在している**ことを示唆する
- 原著の推奨は「競技BJJ選手は**膝傷害リスクを低減するためのスキル訓練**を行うべき」【A】

### 1.2 なぜ他の関節技より危険なのか

| 要因 | 説明 |
|:---|:---|
| **痛覚のフィードバックが遅い** | 膝の十字靱帯・側副靱帯は、損傷ポテンシャルに比して痛覚受容が乏しい。**「痛い」と感じた時には既に損傷している**ことがある【B】 |
| **レバーが長い** | 踵は膝関節から遠い。小さな力で大きなトルクが膝に発生する【B】 |
| **損傷が構造的** | 靱帯断裂・半月板損傷は手術適応になることが多く、復帰に数ヶ月〜1年 |
| **回旋負荷** | 膝は屈曲・伸展の関節であり、**回旋には本来的に弱い** |

### 1.3 生体力学（何が壊れるか）

```
インサイド・ヒールフック（内側）
  → 脛骨を【内旋】させる
  → 主にACL（前十字靱帯）と内側の構造（MCL）に負荷
  → 一般に破壊力が高いとされる

アウトサイド・ヒールフック（外側）
  → 脛骨を【外旋】させる
  → 主に後外側支持機構（PLC）— LCL、膝窩筋腱、膝窩腓骨靱帯 に負荷
```
【B】（一般的な解剖学的理解と、グラップリング医療系解説の一致による。
grappling特化の生体力学的計測研究は現時点で確認できていない）

**重要**: 実際には単一靱帯が単独で壊れることは少なく、
**ACL・MCL・LCL・PCL・半月板の複合損傷**になりやすい。

## 2. 【段階1】防御 — 攻撃より先に完成させる

### 2.1 概念の理解（技より先に）

**(1) ニーライン (knee line)**
```
自分の膝を基準線とする。
相手の脚（特に相手の膝）が、その線を越えて自分の腿の内側に入っているか？

  越えていない → 比較的安全（アウトサイドアシガラミの外側など）
  越えている   → 危険域。ヒールフックのメカニクスが成立しうる
```
**防御の全ての目標は「ニーラインをクリアする（膝の線を越えさせない／戻す）」**。

**(2) リーピング (reaping)**
相手の脚が自分の膝の外側を跨いで、自分の膝関節に回旋負荷をかける配置。
多くのルールで反則とされてきたのはこの危険性ゆえ。**IBJJFは2021年に上位帯のノーギでのみ解禁**。

**(3) ヒール・エクスポージャー（踵の露出）**
```
踵が相手の胸・脇・肘の内側に「露出」した瞬間 = 既に捕まっている
→ 踵を隠すことが、防御の第一目標
```

### 2.2 危険度の警報レベル

```
Lv.0 相手の脚がまだ絡んでいない
      → 距離を切る。脚を掴ませない

Lv.1 相手が片脚を絡めた（アウトサイドアシ、SLXの入口）
      → まだ余裕がある。踵を隠し、股関節を抜く

Lv.2 ニーラインを越えられた（インサイドサドル／ハニーホール、50-50）
      → 警戒。踵を絶対に露出させない。足首を内に折る（"boot"）

Lv.3 踵を掴まれた（まだ組み手が完成していない）
      → 即座に抜くか、抜けないと判断したら **タップを準備**

Lv.4 グリップが完成し、相手が体を回し始めた
      → **即タップ。痛みを待たない。**
```

**このルール表を、練習相手全員と共有すること。** 個人の判断では遅い。

### 2.3 防御技術（3つ）

| # | 名称 | 内容 |
|:---|:---|:---|
| **1** | **ヒール・コンシール（踵を隠す）** | 足首を内側に折り込み、踵を相手の胴に密着させて掴めなくする（"boot" / "hide the heel"）。**最も基本的かつ即効性のある防御** |
| **2** | **クリア・ザ・ニーライン** | 捕まっている脚を、相手の膝の内側方向へ回して、回旋のメカニクスを解除する。ヒールフックは「膝の線」がないと成立しない |
| **3** | **ヒップ・エスケープ／脚を抜く** | 股関節を回して、絡まれた脚そのものを抜く。相手のコントロールが緩い段階でのみ有効 |

**補助**: 「相手の手（グリップ）を先に殺す」— 踵に手が届く前に、相手の手首・前腕を制する。
上級者はここで防御している。【C】

### 2.4 段階1 でやること・やらないこと

**やる**
- [ ] 上記の概念4つを説明できる
- [ ] 警報レベルを見て、Lv.2 で声が出る
- [ ] 防御技術3つを、抵抗のある相手に対して実行できる
- [ ] **ポジショナル防御ドリル**: 相手にアシガラミを与えた状態からスタート、抜けたら成功。1本30秒

**やらない**
- ❌ ヒールフックを掛ける練習
- ❌ 「軽くかけてみる」
- ❌ 防御ができていない相手と足関節の攻防をする

## 3. 安全プロトコル（練習の憲法）

**この6条は、技術ではなくルールである。破る人とは練習しない。**

### 第1条: 形が完成したらタップする。痛みを待たない。
膝の靱帯は、痛みが出る前に損傷しうる。【B】
「まだいける」は、腕十字では通用するが、ヒールフックでは通用しない。

### 第2条: クランク禁止。すべての足関節は「ゆっくり」極める。
原著論文の推奨も、**「急激なクランクではなく、漸進的に力を加えること」**である。【A】
爆発的な回旋を1回でも使う人は、練習相手として不適格。

### 第3条: タップに対する解除は 0.5秒以内。
遅れた解除は、それ自体が加害である。

### 第4条: 「かかっているか分からない」時は止める。
足関節はグリップと角度で成否が決まるため、初心者同士では判断がつかないことがある。
**分からない＝止める。**

### 第5条: 疲労時・試合直前・体格差が大きい時は足関節の攻防をしない。
判断力が落ちている時に最も事故が起きる。

### 第6条: 相手の防御レベルを確認してから入る。
初心者に対してヒールフックを狙うのは、練習ではなく事故の生成である。

## 4. 【段階3】攻撃 — 解禁条件を満たしてから

### 4.1 解禁条件（全て満たすこと）

- [ ] 防御技術3つが**反射レベル**で出る
- [ ] ポジショナルスパーで、アシガラミに入られてから**80%以上抜ける**
- [ ] 練習相手全員が上記6条のプロトコルを共有している
- [ ] **「ゆっくり極める」ができる**（自分がクランクしないと確信できる）
- [ ] 自分の大会ルールで、ヒールフックが合法な区分を正確に把握している

### 4.2 攻撃の学習順序

```
ステップ1: ポジション（アシガラミ）の支配
   ↓  ここに練習時間の 60%
ステップ2: 相手の防御に対する対応（抜かれない）
   ↓  ここに 25%
ステップ3: 踵の露出（heel exposure）
   ↓  10%
ステップ4: ブレイクメカニクス（極め）
        5%  ← 最後。ここは一番簡単で、一番危険
```

**この配分が守れない人は、まだ攻撃を練習してはいけない。**
「極め方」から入ると、支配できていない状態で急激に極めることになり、必ず相手を壊す。

### 4.3 アシガラミ（脚の絡み方）の分類

| 名称 | 別称 | ニーライン | 主な狙い |
|:---|:---|:---|:---|
| **アウトサイド・アシガラミ** | シングルレッグX (SLX) | 越えない | アウトサイド・ヒールフック、スイープ |
| **インサイド・サドル** | ハニーホール、411、インサイド・アシ | **越える** | **インサイド・ヒールフック**（最も強力） |
| **50-50** | — | 越える | 相互に取り合う（＝相互に危険） |
| **アウトサイド・アシ（クロスアシ）** | — | 状況次第 | アウトサイド・ヒールフック |
| **ハーフガード系のエントリー** | — | — | サドルへの移行 |

**MMA的注意**: **50-50 は打撃有りルールでは避ける。**
相互に足関節を取り合う状態だが、**上体の自由度は上にいる側にあることが多く、
一方的に殴られる**危険がある。純グラップリングとは価値が違う。【C】

### 4.4 エントリー（入口）

```
上から:   パスの途中で相手が脚を戻した → その脚を追ってサドルへ
下から:   オープンガード／デラヒーバ／Xガード → 相手の脚の下へ潜る
スクランブル: 相手が立とうとした瞬間の脚
テイクダウン後: 倒した相手が脚を絡めてきた → 逆に取り返す
```

### 4.5 極めの力学（最後に学ぶ）

```
インサイド・ヒールフック
  1. 相手の膝を自分の腿で挟んで【大腿を固定】する ← これが8割
  2. 踵を掴み、前腕を足首の下に通す
  3. 相手の【膝を固定したまま】、脛骨を内旋させる
  4. 自分の上体を後方に倒して回旋を作る（腕で回さない）
```

**重要**: **1 の「大腿の固定」ができていなければ、いくら踵を捻っても極まらない。**
逆に言えば、固定ができていない状態で強引に捻ると、**相手の膝ではなく足首や自分の姿勢が壊れる**か、
**予測不能な角度で膝に負荷がかかる**。ここが最も事故の多い箇所。

## 5. その他の足関節技

| 技 | 対象 | 危険度 | 備考 |
|:---|:---|:---|:---|
| **ストレート・アンクルロック（アキレス腱固め）** | 足首・アキレス腱 | 中 | 入門用として最適。痛覚のフィードバックが機能する |
| **トーホールド** | 足首（回旋） | 中〜高 | ADCC中級区分でも合法なことが多い |
| **膝十字（ニーバー）** | 膝（伸展） | 中 | サンボの主力。痛覚が機能しやすい |
| **カーフスライサー** | 膝・腓腹筋 | 中 | 圧迫系。ゆっくり |
| **ヒールフック（内／外）** | 膝（回旋） | **最高** | この章の主題 |

**学習順序の推奨**: アンクルロック → 膝十字 → トーホールド → ヒールフック。【C】
理由: 痛覚フィードバックが機能する技から順に慣れ、
**「タップされる感覚」と「タップする感覚」の較正を先に済ませる**ため。

## 6. MMAルール下での特殊事情

### 6.1 足関節に入る＝殴られるリスクを買う

```
脚を取りに行く動作 = 自分の頭が相手の足元へ行く
  → 相手が上に立っていれば、パウンドの角度がある
  → 相手が脚を抜いて上を取れば、そのままトップポジション
```

**帰結**: MMAでは、**足関節は「取れる時に取る」ものであって、「狙って入る」ものではない**ことが多い。【C】
狙って入るなら、**相手が既に不安定な瞬間**（スクランブル、立ち際、パスの失敗直後）に限る。

### 6.2 逆に、あなたが得るもの

- **相手のパスガードを止める**カードになる（脚を取られるのが怖いと、相手は前に出られない）
- **下から積極的に脅威を作れる**（純MMAでは下は不利だが、この脅威があると相手が慎重になる）
- **テイクダウン後の相手の追撃を止められる**

つまり、**攻撃力そのものより「抑止力」としての価値が大きい**。

### 6.3 テイクダウン直後の反射

**倒した瞬間に、自分の脚の位置を確認する。**
テイクダウン成功の高揚で前に出た瞬間、下からサドルに入られるのが典型的な事故パターン。
[04章 §6](../2_やる/07_組み技.md) と対で覚える。

## 7. 練習ドリル

| # | ドリル | 内容 | 頻度 |
|:--|:---|:---|:---|
| 1 | **防御サバイバル** | アシガラミに入られた状態から開始。抜けたら成功。30秒×10本 | **毎回** |
| 2 | **ニーライン認識** | パートナーがランダムに脚を絡む。ニーラインを越えたら声を出す | 週2 |
| 3 | **踵隠し反復** | 掴まれる前に足首を折る動作を反復 | 毎回 |
| 4 | **ポジション支配（攻撃側）** | サドルを維持するだけ。**極めない**。60秒 | 段階3〜 |
| 5 | **スローモーション極め** | 極めの動作を通常の1/4速度で。相手はいつでもタップ可 | 段階3〜 |
| 6 | **50-50 脱出** | 50-50から、極めずに抜ける／有利側に回る | 段階3〜 |

**ドリル1は、段階に関係なく永久に続ける。** 防御は消耗する技術。

## 9. この章の弱点（正直に書く）

1. **前向き研究がない。** 根拠となる疫学は横断研究1本で、信頼区間が広い（RR 12.0, 95%CI 1.5–96.1）
2. **グラップリング特化の生体力学的計測が乏しい。**
   「内旋がACL、外旋がPLC」という記述は解剖学からの演繹＋臨床解説の一致であり、
   実測データに基づくものではない【B】
3. **MMAルール下でのレッグロック統計がほぼ存在しない。**
   本章の MMA 特有の記述は大半が【C】（現場のコンセンサス）
4. **「12倍」を過度に恐れる必要もない。** 絶対リスクは 26.5/1000試合 = 約2.7%/試合。
   ゼロではないが、正しい防御技術とプロトコルで下げられる余地が大きい（原著の推奨もそこにある）【A】
