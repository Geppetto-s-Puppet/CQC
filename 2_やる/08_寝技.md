# 08. 寝技 — 位置の序列、脱出、パス、極め

> **核心**: グラウンドは「技のカタログ」ではなく **「位置の序列を上がるゲーム」** である。
> BJJが競技として、米陸軍MACPがドクトリンとして、
> **独立に同じ結論（Gain Dominant Position が Finish に先行する）** に到達している。【A】

---

## 1. ポジショナル・ヒエラルキー（再掲・詳細版）

```
┌ +5 バックコントロール（シートベルト＋両フック / ボディトライアングル）
│    自分: RNC・パウンド・全て可 ／ 相手: ほぼ何も届かない
│
├ +4 マウント
│    自分: パウンド・腕十字・アメリカーナ ／ 相手: 脱出のみ
│
├ +3 ニーオンベリー
│    自分: 移動自由・打撃可 ／ 相手: 苦しい。ただし自分の安定性は低い
│
├ +2 サイドコントロール（ケサ／ノースサウス含む）
│    自分: 肘・膝・キムラ・ダース ／ 相手: フレームで守る
│
├ +1 ハーフガード（上）
│    自分: パスの一歩手前 ／ 相手: 下から返す余地がある
│
├  0 ニュートラル（スタンド／オープンガード同士／50-50）
│
├ −1 クローズドガード（下）  MMAでは実質 −2 に近い
├ −2 ハーフガード（下）      MMAでは危険度が高い
├ −3 サイド下
├ −4 マウント下
└ −5 バックを取られた
```

### 1.1 ルール別の価値変動（重要）

| ポジション | 純グラップリング | **打撃有り（あなたのルール）** |
|:---|:---|:---|
| バックコントロール | 最強 | **最強（不変）** |
| マウント | 強い | **さらに強い**（パウンド） |
| サイド | 強い | 強い（肘・膝が入る） |
| クローズドガード（下） | 有力な攻撃拠点 | **大幅に価値低下**。長居は被弾 |
| ハーフガード（下） | ほぼ五分 | **危険**（頭を制されて肘） |
| 50-50 | 五分 | **不利**（相手にだけ打撃の角度がある場合が多い） |
| タートル | 消極的だが安全 | **ルール次第で最も危険**（膝・サッカーボールキックの可否を確認） |

**唯一、あらゆるルールで最強のまま**なのがバックコントロール。
UFC全サブミッションの約39%がRNCという統計【B】と整合する。
**→ 学習投資の最優先はここ。**

## 2. 下からのエスケープ（段階1 の主戦場）

### 2.1 フレームの原理

**フレームとは、骨で相手の体重を支える構造のこと。**
筋力で押すのではなく、**前腕・脛骨を突っ張り棒として使う**。

- 良いフレーム: 肘が体幹の近く、手首はまっすぐ、**関節がロックされている**
- 悪いフレーム: 腕が伸びきる（腕十字・キムラの餌）、手で押す（力が続かない）

**なぜ重要か**: フレームがなければスペースが作れず、スペースがなければ動けない。
**エスケープの全ては「スペース → 移動」の2工程**であり、フレームは第1工程を担う。

### 2.2 エスケープの型

| ポジション | 第1手 | 第2手 |
|:---|:---|:---|
| **マウント下** | 両手フレーム、肘を膝に近づける | エルボーエスケープ（膝を通す）or ブリッジ&ロール |
| **サイド下** | 首と腰にフレーム、体を横向きに | 膝を入れる → ハーフ → ガードリカバリー |
| **ノースサウス下** | 腕で顔を押す、体を横に | 回転してガードへ |
| **ケサ固め下** | 相手の腰に近い腕を抜く | ブリッジ or 足で相手の頭を挟む |
| **バックを取られた** | **両手で首を守る**（最優先） | 相手のフックを外す → 肩を床へ落とす → 下から抜ける |
| **タートル** | 肘を膝に、頭を上げる | 立つ or ガードに戻す。**留まらない** |

### 2.3 バックディフェンスの詳細（最重要）

```
警報レベル1: 相手が背後を取った、フックはまだ
  → 即座に片側へ倒れて、肩を床につける（相手が上に来るのを防ぐ）
警報レベル2: フックが入った
  → 両手で顎の下を防御。首に前腕を通させない
警報レベル3: 前腕が首に入った（まだ組んでいない）
  → 両手でその腕を掴み、顎を引く。相手の反対の手が組む前に処理
警報レベル4: 完全に組まれた（RNC成立）
  → **タップ。** ここから逃げる技術は存在しないと思っていい
```

**練習の重み付け**: レベル2と3に練習時間の大半を使う。
レベル4は「そこに行かない」ための警告であって、練習対象ではない。【C】

## 3. ガード（下からの攻防）

### 3.1 MMAにおけるガードの再評価

**純グラップリングとの最大の差: 下は殴られる。**

```
MMAでのガードの目的（優先順）
1. 立つ            ← 第一選択。距離をリセットする
2. スイープする     ← 上を取る
3. バックを取る     ← ガードを経由して背後へ
4. サブミッション   ← 三角・腕十字・オモプラータ
5. 守る            ← 消極的だが必要な場面はある
```

**「下から攻める」は、純グラップリングでは有効だが、MMAでは基本的に不利な選択。**
下にいる時間そのものがダメージの蓄積になる。【C】

### 3.2 ガードの種類と使い分け

| ガード | MMA適性 | 用途 |
|:---|:---|:---|
| **クローズドガード** | 低〜中 | 一時的な安全地帯。呼吸を整えて立つ／崩す |
| **バタフライガード** | 中 | スイープ。相手を浮かせる |
| **ハーフガード（アンダーフック有り）** | 中〜高 | 起き上がる、バックを取る |
| **ディープハーフ** | 低（MMA） | 頭が下がる＝殴られる |
| **オープン／シッティング** | 高 | 立つ、足関節に入る、距離を作る |
| **デラヒーバ／Xガード系** | 中（ノーギ・足関節ルールで高） | 足関節への入口として機能する |
| **ラバーガード等の高柔軟系** | 低 | 再現性が低い。推奨しない |

### 3.3 スイープの原理

**スイープ = 相手の支持基底面（ベース）の外へ、相手の重心を出す。**
```
1. 相手のベースを崩す（片手／片脚を無効化する）
2. 相手の重心を崩れた方向へ動かす
3. 自分の体をその下から回す
```
「力で返す」のではなく「相手が支えられない方向を作る」。

## 4. パスガード（上からの攻防）

### 4.1 3系統

| 系統 | 原理 | 代表技 | MMA適性 |
|:---|:---|:---|:---|
| **プレッシャー** | 体重で潰し、脚を殺してから通す | ニースライス、スマッシュパス、オーバーアンダー | **高** |
| **スピード／トルク** | 相手の脚を捌いて回り込む | トレアンド、ロングステップ、ナックルパス | 中（下から蹴られる／立たれる） |
| **レッグウィーブ／ボディロック** | 相手の脚・腰を固定して動きを封じる | ボディロックパス | **最高**（MMAで特に強力） |

### 4.2 MMAでのパスの原則

**原則1: 腰を離さない。**
腰が離れると (a) 下から蹴られる (b) 相手が立てる (c) **足関節に入られる**。
ヒールフック有りのルールでは (c) が致命的。

**原則2: 打撃を「パスの道具」として使う。**
下の相手が防御に手を使えば、脚のコントロールが緩む。
**殴る → 相手が守る → 通る** という因果を作る。

**原則3: 通す前に「脚のライン」を確認する。**
自分の脚が相手のアシガラミに入る位置にないかを常に確認。
特に**片膝立ちで前に出る**動作は、そのまま脚を取られる形。→ [06章](../2_やる/09_足関節.md)

## 5. ポジションキープ

| ポジション | キープの要点 |
|:---|:---|
| **サイド** | **胸で相手の胸を制する**。腕で押さえない。頭側と腰側の両方をブロック |
| **マウント** | 膝を相手の脇へ。手をつかない。**低いマウント**（腰を落とす）と**高いマウント**（腕を殺す）の切替 |
| **バック** | シートベルト（片手が肩越し、片手が脇下）＋ 両フック or ボディトライアングル。**相手が向いた側に体を回し続ける** |
| **ハーフ（上）** | クロスフェイス＋アンダーフック。相手の頭を自分から遠ざける |

**共通原則: 相手が動く方向に、先に自分の体重を置く。**
静止して押さえ込もうとすると、必ず力負けする。

## 6. サブミッション

### 6.1 チョーク（絞技）— 最優先

| 技 | 種別 | 入口 |
|:---|:---|:---|
| **リアネイキッドチョーク (RNC)** | 血管絞め | バックコントロール |
| **ギロチン** | アームイン=血管系 / ハイエルボー=気道混在 | タックル迎撃、フロントヘッドロック |
| **三角絞め** | 血管絞め | クローズド／オープンガード、マウント下からの反撃 |
| **ダース / アナコンダ** | 血管絞め | フロントヘッドロック、スプロール後 |
| **ノースサウスチョーク** | 血管絞め | ノースサウス、サイド |
| **アームトライアングル（片羽絞）** | 血管絞め | マウント、サイド |

**血管絞め (strangle) と 気道絞め (choke) の区別は必須知識。**
- **血管絞め**: 頸動脈を圧迫。数秒で意識が落ちる。**痛みが少ない**
- **気道絞め**: 気管を圧迫。**苦しくて痛い、時間がかかる、喉頭損傷のリスクがある**
- 競技では血管絞めを狙う。気道絞めは効率が悪く、危険度は高い

**生理学**【A】
- 絞め適用時、内頸動脈系の血流は**80〜90%低下**
- 失神時のEEGは**前頭優位の2–3Hz高振幅徐波**、痙攣を伴うことがある
- **血流が回復すれば通常12秒以内に覚醒**
- 柔道家の研究では、**絞めによる恒久的CNS機能変化の証拠は認められていない**
- **前提は「即座の解除」**。詳細と安全プロトコル: [10章](../1_読む/03_壊れる仕組み.md)

### 6.2 RNCの分解（練習の重み付け）

```
(1) バックを取る            … 段階2 の範囲
(2) バックを維持する        … シートベルト／ボディトライアングル
(3) 相手の防御手を剥がす   … ここが本体。練習時間の40%
(4) 首に前腕を通す         … 顎を越える。練習時間の40%
(5) 締める                  … 胸を張り肩甲骨を寄せる。腕力ではない。10%
```
**(3)(4) に8割の時間を使う。** 初心者は (5) ばかり練習して入らない。

### 6.3 関節技

| 技 | 対象 | 備考 |
|:---|:---|:---|
| **腕十字** | 肘 | MMAでは「決め」より**バックへの移行**として価値が高いことが多い【C】 |
| **キムラ** | 肩（内旋） | 支配技としても優秀。移動の起点になる |
| **アメリカーナ** | 肩（外旋） | マウント／サイドから |
| **オモプラータ** | 肩 | 極めにくいが、スイープ・移動として強い |
| **腕がらみ／V1** | 肩 | バックコントロールから |
| **足関節全般** | 膝・足首 | → [06章](../2_やる/09_足関節.md) |

## 7. スクランブル（局面の反転）

**上でも下でもない、位置が確定していない状態。**
ここでの勝敗が試合を決めることが多いのに、最も練習されていない領域。

**原則**:
1. **先に手をつけた方が負ける**（ベースを取られる）
2. **背中を向けない**（バックを渡す）
3. **相手の腰を追う**（頭ではなく腰。腰が向いている方向が相手の逃げ道）
4. **迷ったら立つ**（MMAでは、位置が不明ならスタンドに戻すのが安全）

**練習法**: 「スクランブルスパー」— 両者が中間位置から始めて、
位置が確定したら（サイド以上を取ったら）止めてリセット。10〜20秒×多数回。

## 8. チェックリスト

### 段階1
- [ ] フレームを骨で作れる（腕が伸びきらない）
- [ ] マウント下・サイド下から5分で1回以上脱出
- [ ] バックを取られて60秒、首に前腕を入れさせない
- [ ] スタンドアップ・イン・ベースが安全にできる

### 段階2
- [ ] パスガード3系統をそれぞれ1回は通せる
- [ ] サイド／マウントを60秒キープ
- [ ] クローズドガードから3手以内に立つ／スイープ／バックへ移行
- [ ] スクランブルで背中を向けない

### 段階3
- [ ] バックからRNCを、防御手を剥がす工程込みで成立させる
- [ ] 腕十字・三角・ギロチンをセットアップから成立させる
- [ ] 血管絞めと気道絞めを意識的に打ち分けられる
- [ ] 極めた瞬間に即解除できる（タップに対する反応が0.5秒以内）
