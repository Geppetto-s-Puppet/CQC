# 11. 判断フロー

> **これは読み物ではない。引くものである。**
> 通して読もうとすると必ず挫折するし、読んでも身につかない。
>
> **使い方**
> 週にひとつだけ行を選び、その週のスパーではその「第1選択」だけを意識して使う。
> 通ったか通らなかったかを記録し、通らなかった理由を書く。翌週、次の行へ進む。
> 全部で60行ほどあるので、週1行なら1年で一周する。一周したら自分のデータで書き換える。

**この章の構成**

- **A編（A-1〜A-7）— 対応表.** 「こう来たらこう返す」を局面別に並べたもの
- **B編（B-1〜B-12）— フローチャート.** 判断の分岐を図にしたもの

迷ったときのデフォルトは **A-7** と **B-12** にまとめてある。**まずそこだけ覚えるといい。**

表では、各行のいちばん左の選択肢が第1選択（＝迷ったらこれ）である。
図のなかの ★ も同じく「迷ったらこれ」を指している。

## A-1. スタンド — 打撃への対応

| 相手が来る技 | 第1選択 | 第2選択 | 第3選択 | 禁じ手 |
|:---|:---|:---|:---|:---|
| **ジャブ** | 距離を切る（後ろに下がらず**横へ**） | パリー → 同時に自分のジャブ | スリップ → ボディ | 下がりながら受ける（連打を貰う） |
| **ストレート／オーバーハンド** | スリップ or ダック → **タックル** | パリー → カウンターのストレート | 距離を外す | 腕でブロックして止まる |
| **フック** | シェル（腕でカバー）→ 内側へ入る | ダック → クリンチ | 距離を切る | 後ろに引く（追撃を貰う） |
| **アッパー** | 距離を取る（下がる／離れる） | 前腕でブロック | クリンチ | 頭を下げる（真芯に入る） |
| **ローキック（腿・カーフ）** | チェック（脛で受ける） | 距離を切る（前に詰める） | **キャッチ → テイクダウン** | 立ったまま受け続ける |
| **ミドルキック** | 前腕＋膝でブロック | **キャッチ → テイクダウン** | 距離を切る（前に詰める） | 後ろに逃げる（回転力の最大点で受ける） |
| **ハイキック** | 両腕でシェル＋頭を離す | 距離を切る（前に詰める） | ダック → タックル | 片手だけで受ける |
| **前蹴り／ティープ** | 横にずれる（サイドステップ） | 手で払う（パリー） | 前に詰めてクリンチ | 真後ろに下がる |
| **膝（クリンチ内）** | 腰を引き、フレームで距離を作る | 相手の腰を制する（ボディロック） | 離れる | 上体だけ引く |
| **肘** | 距離を切る（密着 or 離脱）※中距離が最も危険 | 頭の位置を変える | クリンチ | 中距離で止まる |
| **フェイント（見せ技）** | **反応しない**。体幹の重心移動だけを見る | 自分から距離を変える | 先に手を出して主導権を取る | 手先・顔を見て反応する |

**共通原則**:
- 相手の**四肢ではなく胸〜肩の中心**を見る（visual pivot）。予測情報は体幹の動きにある【A】
- **下がりながら受ける**のは最悪。横に外す（アングル）か、前に詰める
- ブロックは最終手段。防御の質は脳の寿命に直結する【A】→ [10章](../1_読む/03_壊れる仕組み.md)

## A-2. スタンド — 組みへの対応

| 相手が来る技 | 第1選択 | 第2選択 | 第3選択 |
|:---|:---|:---|:---|
| **ダブルレッグ（正面）** | スプロール → クロスフェイス | 距離を切って入らせない（事前） | フロントヘッドロック → ダース／ギロチン |
| **シングルレッグ** | 取られた脚を**後ろに引きながら**ウィザー | 相手の頭を押して角度を潰す | 壁／ロープに逃げて脚を抜く |
| **タックルのフェイント** | 反応しない（腰を落としすぎない） | 前手で頭を止める | 自分から先にレベルチェンジ |
| **クリンチに入られる** | **アンダーフックを1本取る** | 前腕で相手の首・鎖骨をフレーム | 角度を切って離れる |
| **首相撲（プラム）を取られた** | 手を**内側から**上げて外す＋腰を引く | 相手の肘を持ち上げる | **タックルに入る**（首相撲は下がガラ空き） |
| **ボディロック（両アンダー）を取られた** | 腰を落として重心を下げる＋相手の腰を引き離す | ウィザーを1本入れる | 壁を背にしない位置へ移動 |
| **背後を取られた（立ち）** | **手を組ませない**（自分の手で相手の手をブロック） | 腰を落とし、相手の重心を下へ | 壁を使って回る／向き直る |

**共通原則**:
- 「倒されない」より「**倒されても即立つ**」【C】
- テイクダウン防御の目標は、相手のTD成功率を**25%未満**に抑えること【A】

## A-3. グラウンド — 下からの対応

| 状況 | 第1選択 | 第2選択 | 第3選択 | 絶対にしない |
|:---|:---|:---|:---|:---|
| **クローズドガード（自分が下）** | **立つ**（MMAでは最優先） | スイープ | バックへ回る／三角・腕十字 | 長居する |
| **ハーフガード（下）** | **アンダーフックを取って起きる** | 深く入ってスイープ | ガードに戻す | 頭を下げたまま留まる |
| **サイド（下）** | フレーム（首＋腰）→ 膝を入れる | ブリッジして横向きに | 背中を向けずに立つ | 相手を押し返そうとする |
| **ノースサウス（下）** | 腕で顔を押して首を外す | 体を横に回してガードへ | ブリッジ | 仰向けで固まる |
| **マウント（下）** | エルボーエスケープ（膝を通す） | ブリッジ&ロール（アップア） | ハーフに戻す | 両手で押し上げる（腕十字の餌） |
| **バックを取られた（フック有）** | **両手で顎の下を防御** → 片側に倒れて肩を床に | 相手のフックを外す | 相手の腕を掴んで首から外す | 前に逃げる（RNCが深くなる） |
| **RNCが完成した** | **タップ** | — | — | 我慢する（失神＋反復リスク） |
| **タートル（自分が下）** | 立つ or ガードに戻す（**即座に**） | 相手の腕を取って前転 | 壁に押し付けて立つ | 留まる（膝・肘・バックを貰う） |
| **パウンドを浴びている** | 相手の**上腕を抱えて**距離を殺す（クローズド／ボディロック） | 腰を動かして角度を変える | 脚を絡めて立つ | 顔だけ守って動かない |

## A-4. グラウンド — 上からの対応

| 状況 | 第1選択 | 第2選択 | 第3選択 |
|:---|:---|:---|:---|
| **相手がクローズドガードで引き込んだ** | **姿勢を立てる**（ポスチャー）→ 開かせる | 打撃で開かせる | 立ち上がって離脱（ルール上有利なら） |
| **相手がオープンガードで脚を出してくる** | **脚をコントロール**してから前へ（腰を離さない） | 打撃で手を使わせる | **ニーライン確認** → [06章](../2_やる/09_足関節.md) |
| **相手がデラヒーバ／Xガードに入った** | 足関節の警報。**踵を隠す**＋膝の線をクリア | 相手の脚を切る（脚を抜く） | 立って離脱 |
| **相手がタートルになった** | バックのフックを入れる or シートベルト | 前に回してパス | ルール上合法なら膝／打撃 |
| **相手がスイープを狙っている** | 重心を下げ、崩れる方向に手足を出す（ベース） | 相手の腰を制する | 一旦立つ |
| **相手が立とうとしている** | 腰を制して立たせない | 立たせて打撃で迎える | バックを取る |

## A-5. 足関節への対応（このルール特有・最重要）

| 相手の動き | 第1選択 | 第2選択 | 判断 |
|:---|:---|:---|:---|
| **脚を絡めてきた（Lv.1）** | 踵を隠す（足首を内に折る） | 股関節を抜く／脚を引き戻す | まだ余裕あり |
| **ニーラインを越えられた（Lv.2）** | **踵を絶対に露出させない** | 相手の膝の内側へ回る（クリア・ザ・ニーライン） | **声を出して警戒宣言** |
| **踵を掴まれた（Lv.3）** | 相手のグリップを両手で剥がす | 即座に膝の線をクリア | **抜けないと判断したらタップ準備** |
| **グリップ完成＋相手が回り始めた（Lv.4）** | **即タップ** | — | 痛みを待たない |
| **50-50 になった** | MMAなら**抜けて上を取る**（相互に危険＋殴られる） | 自分が先に取る（純グラップリングなら） | ルールで判断が変わる |
| **アキレス腱固め／トーホールド** | 足首を回して圧を逃がす → 相手の膝の内側へ | ローリング／向きを合わせて逃げる | 痛覚が機能するので判断しやすい |
| **膝十字** | 脚を曲げて伸展を防ぐ → 相手の上に乗る | 回転して抜く | 早めに動く |

**反射として入れるべきこと**
```
1. 相手の脚が自分の膝の線を越えた瞬間 → 「入られた」と声に出す
2. 踵が露出しそうになったら → 足首を内に折る（考える前に）
3. テイクダウンを決めた直後 → 自分の脚の位置を確認する
```

## A-6. 相手タイプ別のゲームプラン

### A-6.1 ストライカー型（打撃が強い、組みが弱い）
```
狙い: ミッドレンジに滞在させない。組みに持ち込む
第1手: ローキックで前足を潰す → 相手の踏み込みを鈍らせる
第2手: レベルチェンジのフェイントを混ぜ、打撃の反応を遅らせる
第3手: 壁／ケージに押し込んでボディロック → テイクダウン
避ける: ミッドレンジでの打ち合い、下がりながらの防御
```

### A-6.2 レスラー型（テイクダウンが強い）
```
狙い: 組ませない。組まれても即立つ
第1手: 距離管理。ティープ／前蹴りで入口を潰す
第2手: 相手のレベルチェンジに対し、頭を上げてアンダーフック
第3手: 倒されたら即立つ（ワンダウン・ワンアップ）
       or ★ 脚を絡めて足関節の脅威を作る（このルールなら有効）
避ける: 壁を背にする、正対して下がる
```

### A-6.3 グラップラー型（寝技が強い、引き込む）
```
狙い: 下に付き合わない。立たせるか、上を維持する
第1手: 引き込みには付き合わず、立ったまま打撃／離れる
第2手: 上を取ったら腰を離さない（離すと足関節・スイープ）
第3手: ニーラインを常に確認。脚を差し出さない
避ける: ガードの中で長居、腰を高くしたパス
```

### A-6.4 プレッシャー型（前に出続ける）
```
狙い: 前進を止める、または利用する
第1手: 前蹴り／ティープで距離を止める（オブリークキックも）
第2手: 横に外す（下がらない）。円を描いて角度を作る
第3手: 前進の力を利用したカウンター、または引き込みでのテイクダウン
避ける: 直線的な後退（コーナーに詰まる）
```

### A-6.5 カウンター型（待って合わせる）
```
狙い: 相手に先に動かせる
第1手: フェイントを多用し、反応を引き出す
第2手: リズムを変える（速→遅→速）
第3手: 組みで主導権を握る（カウンターは打撃の技術に依存する）
避ける: 単発の大振り、リズムの固定化
```

## A-7. 局面遷移のデフォルト（迷った時の答え）

**格闘中、脳の処理が追いつかない瞬間は必ず来る。その時のデフォルト行動を決めておく。**

| 局面 | 迷った時のデフォルト |
|:---|:---|
| スタンドで距離が分からない | **横に動く**（下がらない、止まらない） |
| クリンチで劣勢 | **アンダーフックを1本取りに行く** |
| 倒された直後 | **立つ** |
| ガードの中（下） | **立つ** |
| ガードの中（上） | **腰を落として姿勢を立てる**（前に出ない） |
| スクランブル | **相手の腰を追う。背中を向けない** |
| 位置が不明なグラウンド | **一旦立つ**（MMAではスタンドが最も安全） |
| 足関節の攻防で不明 | **踵を隠す＋動きを止める** |
| 息が上がった | **クリンチする**（打ち合いは絶対にしない） |
| 相手が何をしてくるか読めない | **プレッシャーをかけて先に動かせる**（[原理11](../1_読む/01_この競技の構造.md)） |

                                │
        ┌───────────────┼───────────────┐
        │               │               │
    離れている       組んでいる        寝ている
        │               │               │
        ▼               ▼               ▼
     B-2 立ち技      B-3 クリンチ    B-5(上) / B-6(下)
        │               │               │
        └───────────────┴───────────────┘
                                │
                     【常に並行して確認する3つ】
                                │

## B-12. 1枚まとめ（印刷用）

```
╔══════════════════════════════════════════════════════════╗
║  迷ったときのデフォルト行動                                ║
╠══════════════════════════════════════════════════════════╣
║  距離が分からない        → 横に動く（真後ろに下がらない）  ║
║  クリンチで劣勢          → アンダーフックを1本取る         ║
║  倒された直後            → 立つ                            ║
║  ガードの中（下）        → 立つ                            ║
║  ガードの中（上）        → 腰を落として姿勢を立てる        ║
║  スクランブル            → 相手の腰を追う／背を向けない    ║
║  位置が不明なグラウンド  → 一旦立つ                        ║
║  足関節が不明            → 踵を隠す＋止まる                ║
║  息が上がった            → クリンチする（打ち合わない）    ║
║  相手が読めない          → 前に出て先に動かせる            ║
╠══════════════════════════════════════════════════════════╣
║  常時確認する3つ                                          ║
║   1. 呼吸しているか                                       ║
║   2. 顎は引けているか                                     ║
║   3. 脚は安全か（ニーライン）                             ║
╠══════════════════════════════════════════════════════════╣
║  即タップする条件（痛みを待たない）                        ║
║   ・ヒールフックの形が完成した                            ║
║   ・RNCの腕が完全に組まれた                               ║
║   ・関節が可動域の端に達した                              ║
╠══════════════════════════════════════════════════════════╣
║  即座に練習を止める条件                                    ║
║   ・頭部の症状が1つでもある                               ║
║   ・関節から「ポップ」音がした                            ║
║   ・首の痛み＋手足のしびれ                                ║
╚══════════════════════════════════════════════════════════╝
```
