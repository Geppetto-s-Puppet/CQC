# 10. 用語と技の辞典

> **この章の目的**: 「知らない単語が出てきて話が進まない」を無くす。
> 技の名前は**同じものに3〜4個の呼び名がある**のが普通。それは体系が3〜4個混ざっているから。
> ここで一度、全部を1枚に並べる。

---

## 0. まず、なぜ用語が分からないのか

MMAの用語は **5つの言語圏が混ざっている**。だから同じ技に複数の名前がある。

| 出自 | 言語 | 例 |
|:---|:---|:---|
| **柔道・日本武術** | 日本語 | 大外刈、裸絞、腕挫十字固 |
| **BJJ（ブラジル）** | ポルトガル語 | Mata-leão、Raspagem、Montada |
| **レスリング（米）** | 英語 | Double leg、Sprawl、Whizzer |
| **ムエタイ（タイ）** | タイ語 | ティープ、ソーク、カオ |
| **ボクシング（英米）** | 英語 | ジャブ、フック、スリップ |

**例: 同じ技の4つの名前**
```
「相手の背後から首を腕で絞める技」
  柔道      : 裸絞（はだかじめ）
  BJJ       : Mata-leão（マタレオン／"獅子殺し"）
  英語      : Rear Naked Choke（RNC）
  日本の現場 : リアネイキッドチョーク、スリーパー
  → 全部同じもの
```

**対処法**: 分からない単語が出たら、**「それは何をする技か（動詞）」を聞く**。
名前は後から一致させればいい。この章の表はそのためにある。

## 1. 身体部位の辞典

### 1.1 「当てる側」の部位 — 何で打つか

| 呼び方 | 解剖名 | どこか | 使う技 | 注意 |
|:---|:---|:---|:---|:---|
| **拳頭（けんとう）** | 第2・第3中手骨頭 | 人差し指と中指の付け根の関節 | パンチ全般 | **ここ以外で当てると骨折する**（小指側で当てる＝ボクサー骨折） |
| **前腕** | 尺骨・橈骨 | 肘〜手首 | ブロック、フレーム、絞め | 骨で受ける／支える |
| **肘先** | 肘頭（ちゅうとう） | 肘の尖った骨 | 肘打ち | 人体で最も硬い打点の1つ |
| **脛（すね）** | **脛骨（けいこつ）** | すねの内側の太い骨 | 蹴り全般、チェック | **足の甲ではなく脛骨で当てる**。甲は折れる |
| **足の甲** | 中足骨 | 足の上面 | ハイキック（顔面）のみ | 硬い部位に当てると折れる |
| **膝** | 膝蓋骨〜大腿骨遠位 | 膝の皿とその上 | 膝蹴り | 皿で当てない。少し上で当てる |
| **足底／踵** | 踵骨・足底 | かかと・足裏 | 前蹴り、ティープ、オブリーク | 押す蹴りに使う |
| **手刀** | 尺骨側の手の側面 | 小指側の側面 | ※MMAでは使用機会が少ない | — |
| **頭（額）** | 前頭骨 | おでこ | ※バッティング＝反則 | **禁止** |

### 1.2 「当てられる側」の部位 — 何を狙うか

詳細は[13章](../1_読む/02_効く仕組み.md)。ここは名前の対応のみ。

| 通称 | 解剖名 | 位置 | 効果の種類 |
|:---|:---|:---|:---|
| **顎先（あごさき）** | 下顎骨のオトガイ部 | 顎の先端 | 回転加速度 → 意識消失 |
| **下顎角（かがくかく）** | 下顎角 | 顎のエラの部分 | 同上。フックの標的 |
| **こめかみ** | 側頭部 | 目尻と耳の間 | 平衡感覚の喪失 |
| **レバー** | **肝臓**（第9〜10肋骨下） | 右の肋骨の下端 | 自律神経反射 |
| **みぞおち** | **腹腔神経叢**（celiac plexus） | 胸骨の下、へその上 | 横隔膜痙攣 → 呼吸不能 |
| **フローティングリブ** | 第11・12肋骨（浮遊肋） | 脇腹の下のほう | 骨折・激痛 |
| **カーフ** | **総腓骨神経**（腓骨頭のすぐ下） | ふくらはぎの外側、膝の少し下 | 神経痛 → 下垂足 |
| **腿（もも）外側** | 外側広筋 | 太ももの外側 | 筋の累積損傷 |
| **腿内側** | 内転筋群 | 太ももの内側 | 同上。より痛い |
| **首（絞めの標的）** | **総頸動脈／内頸動脈** | 首の左右、顎の下 | 脳血流低下 → 意識消失 |
| **喉** | 気管・喉頭 | 首の正面中央 | **禁止標的** |

**覚えるべき最小セット（初心者はまずこの5つ）**
```
1. 顎先        … 効く。守るときは「顎を引く」
2. レバー      … 効く。守るときは「肘を締める」
3. みぞおち    … 効く。守るときは「腹を締める」
4. カーフ      … 効く。守るときは「脛でチェック」
5. 頸動脈      … 絞めの標的。守るときは「顎を引いて手で塞ぐ」
```

## 3. 動作の基本語彙（動詞）

| 用語 | 意味 |
|:---|:---|
| **フレーム** | 前腕や脛の**骨**を突っ張り棒にして、相手との間にスペースを作る |
| **ポスチャー** | 姿勢を立てること（背を伸ばし、頭を上げる） |
| **ベース** | 倒れないための支え。手足の接地面 |
| **レベルチェンジ** | 腰の高さを上下に変えること |
| **シュリンプ／エビ** | 横向きになって**腰を後ろへ逃がす**基本移動 |
| **ブリッジ** | 仰向けから**腰を持ち上げる**（橋を作る） |
| **スイープ** | 下から相手を**ひっくり返して上を取る** |
| **パス（パスガード）** | 相手の脚（ガード）を**通過して**サイド以上を取る |
| **エスケープ** | 不利な位置から**脱出**する |
| **リカバリー** | ガードなど、**元の状態に戻す** |
| **トランジション** | 局面から局面への**移行** |
| **スプロール** | タックルに対して**腰を落とし脚を後ろへ飛ばす**防御 |
| **ペンメル** | アンダーフックを**交互に取り合う**組み手の反復動作 |
| **ハンドファイト** | 手・腕の**支配権を争う**こと |
| **タップ** | 参ったの合図。**叩く／声を出す** |
| **リーピング** | 相手の膝の外側を**脚で跨いで回旋負荷をかける**危険な配置 |
| **ニーライン** | **膝の線**。相手の脚がこれを越えたかどうかが足関節の危険度を決める |

## 4. 技の全カタログ

**表の読み方**
- **段階** = [02章ロードマップ](../2_やる/05_ロードマップ.md)の習得段階（0〜5）
- **** = そのカテゴリで最優先の技

### 4.1 パンチ

| 名前 | 別名 | どんな動きか | 何で当てる／どこに | 段階|
|:---|:---|:---|:---|:--:|
| **ジャブ** | 前手の突き / Jab | 前の手を**まっすぐ伸ばして戻す**。最速・最軽量 | 拳頭 → 顔面・胸 | 1 |
| **ストレート／クロス** | Cross / 後ろ手の突き | 後ろの手を**腰の回転と共に**まっすぐ | 拳頭 → 顎先 | 1 |
| **フック** | Hook | 肘を曲げたまま**横から円を描いて**打つ | 拳頭 → 下顎角・こめかみ・レバー | 2 |
| **アッパー** | Uppercut | 下から**突き上げる** | 拳頭 → 顎の下・みぞおち | 2 |
| **オーバーハンド** | Overhand | 上から**弧を描いて**被せる | 拳頭 → 側頭部 | 3 |
| **ボディブロー** | Body shot | 胴体への打撃の総称 | 拳頭 → レバー・みぞおち | 2 |
| **バックフィスト** | 裏拳 | 手の甲側で振り抜く | 拳の甲側 → 側頭部 | 4 |
| **スーパーマンパンチ** | — | 蹴るフェイントから飛び込んで打つ | 拳頭 → 顔面 | 4 |

| 名前 | 別名 | どんな動きか | 何で／どこに | 段階|

| **ロー（腿）** | Low kick / 下段回し蹴り | 同上、標的が腿 | 脛骨 → 外側広筋 | 2 |
| **ミドルキック** | 中段回し蹴り / Body kick | 腰を回して**胴を蹴る** | 脛骨 → 肋骨・レバー | 2 |
| **ハイキック** | 上段回し蹴り | 同上、標的が頭 | 脛骨・足の甲 → 側頭部 | 3 |

| **オブリークキック** | — | 相手の**膝／腿の前面**を踏みつけるように押す | 足底 → 大腿前面 | 3 |
| **フロントキック（突き上げ）** | Front snap kick | 前方へ**跳ね上げる** | 足底・つま先 → 顎・腹 | 3 |
| **サイドキック** | 横蹴り | 横向きに押し出す | 足底 → 胴・膝 | 4 |
| **回転系（後ろ回し等）** | Spinning kick | 背を向けて回転して蹴る | 踵・脛 → 頭・胴 | 5 |

**注意**: 回転系は[13章 §1.2](../1_読む/02_効く仕組み.md)の通り、**回転加速度が最も高い技群**。
効果が大きい反面、外した時のリスク（背中を向ける＝バックを取られる）も最大。段階5 の技。

## 8. 分からない用語に出会ったときの手順

```
1. 「それは立ち技か、寝技か、組みか」を聞く      → カテゴリが決まる
2. 「それは位置か、技か、動作か」を聞く           → §2 / §4 / §3 のどれか
3. 「何をする（動詞）ものか」を聞く               → 名前より本質
4. この章の表で検索する                          → 別名が見つかる
5. 見つからなければ、13章・7章の索引を見る
6. それでも無ければ、その場でメモして後で調べる    → 練習を止めない
```

**重要**: **用語が分からないことを恥じない。** 5言語圏が混ざっている以上、
**全部知っている人は存在しない**。指導者も知らない別名がある。
「それって〇〇と同じですか？」と聞くのが最短。
