# 12. 困ったときの索引 — 「決まらない」の原因を引く

> **使い方**: 症状から引く。
> **原因は「頻度順」に並べてある。上から順に潰す。**
> 「筋力が足りない」を原因にするのは**最後**。ほとんどの場合、それは原因ではない。

---

## A. 首（RNC）が決まらない — 「もっと強くしてください」と言われる

### A-0. まず、この症状が意味していること

```
相手が「もっと強く」と言える  =  相手は【喋れている】
                              =  気道も頸動脈も圧迫されていない
                              =  あなたの腕は「どこにも乗っていない」
```

**重要な切り分け**:
- **気道（気管）に乗っている** → 相手は咳き込む・むせる・「痛い」と言う。**「もっと強く」とは言わない**
- **頸動脈に乗っている** → **数秒で効く**。相手は何も言う暇がない
- **どちらにも乗っていない** → **「もっと強くしてください」** ← あなたはここ

> **結論: これは筋力不足ではない。配置の問題である。**
> しかも**あなたは前腕が長い**（[16章 §2](../4_あなた/14_現在地と方針.md)）。
> 長い前腕はRNCにおいて**有利**な要素であり、決まらない理由になりえない。

### A-1. 原因チェックリスト（頻度順）

| # | 原因 | 確認方法 | 修正 |
|:--:|:---|:---|:---|
| **1** | **前腕が顎を越えていない**（下顎骨の上に乗っている） | 相手に「今どこに当たってる？」と聞く。「顎」と言われたらこれ | 顎を越える工程を先に作る（A-2） |
| **2** | **肘の谷（肘窩）が正中にない** | 相手の顎の真下の中心に、自分の肘の折れ目が来ているか | 肘窩を相手の**気管の正面**に合わせる。ここが軸 |
| **3** | **胸が相手の背中から離れている** | 自分の胸と相手の背中の間に隙間があるか | **密着させる**。隙間があると腕だけの力になる |
| **4** | **腕で引いている** | 締めるとき、腕がプルプルしているか | 腕ではなく**胸を張って肩甲骨を寄せる**。背中で締める |
| **5** | **もう一方の手が仕事をしていない** | 逆の手はどこにあるか | 相手の**後頭部を前に押す**（または自分の上腕二頭筋を掴んで固定） |
| **6** | **相手の姿勢を崩していない** | 相手が真っ直ぐ座って顎を引いていないか | **相手を後ろに倒して自分の胸に乗せる**。頸部が伸びて頸動脈が浅くなる |
| **7** | **自分の頭が離れている** | 頭が相手の頭から離れていないか | 自分の頭を相手の**頭の横につける**。顎を引く隙間を消す |

### A-2. 正しい配置（図解）

```
        【上から見た図】

              相手の顔
                 ↑
        ┌────────────────┐
        │   顎（下顎骨）  │  ← ここに乗ったら、何も起きない
        └────────────────┘
        ┌────────────────┐
   頸動脈 ● 気管 ● 頸動脈  │  ← ここを挟む
        └────────────────┘
                 │
            相手の背中


        【あなたの腕の配置】

           前腕 ────┐
                     │ ← 肘窩（肘の折れ目）が【気管の正面】
           上腕 ────┘

        前腕と上腕の「V字」で、左右の頸動脈を挟む
        気管を潰すのではない。気管はV字の【谷】に逃がす
```

**言い換えると**:
> **気管を「押し潰す」のではなく、気管を「避けて」その両脇を挟む。**
> だから正しく入ると相手は**苦しくない**まま落ちる。
> 「苦しい」と言われている時点で、配置が間違っている。

### A-3. 工程の分解 — あなたはどこを練習しているか

[05章 §6.2](../2_やる/08_寝技.md) の再掲:

```
(1) バックを取る                    … 段階2 の範囲
(2) バックを維持する                … シートベルト／ボディトライアングル
(3) 相手の防御手を剥がす           … 練習時間の 40%
(4) 首に前腕を通す（顎を越える）   … 練習時間の 40%
(5) 締める                          … 10%
```

**「もっと強くしてください」と言われている人は、(5) だけを練習している。**
(3)(4) が抜けているので、そもそも締める対象の上に腕が乗っていない。

**顎を越えるための具体的な手段（(4)の中身）**
```
・相手の顎の下に、手のひらではなく【手刀（小指側の側面）】を滑り込ませる
・相手の顔を横に向けさせてから、空いた側から通す
・相手の防御している手首を、もう一方の手で剥がしてから通す
・相手を後ろに倒して、顎が上がった瞬間に通す
・肩で相手の顎を押し上げる
```

### A-4. 診断ドリル（次の練習で必ずやる）

```
【フィードバック・ドリル】所要5分

1. パートナーに座ってもらう（抵抗なし）
2. あなたがRNCの形を作る
3. パートナーは【3択】で答える:
      ① 「気管に当たってる」（苦しい・痛い）  → 配置が中央すぎ。V字を作る
      ② 「顎に乗ってる」（何も感じない）      → 浅い。顎を越える
      ③ 「効いてる」（すーっとする）          → 正解。即座に外す
4. ③ が出るまで、位置を1cmずつ動かして探す
5. ③ の位置を身体で覚える

これを片側5回ずつ。抵抗のある相手でやる前に、まず「正解の位置」を知る
③ が出た瞬間に必ず外す。落とさない（[10章 §3](../1_読む/03_壊れる仕組み.md)）
```

**このドリルを1回やるだけで、「もっと強く」は消える可能性が高い。**

### A-5. 検証

- [ ] パートナーが「効いてる」と言う位置を再現できる
- [ ] 締めるとき腕がプルプルしない（背中で締めている）
- [ ] 抵抗のある相手に対して、顎を越える工程を実行できる
- [ ] **「もっと強く」と言われなくなった**

## B. 腕十字が決まらない

| # | 原因 | 修正 |
|:--:|:---|:---|
| 1 | 相手の腕が曲がっている | **伸ばす工程が別技術**。相手の手首を両手で持ち、自分の胸に引きつけてから倒れる |
| 2 | 相手の親指が下を向いていない | 相手の**親指を天井に**向ける（肘の弱い方向に合わせる） |
| 3 | 膝が締まっていない | 両膝で相手の腕を挟む。隙間があると抜かれる |
| 4 | 尻が相手の肩から離れている | 自分の股関節を相手の**脇の下に密着**させる。ここが支点 |
| 5 | 腕の力で反らせている | **股関節を突き上げる**。腕は固定するだけ |

**あなた向けの注記**: [16章 §2.2](../4_あなた/14_現在地と方針.md) の通り、**あなたは腕十字を「極めやすく、極められやすい」**。
攻めるときは相手の前腕長がレバーになるので有利。**守るときは自分の前腕が長い分、不利**。
→ **肘を曲げて手を自分に引き寄せる防御を、反射で出せるようにする。**

## C. 三角絞が決まらない

| # | 原因 | 修正 |
|:--:|:---|:---|
| 1 | 角度がない | 相手の腕を引いて、**自分の体を横にずらす**（真正面では極まらない） |
| 2 | 膝裏に足首が入っていない | 足首を膝裏の**奥**まで。浅いと外れる |
| 3 | 相手の姿勢が立っている | **頭を下げさせる**（腕を引く、頭を押す） |
| 4 | 相手の肩が抜けている | 相手の**片腕を中に、片腕を外に**。両腕とも中／外だと極まらない |
| 5 | 締めていない | 膝を寄せる＋腹筋で相手の頭を引きつける |

**あなた向け**: **長い脚は三角絞の最大の武器**。これはあなたのAゲームに入れるべき技（[16章](../4_あなた/14_現在地と方針.md)）。

## D. ギロチンが決まらない

| # | 原因 | 修正 |
|:--:|:---|:---|
| 1 | 相手の頭だけ抱えている | **首の付け根**まで深く。頭を抱えても何も起きない |
| 2 | 相手の腕が抜けている | **アームイン**（相手の片腕ごと）か**ハイエルボー**（腕を外す）か、どちらか決める |
| 3 | 上体が起きていない | 胸を張って**上に伸び上がる**。丸まると圧が逃げる |
| 4 | 相手が体を回して逃げている | 相手の**回る方向を、自分の脚でブロック**する |

## E. テイクダウンが入らない

| # | 原因 | 修正 |
|:--:|:---|:---|
| **1** | **セットアップがない**（いきなり入っている） | ジャブ／ロー／レベルチェンジのフェイントで**反応を作ってから**入る |
| 2 | レベルチェンジで背中が丸まる | 股関節と膝で落ちる。**背中は真っ直ぐ**。頭が下がるとギロチン |
| 3 | 距離が遠い | 入る前に**一歩詰める**。届かない距離から入ると潰される |
| 4 | 頭の位置が正面 | 頭は相手の**体側**へ。正面はギロチンの餌 |
| 5 | 入った後の駆動がない | 掴んで終わりではない。**入ってから足を動かし続ける** |

**あなた向け**: 腰の位置が高い＝レベルチェンジの移動距離が長い（[16章 §2.3](../4_あなた/14_現在地と方針.md)）。
**入りが遅くなる構造的不利があるので、セットアップへの依存度が人より高い。**
「速さで入る」を諦め、「相手を動かしてから入る」に振り切る。

## F. パスガードが通らない

| # | 原因 | 修正 |
|:--:|:---|:---|
| 1 | 相手の脚を制していない | **足首・膝・腰のどれかを固定**してから動く。フリーな脚は必ず戻る |
| 2 | 腰が高い | 腰を落とす。腰が浮くと（a）蹴られる（b）立たれる（c）**足関節に入られる** |
| 3 | 急いでいる | パスは**位置を1段ずつ上げる**作業。一気に通そうとすると戻される |
| 4 | 上体だけで通そうとしている | 脚（自分のベース）を動かす。上体だけでは通らない |

**あなた向け（ヒールフックありルール）**: 腰を離した瞬間が最も危ない。
[15章 §7](../3_引く/11_判断フロー.md)のフローを常に並行して回す。

## G. スイープが返らない

| # | 原因 | 修正 |
|:--:|:---|:---|
| 1 | 相手のベース（支え）を消していない | 返す方向の**手か脚を、先に無効化**する |
| 2 | 相手の重心を動かしていない | 崩し（引く／押す）が先。返しは後 |
| 3 | 力で返そうとしている | 相手が**支えられない方向**を作る。力比べは体重差で負ける |
| 4 | 自分の体が下に潜っていない | 相手の下に自分の体を入れる。横からでは返らない |

## H. 打撃が当たらない

| # | 原因 | 修正 |
|:--:|:---|:---|
| **1** | **距離を測っていない** | ジャブを「当てる」ためでなく「測る」ために打つ（[03章 §1](../2_やる/06_立ち技.md)） |
| 2 | 単発で打っている | 2〜4発の連鎖。1発目は当てるためではない |
| 3 | 相手の四肢を見ている | **胸〜肩の中心**を見る（visual pivot）【A】 |
| 4 | 同じリズムで打っている | 速→遅→速。リズムを変える |
| 5 | 角度を作っていない | 打つ前後に**45度動く**（[12章](../2_やる/06_立ち技.md)） |

## J. 拳が痛い

### J-0. まず — あなたの当て方は「正しい」

> 「拳の中指と人差し指あたりを殴ってた」

**これは正解。** 人差し指・中指の付け根 = **第2・第3中手骨頭**。
[14章 §1.1](../3_引く/10_用語と技の辞典.md) の通り、**ここ以外で当てると骨折する**。
小指側（第5中手骨）で当てるのが**ボクサー骨折**の典型機序。
あなたは正しい部位で当てている。

### J-1. それでも痛い場合

| # | 原因 | 修正 |
|:--:|:---|:---|
| **1** | **量が多すぎる**（初心者の皮膚・骨膜が適応していない） | **バッグの量を減らす**。強度ではなく本数を落とす |
| 2 | バンテージを巻いていない | 必ず巻く。中手骨と手首を保護する |
| 3 | **手首が折れている**（背屈・掌屈している） | 前腕〜拳頭が**一直線**。手首が曲がると衝撃が手首に集中 |
| 4 | 握りが緩い | インパクトの瞬間だけ握り込む。常時握ると疲れる |
| 5 | 押している | 当てて**引く**。押し込むと関節に長く負荷がかかる |

### J-2. 受診すべきサイン
```
・腫れが引かない、変形している
・握れない、物が持てない
・押すと一点に鋭い痛み（骨折の疑い）
→ 整形外科へ。中手骨骨折は放置すると変形が残る
```

## K. ヒールフック関連

### K-1. 極まらない（攻め）
| # | 原因 | 修正 |
|:--:|:---|:---|
| **1** | **相手の大腿を固定していない** | これが8割。膝を自分の腿で挟む。固定なしに捻っても極まらない |
| 2 | 踵が露出していない | 相手が足首を折って隠している。先に踵を出す工程が要る |
| 3 | 腕で回している | **上体を後方に倒して**回旋を作る。腕ではない |
| 4 | ニーラインを越えていない | サドル／インサイドアシガラミに入り直す |

**絶対にやらないこと**: 「決まらないから強く捻る」。
これが[06章](../2_やる/09_足関節.md)の **RR 12.0** を生む行動そのもの。
**極まらないのは配置の問題であり、力の問題ではない**（RNCと同じ構造）。

### K-2. 防御できない（守り）
| # | 原因 | 修正 |
|:--:|:---|:---|
| **1** | **気づくのが遅い** | ニーラインを越えられた瞬間に**声を出す**（[15章 §7](../3_引く/11_判断フロー.md)） |
| 2 | 踵を隠していない | 足首を内に折る動作を、考える前に出るまで反復 |
| 3 | 抜こうとして暴れる | 暴れると回旋が加速する。**止まって踵を隠す**が先 |

**あなた向け**: 脛骨が長い＝相手のレバーが長い（[16章 §2.2](../4_あなた/14_現在地と方針.md)）。
**あなたは平均より早くタップする必要がある。** これは弱さではなく、物理である。

## L. クリンチで押し負ける

| # | 原因 | 修正 |
|:--:|:---|:---|
| **1** | **押し合いに応じている** | 体重差があるなら**押し合わない**。角度を作って外す |
| 2 | アンダーフックがない | ペンメルで1本取る。差し手のない組みは全部不利 |
| 3 | 腰が高い | 腰を落とす。重心が高いと押される（[16章](../4_あなた/14_現在地と方針.md)） |
| 4 | 壁を背にしている | 壁際に入る前に角度を変える |

**あなた向け**: 55.3kgで相手が60kgなら、**押し勝つのは物理的に無理**。
「勝つ」ではなく「**切る**」を練習する（[16章 §4.3](../4_あなた/14_現在地と方針.md) Bゲーム）。

## M. 汎用診断 — 原因が分からないとき

```
        【技が決まらない】
                │
                ▼
    ①【位置は正しいか？】 ← 9割ここ
        │
      NO → 位置の練習に戻る（技の練習をやめる）
        │
       YES
        ▼
    ②【工程が抜けていないか？】
        （決め技の直前の「準備」をやっているか）
        │
      NO → 準備工程だけを単独で練習する
        │
       YES
        ▼
    ③【力で解決しようとしていないか？】
        （プルプルしていたら、それは間違い）
        │
      YES → 骨・体重・レバーで解決する方法を探す
        │
       NO
        ▼
    ④【タイミングか？】
        （相手が反応する前に入れているか）
        │
        ▼
    ⑤ ここまで来て初めて「筋力」を疑う
```

> **「筋力が足りない」を原因にするのは最後。**
> 首が決まらない、腕十字が決まらない、パスが通らない — **その9割は配置と工程の問題**であり、
> 筋力を上げても直らない。

## N. この章の弱点

1. 本章の原因リストは**現場のコンセンサス**【C】であり、系統的に検証されたものではない
2. 「頻度順」は経験的な並びで、統計的根拠はない
3. 個別の身体特性（体格差、可動域、既往）で優先順位は変わる
4. **指導者に直接見てもらうのが常に最良**。この章は補助であって代替ではない
