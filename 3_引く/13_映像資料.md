# 13. 映像資料 — 動きを見るための動画と画像

> **使い方の原則**: 動画は「技を覚える」ためではなく **「動きの質を見る」** ために使う。
> 技の手順は文章で足りる。動画でしか得られないのは **タイミング・重心・接触の圧・呼吸** である。

---

## 0. 動画から学ぶときのルール

| # | ルール | 理由 |
|:--|:---|:---|
| 1 | **1本につき1つの観察点だけ決めて見る** | 全部見ようとすると何も見えない |
| 2 | **0.25〜0.5倍速で、同じ箇所を5回見る** | 通常速度では重心移動が見えない |
| 3 | **技そのものより「技の3秒前」を見る** | 成否は入る前に決まっている（[04章](../2_やる/07_組み技.md)） |
| 4 | **「できる人の動画」と「自分の動画」を並べる** | 差分を見ないと修正点が分からない |
| 5 | **インストラクショナルは、練習で試すまで次を見ない** | 見るだけでは何も身につかない |
| 6 | **試合映像 > 教則映像** | 抵抗する相手に対して何が起きるかは、試合にしか写っていない |

**観察点の例**（1本につき1つ選ぶ）
```
・足の位置（どちらの足が先に動いたか）
・頭の高さ（いつ下がって、いつ上がったか）
・グリップ（どこを、いつ掴んだか、いつ離したか）
・重心（前後どちらに乗っているか）
・呼吸（吐いているタイミング）
・視線（どこを見ているか）
```

## 2. 解剖・医学の画像（[06章](../2_やる/09_足関節.md) [10章](../1_読む/03_壊れる仕組み.md) の理解用）

| 対象 | 資料 | リンク |
|:---|:---|:---|
| **膝の靱帯（ACL）** | StatPearls（NCBI, 無料・査読済み教科書）。図あり | [NBK559233](https://www.ncbi.nlm.nih.gov/books/NBK559233/) |
| **膝の靱帯（PCL）** | 同上 | [NBK535416](https://www.ncbi.nlm.nih.gov/books/NBK535416/) |
| **膝靱帯の全体像** | Cleveland Clinic の患者向け解説（図が分かりやすい） | [my.clevelandclinic.org](https://my.clevelandclinic.org/health/body/21596-knee-ligaments) |
| **頸動脈の走行** | 「carotid artery anatomy」で Wikimedia Commons を検索。パブリックドメイン画像が多数 | commons.wikimedia.org |

**見るべきポイント**:
- **ACL と PCL が交差している**構造を立体的に理解する → なぜ回旋に弱いかが分かる
- **後外側支持機構（LCL・膝窩筋腱・膝窩腓骨靱帯）**の位置 → アウトサイドヒールフックが何を壊すか
- **総頸動脈の分岐（内頸/外頸）の高さ** → 血管絞めがどこを押さえているか

## 3. 段階別の推奨映像

| 主題 | 推奨リソース | 観察点 |
|:---|:---|:---|
| **受け身** | 「柔道 受け身」で講道館・全日本柔道連盟系のチャンネルを検索 | 顎を引くタイミング、腕を叩く角度、頭の位置 |
| **エスケープ全般** | **Stephan Kesting（Grapplearts）** — YouTube に無料の体系的な解説が大量にある | フレームの作り方、股関節の移動 |
| **BJJ入門の全体像** | [Grapplearts "Roadmap for BJJ"](https://www.grapplearts.com/) — 無料の入門教材あり | ポジションの序列がどう説明されているか |

  → **初心者〜中級で最も費用対効果が高い無料リソースの1つ**。概念の説明が丁寧

### 段階1〜2（打撃の基礎）

| 主題 | 推奨リソース | 観察点 |
|:---|:---|:---|
| **ムエタイの動きの質** | **Muay Thai Library**（Sylvie von Duuglas-Ittu / 8limbsus） — タイの伝説的選手・トレーナーのセッションを長尺で記録した映像アーカイブ。有料（月$5〜） | 力を抜いた状態からの加速、体重移動、蹴りの「戻り」 |
| **ボクシングの防御** | 試合映像を0.25倍速で。教則より試合 | 頭の軌道、足の位置、打った後の移動 |

- Muay Thai Library: [patreon.com/sylviemuay](https://www.patreon.com/sylviemuay) / 解説記事 [8limbsus.com](https://8limbsus.com/patreon-supporter-content/greatest-single-thai-technique-internet-resource-muay-thai-library)
  → **タイの「本物の動き」を見るなら、現状これが最良のアーカイブ**。
    技を覚えるためでなく、**脱力と体重移動の質を見る**ために使う

### 段階2（テイクダウン・組み）

| 主題 | 推奨リソース | 観察点 |
|:---|:---|:---|
| **レスリング** | NCAA/オリンピックの試合映像。「wrestling folkstyle highlights」「freestyle wrestling」 | ハンドファイトの量、入る前の頭の位置 |
| **柔道** | IJF（国際柔道連盟）公式の試合映像。技名で検索できる | 組手争い、崩しのタイミング |
| **講道館の技名索引** | [Kodokan Global 技一覧](https://kdkjd.org/%E6%8A%80/) | 技名と分類の照合用 |

**重要**: レスリング・柔道の試合映像を見るときは、**技が決まった瞬間ではなく、
その前の20秒のハンドファイト**を見ること。そこが本体。

## 4. 自分の動画を撮る（最も重要な映像資料）

**他人の動画100本より、自分の動画1本のほうが上達に効く。**【C】

### 撮り方
```
・週1回、スパーを1〜2ラウンド撮る
・カメラは腰の高さ、コート全体が入る位置に固定（三脚 or 壁）
・スマホで十分。画質より「毎週続くこと」が重要
```

### 見方（[08章 §8.2](../1_読む/04_うまくなる仕組み.md) と同じ）
```
1. 「やられた場面」だけを見る（通った場面は見なくていい）
2. やられた3秒前に戻す
3. 位置 → 姿勢 → タイミング の順に原因を問う
4. 月に1回、頻度を集計する
5. 上位3つだけを、その月の課題にする
```

### 記録フォーマット
```
日付 / 相手（体格・スタイル）/ ラウンド数
[通ったこと]   技名 × 回数
[やられたこと] 技名 × 回数、どの局面か
[原因の仮説]   位置 / 姿勢 / タイミング / 体力 / 判断
[次回試すこと] 1つだけ
```

## 5. 見るべきでないもの

| 避けるもの | 理由 |
|:---|:---|
| **「秘伝」「一撃必殺」「達人」系** | 抵抗する相手に対する検証がない。[01章 §6.1](../1_読む/01_この競技の構造.md) の検証困難性そのもの |
| **協力的な相手にしか掛からない技のデモ** | 相手が抵抗した瞬間に成立しない |
| **ストリートファイト動画** | 学習素材としての情報が少なく（画質・角度・文脈）、消費されるだけ |
| **「〇〇 vs △△、どっちが強い？」系** | 議論であって技術ではない |
| **技を大量に紹介するだけの動画** | 選択肢が増えるほど実戦での判断が遅くなる（[07章](../3_引く/11_判断フロー.md)） |

**判定基準**: **「相手が全力で抵抗している映像か？」** これ一つで9割ふるいにかけられる。

## 6. 検索クエリ集（自分で探すとき）

リンクは切れるので、**検索の仕方**を残しておく。

```
【技術】
  "<技名> defense"                 例: "heel hook defense"
  "<技名> details" / "<技名> concepts"
  "<技名> against resisting opponent"
  "positional sparring <ポジション名>"

【分析】
  "<選手名> breakdown"
  "<選手名> game study"
  "how <選手名> passes guard"

【一次資料】
  "TC 3-25.150 pdf" / "MCRP 3-02B pdf"
  "<競技団体> rules pdf <年>"       例: "ADCC rules pdf 2026"

【研究】
  site:pubmed.ncbi.nlm.nih.gov <キーワード>
  site:pmc.ncbi.nlm.nih.gov <キーワード>
  "<キーワード> systematic review"

【日本語】
  "講道館 <技名>"
  "自衛隊 徒手格闘"
  "日本拳法 <技名>"
```

## 7. リンクの健全性について（正直な注記）

- 本章のリンクは **2026年8月時点で検索結果から確認したもの**。
  YouTube の個別動画・チャンネルURLは削除・変更されうる
- **チャンネル名のみで記載しているもの**（Gracie Breakdown, BJJ Scout, Fight Tips 等）は、
  URLを断定せず名前で示している。**検索して、登録者数と投稿履歴を確認してから**視聴すること
- **有料リソース**（Muay Thai Library, SUBMETA, BJJ Fanatics 等）は、
  その旨を明記した。無料で足りる段階（段階0〜2）では無理に買わなくてよい
- **一次資料（軍教範PDF、StatPearls、PubMed）が最も長持ちする。** 迷ったらそこへ戻る
