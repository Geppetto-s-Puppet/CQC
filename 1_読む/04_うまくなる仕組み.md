# 04. うまくなる仕組み

> **この章が答えること** — どんな練習が身につき、どんな練習が無駄になるのか。
> **読了の目安** — 25分
>
> **要約**
> 技術の質は「何を練習したか」より「どう練習したか」で決まる。そしてこの領域は、格闘技のなかで最も査読研究が使える。
> 練習設計を縛る条件は3つある。頭部への累積曝露を最小にすること、習得の局面と定着の局面を分けること、実戦の情報構造を保つこと。
> この3つを同時に満たす練習形態がひとつだけある。局面を限定したスパーリングである。

---

## 1. 練習設計を縛る3つの条件

やみくもにメニューを組む前に、守らなければならない制約を確認しておく。

**第一に、頭部への累積曝露を最小にすること。**
[03_壊れる仕組み](03_壊れる仕組み.md) で見たとおり、累積の曝露量と競技年数が
視床・尾状核の容積低下と処理速度の低下に関連する。【A】
これは不可逆なので、最優先の制約になる。

**第二に、習得の局面と、定着・転移の局面を区別すること。**
新しい動きを覚えているときと、覚えた動きを試合で出せるようにするときでは、
効果的な練習法が違う。それどころか**逆になる**。【A】

**第三に、実戦の情報構造を保つこと。**
相手が抵抗しない状況で練習した技は、抵抗する相手には出ない。
これは制約主導アプローチと呼ばれる考え方の中心にあり、
制約を操作した訓練の研究では**77.7%が技能習得に肯定的な効果**を示している。【A】

---

## 2. 練習には階層がある

練習の形式を、実戦からの距離で並べると次のようになる。

```
 Lv.1  分解ドリル        相手は動かない。動作パターンを作る
 Lv.2  反復ドリル        相手は決まった反応をする
 Lv.3  反応ドリル        相手が2〜3択でランダムに反応する
 Lv.4  ポジショナルスパー 局面を限定した全力の攻防
 Lv.5  限定スパー        技術に制約をつける（打撃なし、ジャブのみ等）
 Lv.6  フルスパー        試合と同じ条件
```

このうち **Lv.4「ポジショナルスパー」に練習量を寄せるべき**である。理由が3つある。

**頭部のリスクを上げずに強度を上げられる。**
グラウンドやクリンチの局面限定スパーは、頭部への打撃を伴わずに全力を出せる。
実際、[02_効く仕組み](02_効く仕組み.md) の数値では、
柔道とレスリングの回転加速度は276〜2,434 rad/s²で、脳振盪の閾値4,500を一貫して下回っている。
打撃は3,000〜11,000である。**1桁の差**があるので、
制約1（頭部曝露の最小化）と制約3（実戦の情報構造）を同時に満たせる唯一の形態になる。

**失敗の回数が多い。**
30秒×20本なら、意思決定の機会が20回ある。5分×2本より学習の密度が高い。

**相手が全力で抵抗する。**
知覚と行動の結びつきが実戦と同じ形になる。これが制約3を満たすということである。

### ポジショナルスパーの組み方

```
例1  バックコントロール   攻：極める ／ 守：逃げる      45秒 → 交代
例2  マウント             攻：維持   ／ 守：脱出        45秒 → 交代
例3  アシガラミ           攻：支配のみ ／ 守：抜ける    30秒 → 交代
例4  クリンチ             攻：倒す   ／ 守：防ぐ        30秒 → 交代
例5  スクランブル         中間位置から。位置が確定したらリセット  15秒
例6  ガード（下）＋軽い打撃  下：立つ ／ 上：抑える      60秒
```

組むときのコツは3つある。**時間を短く、本数を多く**（30〜60秒を10〜20本）。
**役割を固定する**（攻めと守りを分ける。両方やろうとすると学習が薄まる）。
**勝利条件をひとつに絞る**（「極める」ではなく「バックを維持する」のように）。

## 3. 固めてやるか、混ぜるか

同じ技を連続で50回やるのと、5つの技を順不同で10回ずつやるのとでは、どちらが身につくのか。

これは運動学習の分野で**文脈干渉効果**として長く研究されてきたテーマで、
結論は直感に反する。

**ランダムに混ぜると、練習中のできは悪くなる。しかし後日のテストと、別の状況への転移では優れる。**【A】

つまり、練習の場での上達感と、実際に身についているかどうかは一致しない。
固めて練習すると気持ちよく上達するが、それは定着していない可能性がある。

ただし、ここには重要な但し書きがある。
転移に対する効果量は中程度（SMD 0.55）だが、その内訳を見ると
**実験室では0.75、応用的なスポーツ場面では0.34で統計的に有意ではない**。【D】
さらに『スポーツ実践における文脈干渉の利益という神話』と題した2023年のメタ分析は、
応用場面での効果に否定的である。【D】

だから実務上の結論は、どちらか一方に振り切るのではなく、**局面で使い分ける**ことになる。

| 局面 | 使う方法 |
|:---|:---|
| 新しい動作を初めて覚える／フォームを直す／疲れている | **固めて練習する**。同じ動作を連続で反復し、まず形を作る |
| 形ができた後の定着／実戦への転移を狙う | **ランダムに混ぜる**。複数の技を順不同で、相手の反応もランダムに |

目安としては、新しい技術は固めて1〜2セッション、以降は混ぜていく。【B】
固めたまま何ヶ月も続けると、「練習では出るが試合では出ない技」になる。

## 4. 教えるのではなく、制約を変える

「こう動け」と口で説明するかわりに、**課題の条件を変えることで、望ましい動きが自然に出てくるようにする**。
これが制約主導アプローチと呼ばれる方法である。

制約には3種類ある。身長や筋力や疲労といった個体の制約。マットや壁の有無といった環境の制約。
そしてルールや目標や時間といった**課題の制約**で、操作するのはこれである。

具体例を挙げる。

| 引き出したい行動 | 課す制約 |
|:---|:---|
| ジャブを使わせたい | 「前手だけ有効」でスパー |
| 前に出させたい | 「後退禁止」 |
| アンダーフックを取らせたい | 「アンダーフックを取ったら1点」 |
| フレームを使わせたい | 「相手を掴んではいけない」 |
| 下から立たせたい | 「立ったら勝ち」でガードスパー |
| 足関節の防御を鍛えたい | 「攻撃側は極めてはいけない。支配のみ」 |
| 頭を上げさせたい | 「頭が相手の胸より下がったら負け」 |
| セットアップを作らせたい | 「同じ技を2回連続で使ってはいけない」 |

制約操作を行った研究の**77.7%が技能習得に肯定的な効果**を示している。【A】

利点は、口で説明するより速いことと、**選手が自分で解を見つける**ので転移しやすいことである。
「45度に動け」と言うより、「真後ろに下がったら失点」というルールのほうが速く身につく。

## 5. スパーの強度をどう設計するか

| 強度 | 内容 | 頻度 | 頭部リスク |
|:---|:---|:---|:---|
| 20–30% | フロー。技術の確認。当てない | 毎回 | ほぼゼロ |
| 40–50% | ライト。当てるが効かせない | 週2〜3 | 低 |
| 60–70% | ミディアム。試合に近い判断速度 | 週1 | 中 |
| 80–100% | ハード。試合と同等 | **月1〜2、試合期のみ** | 高 |

### 頭部の曝露をどう管理するか

ここが核心である。[03_壊れる仕組み](03_壊れる仕組み.md) の議論をもう一度整理すると、

- 試合数と競技年数は、脳の容積低下と処理速度の低下に関連する【A】
- 自己申告のスパー回数は、脳容積の低下と有意に関連しなかった【D】
  （ただし、この研究は強度や被弾数を測っていない）

したがって導かれる方針は、

> **スパーのラウンド数を減らすより、1ラウンドあたりの頭部への被弾を減らすほうが根拠に沿う。**【B】

具体的には次のようになる。

ボディだけのスパー（顔面なし）で技術と距離を鍛える。
タッチスパー（当てる強度を最小に）でタイミングを鍛える。
片方は打たない防御専用のラウンドを作る。
ハードスパーは試合期に集中させ、オフには入れない。
そして**ヘッドギアを過信しない** — 脳の回転加速度は防げないので、
着けたから強度を上げてよいという発想は逆効果になる。【B】

## 6. 試合のリズムを再現する

[01_この競技の構造](01_この競技の構造.md) で述べたとおり、
MMAの試合は高強度と低強度がおよそ 1:2 から 1:4 の比で交互に現れる。【A】
模擬スパーの研究でも、高強度と低強度の比は1:2、努力と休止の比は1:3だった。【A】

つまり「5分間ずっと全力」は試合を再現していない。再現するなら、

```
  15秒 全力（爆発）→ 45秒 中強度（支配・回復）を 5セット ＝ 5分
  これを3ラウンド
```

のような構造になる。詳細は [15_からだを作る](../4_あなた/15_からだを作る.md) と連動する。

## 7. 見る力を鍛える

熟練者と非熟練者の差は、反応の正確さと速さの両方で大きい（27の研究、233のデータセット）。【A】
そして [02_効く仕組み](02_効く仕組み.md) で見たとおり、
**見えているだけで頭の回転が最大29%減る**【A】ので、これは技術であると同時に安全対策でもある。

| 鍛える対象 | 方法 |
|:---|:---|
| 視線の置き方 | 相手の胸から肩の中心を見る。四肢を目で追わない。動画で自分の視線移動を確認する |
| 体幹からの予測 | 顔を隠した状態での対人ドリル。予測に有効な情報は身体の動きにある【A】 |
| 触覚からの予測 | 目隠しでのポジショナルスパー（グラウンドとクリンチ限定） |
| 反応の抑制 | フェイントに反応しない訓練。「相手の重心が移動したときだけ動く」という制約 |

空手を対象にした実験で、**攻撃者の顔を隠したほうが攻撃の認識と反応が良かった**という結果は示唆的である。【A】
フェイントに引っかかりやすいなら、視線が顔や手先に固定されていないか疑ってみるといい。

## 8. フィードバックと記録

フィードバックは量より質である。毎回すべてを指摘されると、かえって学習が阻害される。
**1セッションにつき修正点はひとつ**にする。
また、動きの善し悪しを教える前に、まず「できたかできなかったか」を自分で判断させるほうがいい。

動画は週1回でいい。見るのは**やられた場面だけ**である。
「なぜやられたか」を、位置 → 姿勢 → タイミング の順に問う。
そして頻度の上位3つだけを、その月の課題にする。

練習日誌は3行でいい。

```
[通ったこと]    例：ボディロックからのテイクダウン ×3
[やられたこと]  例：右のオーバーハンド ×2、サドルに入られた ×1
[次回試すこと]  例：右を打たれる前に横に外す
```

3ヶ月続けると、自分のゲームの形と穴がデータとして見えてくる。【C】

## 9. 週の設計

段階1〜2（週5〜6セッション）の例を挙げる。

| 曜 | 主な内容 | 強度 | 頭部曝露 |
|:--|:---|:--|:--|
| 月 | グラウンド技術（Lv.1–3）＋ポジショナルスパー（Lv.4） | 中 | なし |
| 火 | 打撃技術＋反応ドリル＋ライトスパー40% | 低〜中 | 低 |
| 水 | 筋力＋首＋可動域 | 高 | なし |
| 木 | 組み技・クリンチ・テイクダウン＋ポジショナルスパー | 中〜高 | なし |
| 金 | 休養、または低強度の有酸素 | 低 | なし |
| 土 | 統合スパー（60%）＋足関節の防御ドリル | 中〜高 | 中 |
| 日 | 完全休養 | — | — |

試合期に入ってからも、**試合2週前にはハードスパーを止める**。
直前の負傷と脳の疲労は、試合当日のパフォーマンスに直結する。【C】

## 10. やってはいけない練習

| 悪い練習 | なぜ悪いか | 代わりに |
|:---|:---|:---|
| 毎日フルスパー | 頭部曝露が累積する【A】。学習ではなく消耗 | ポジショナルスパーに置き換える |
| サンドバッグだけで打撃を練習 | 相手が動かないので、距離感と予測が一切鍛えられない | 対人の反応ドリル |
| 同じ技を数ヶ月間ずっと固めて練習 | 試合で出ない技になる【A】 | 1〜2セッション後にランダム化 |
| 効かせ合いのスパー | 学習密度が最低で、リスクが最高 | 強度を落として本数を増やす |
| 防御ができていない相手への足関節 | 事故を生成しているだけ【A】 | 防御ドリルを共同でやる |
| 疲労時の高強度スパー | 判断力の低下がそのまま事故率になる | 技術練習に切り替える |
| 「気持ち」で乗り切る練習 | 測定も改善もできない | 記録を取る |

## この章の弱点

- 文脈干渉効果の応用スポーツにおける再現性は割れている【D】。本章の推奨は暫定である
- 格闘技に特化した制約主導アプローチの研究は少ない。
  根拠の大半は他の対人スポーツからの外挿である【B】
- スパーの強度と長期的な脳への影響を、被弾数を基準に測った研究がない。
  マウスピース型の加速度計を使った研究が出れば、この章は書き換わる
- 知覚トレーニングの転移（実験室から実戦へ）は、まだ十分に実証されていない【D】
