# 02. 効く仕組み

> **この章が答えること** — なぜ技は効くのか。どこを狙い、何と何を組み合わせるのか。
> **読了の目安** — 30分
>
> **要約**
> 効き方は4種類しかない。頭部は回転の加速度で、胴体は神経の反射で、脚は神経と筋の損耗で、関節はてこで壊れる。
> 同じ打撃でも受け手の条件で脳への負荷は5倍変わり、その差の大半は「見えていたかどうか」で決まる。
> だからこの章は、攻撃の設計であると同時に、防御の設計でもある。

> **この章の範囲について**
> 扱うのは、競技のルール内で「なぜその技が効くのか」を医学と物理で説明することである。
> 恒久的な障害を最大化する方法や、禁止されている標的の攻撃法は扱わない。
> 禁止標的については「なぜ禁止なのか」という医学的理由だけを §9 で述べる。

---

## 1. 効き方は4種類しかない

技を名前で覚えていくと際限なく増える。ところが「身体に何をしているのか」で分類すると、4つしかない。

**第一に、回転の加速度で脳を揺らすもの。** 頭蓋が急に回されると、中に浮いている脳がわずかに遅れて動き、
神経の線維がずれる。効果は0.1秒で出る。フック、肘、回し蹴りがこれにあたる。

**第二に、内臓の神経を刺激して反射を起こすもの。** 血圧と心拍が反射的に落ちたり、横隔膜が痙攣したりする。
効果は1〜3秒遅れて出るのが特徴で、打った直後は相手が平気に見える。レバーブローとみぞおちがこれ。

**第三に、末梢の神経や筋を機能停止させるもの。** 神経の圧迫や筋の物理的な損傷で、単純に力が出なくなる。
即効のものと累積するものがある。カーフキックと腿へのローキック。

**第四に、骨や関節を構造として壊すもの。** てこで関節を可動範囲の外へ持っていく。関節技のすべてがこれ。

この4分類が、そのまま戦術の骨格になる。

| 種別 | 決着までの性質 | 自分が負うリスク |
|:---|:---|:---|
| **I. 回転加速度（脳）** | 一発で終わりうる | 同じリスクを自分も負う |
| **II. 自律神経の反射（胴）** | 見た目より確実。効いた相手は立てない | 低い |
| **III. 神経・筋の損耗（脚）** | 累積型。序盤に投資して後半に回収する | 低い |
| **IV. 構造の破壊（関節）** | 相手がタップすれば終わる | 競技では最も安全な決着手段 |

## 2. 頭部 — なぜ「回転」なのか

脳は頭蓋のなかで脳脊髄液に浮いている。だから、まっすぐ押されるよりも、
**回転させられたほうが脳の組織にひずみが生じやすい**。
外傷性脳損傷のリスクを予測する生体力学的な指標として最も強いのは、直線の加速度ではなく回転の加速度である。【A】

これは数値で押さえておく価値がある。格闘技における回転加速度を集めた体系的レビューによれば、
閾値と実測値はおよそ次のようになっている。【A】

**閾値**

| | 回転加速度 |
|:---|---:|
| 脳振盪 | 約 **4,500 rad/s²** |
| びまん性軸索損傷・急性硬膜下血腫 | 約 **10,000 rad/s²** |

**実測（技・競技別）**

| | 回転加速度 |
|:---|---:|
| ボクシング フック | 1,740 – **9,306** |
| ボクシング ストレート | 4,036 |
| ボクシング アッパー | 3,181 |
| **意識消失を起こしたパンチ** | **11,279.5** |
| テコンドー 後ろ回し蹴り | 10,927 |
| テコンドー 突き | 9,556 |
| テコンドー 回し蹴り | 5,908 |
| MMA 全般 | 3,773 – 7,561 |
| **柔道・レスリング** | **276 – 2,434** |

### この表から読み取るべきこと

**組み技の頭部への負荷は、打撃の1桁下である。**
柔道とレスリングが276〜2,434であるのに対し、打撃は3,000から11,000に及ぶ。
[04_うまくなる仕組み](04_うまくなる仕組み.md) で「ポジション限定のスパーリングに練習量を寄せよ」と書いているのは、
根性論ではなくこの1桁の差に基づいている。

**意識が飛ぶ一撃は、重症損傷の閾値域にある。**
意識消失を起こしたパンチの平均値 11,279.5 は、びまん性軸索損傷や硬膜下血腫の閾値である10,000を超えている。
KOは派手な決着ではなく、**重症損傷の閾値を踏んだ事象**である。

**フックの分散が異常に大きい。** 1,740から9,306まで、5倍以上の幅がある。
同じ「フック」でも条件次第で脳への負荷が5倍変わるということで、
この分散の正体こそが次節の主題になる。

**倒れなかった衝撃も、頻繁に閾値を超えていた。**
原著はここを明記していて、**見た目の無事は医学的判断の指標にならない**と述べている。【A】

## 3. 揺れやすい条件 — 分散の正体

回転加速度は、殴る側のパワーだけでは決まらない。**受け手側の条件のほうが支配的**である。

物理としては単純な話で、頭は棒の先についた重りのようなものだと考えればいい。
回転の中心は頸椎にある。トルク（回転させる力）は、加えた力に、回転中心からの距離を掛けたものになる。

```
     頭（重り）
      │
      │  ← てこの長さ（首）
      │
     胴（土台）        回転の中心は頸椎

  トルク ＝ 力 × 回転中心からの距離

  顎の先端と下顎角は、頸椎から最も遠い
  → 同じ力でも最大のトルクが発生する
  → だから顎が狙われる
```

この式から、回転加速度が増える条件が導かれる。

**見えていないとき。** 首の筋肉が事前に収縮できず、頭が「自由な重り」になる。
これは実測されていて、後述のとおり効果が大きい。【A】

**顎が上がっているとき。** 回転中心からの距離が伸び、てこが長くなる。【B】

**接線方向の打撃を受けたとき。** フック、肘、回し蹴りは回転の成分が大きい。上の表のとおりである。【A】

**後退中、あるいは片足に体重が乗っているとき。** 土台である胴が支えを失い、頭だけが加速する。【C】

**疲労しているとき。** 首の筋肉が使えず、姿勢の制御も落ちる。【B】

**首が弱いとき。** 頭の実効的な質量が小さくなり、同じ力でよく回る。【B〜D】

### 「見えている」ことの効果は測られている

接触競技の選手46名（8〜30歳）を対象に、頸部の最大等尺性筋力と、衝撃を予期することの効果を計測した研究がある。
予期できた場合と不意打ちの場合を比べると、次のような差が出た。【A】

| 測定値 | 予期あり vs 不意打ちでの減少率 |
|:---|:---|
| 最大線加速度（矢状面の伸展方向） | −15% |
| 最大線加速度（前額面の側屈方向） | −18% |
| **最大角速度（矢状面の伸展方向）** | **−29%** |
| 最大角速度（前額面の側屈方向） | −23% |

> **見えているだけで、頭の回転が最大29%減る。**

[01_この競技の構造](01_この競技の構造.md) で述べた「反応より予測」と、
「相手の胴の中心を見る（ビジュアル・ピボット）」という知覚技術は、
単なる技術論ではなく**脳を守るための手段**でもある、ということになる。

### 防御への翻訳

この章でいちばん重要なのは、実はここである。

1. **見る。** 相手の胸から肩の中心を見て、打撃を予測する — 角速度が最大29%減る【A】
2. **顎を引く。** てこを短くする【B】
3. **首を締める。** 頭を胴に結びつけ、実効質量を上げる【B】
4. **真後ろに下がらない。** 45度に外して土台を保つ【C】
5. **疲れたら組む。** 首も姿勢も使えない状態で打ち合わない【C】

### 攻撃への翻訳

同じ表を裏から読むと、KOは「強く殴る」より「当たる状況を作る」ほうが決定的だと分かる。

相手が見ていないとき（フェイントで視線を外す、連打の2発目以降、死角からの角度）。
相手の顎が上がっているとき（ボディを打って上体を起こさせる）。
相手が後退しているとき（圧力をかけて下がらせてから当てる）。
そして接線方向の技を選ぶこと。

逆にいえば、**相手が見ていて、顎を引いていて、足が地についているときに強打を狙うのは、
回転加速度の観点で最も効率が悪く、カウンターをもらうリスクだけが高い**。

## 4. 胴体 — 反射で止める

### レバーブロー

肝臓は右の上腹部、第9〜10肋骨の下にある。肋骨弓のすぐ下が最も露出する場所になる。

打撃で肝臓がリブケージに圧迫されると、被膜と周囲の**迷走神経**が過剰に刺激される。【B】
その結果として起きるのが**血管迷走神経反射**で、交感神経の緊張が抜け、副交感神経の出力が増える。
末梢の血管が拡張すると同時に心拍が落ちるので、血圧が下がり、脳への血流が減る。【A】

症状は、激しい痛み、吐き気、めまい、そして脱力である。
**意識はあるのに動けない**というのが特徴で、効いた相手はガードを上げられない。

重要なのは**効果が1〜3秒遅れて出る**ことだ。打った直後に相手が平然としていても効いていることがある。
そして効いた相手は次に上段が空く。

なお、血管迷走神経反射という現象の生理学そのものは【A】だが、
「レバーブローがその反射を介する」という具体的な因果を直接検証した研究は見あたらない【B〜C】。
ただし臨床像（徐脈・低血圧・脳灌流の低下）は反射性失神そのものである。

### みぞおち

みぞおちの正体は**腹腔神経叢**という神経の束で、上腹部の深いところ、腹部大動脈の前、
おおよそ第1腰椎の高さ、横隔膜のすぐ下にある。

ここへの急激な刺激は、反射的に横隔膜の痙攣ないし一時的な麻痺を起こす。【A】
医学的には横隔膜痙攣と呼ばれる。**息が吸えなくなる**のがこの技の効果で、通常は1〜2分で自然に回復する。【A】

自分が受けた場合、吸おうと焦るほど回復が遅れる。**細く長く吐く**ことを意識するといい。

### 肋骨

打撃や組み技の圧迫による肋骨骨折・肋軟骨離開は、機序としては構造の破壊（第IV種）に近い。
柔術の競技では、整形外科的な傷害に次いで2番目に多い傷害カテゴリだった。【A】
肋軟骨離開は回復に2〜3ヶ月を要することがあり、骨折より長引きやすい。【B】
呼吸のたびに動くので治りにくい。

攻める価値は高いが、**受けたときのコストが大きい**部位である。

## 5. 脚 — 削って奪う

### カーフキック

狙っているのは**総腓骨神経**である。膝の外側、腓骨頭のすぐ下を、極めて浅いところを走っていて、
筋にも骨にも覆われていない。

脛骨でここを打つと鋭い神経痛が走る。加えて、下腿は筋の区画（コンパートメント）が小さいため、
腫れると急速に内圧が上がり、神経と血流を圧迫する。【B〜C】
重度になると一時的に足首が持ち上がらなくなる（下垂足）。【C】

数発では効かない。10発以上積んで、相手が立てなくなるというのが典型的な決まり方である。
**序盤に投資して後半に回収する、累積型の代表**といえる。

### 腿へのロー

狙いは外側広筋（腿の外側）または内転筋群（内腿）。筋を直接打撲して微小な損傷と血腫を作り、
筋の出力と可動域を落とす。単発ではほとんど効かないが、累積すると
踏み込み・蹴り・タックルのすべてが劣化する。累積性という点では最も高い。

カーフとの違いは、**カーフが神経（即効・低回数）、腿が筋（遅効・高回数）**であること。
両方を混ぜると、相手は防御の高さを固定できなくなる。

## 6. 関節 — なぜ小さな力で壊れるのか

関節技のすべては、たったひとつの式で説明できる。

```
  トルク ＝ 加えた力 × 回転軸からの距離
```

腕十字を例に取る。支点になるのは自分の股関節で、そこに相手の上腕を乗せる。
力を加えるのは自分の脚と体重で、作用点は相手の手首、つまり肘から最も遠い場所である。

```
   相手の肘 ←── 約20cm ──→ 相手の手首
       │
     ここが壊れる
```

手首を握って引くと、肘から遠い位置に力がかかる。てこが長いので、小さな力で大きなトルクが出る。
逆に相手が肘を曲げて手を自分に引き寄せると、てこが短くなって効かなくなる。
これが腕十字の防御原理そのものである。

参考までに、肘を伸ばした状態で外反方向のトルクをかけた場合、
30〜40 N·m 程度で尺側側副靱帯が損傷しうるとされる。
ただしこの数値は二次情報で、格闘技に特化した実測ではない。桁の感覚としてだけ使うべきである。【C】

### ヒールフックが特別な理由

同じ式で、ヒールフックがなぜ危険なのかも説明がつく。

```
      腕十字                    ヒールフック
  肘 ── 手首                膝 ─── 足首 ── 踵
  てこ：約20cm               てこ：約40cm
  方向：伸展（1軸）           方向：回旋（膝が最も弱い方向）
  痛覚：よく機能する          痛覚：損傷閾値に対して乏しい
```

同じ力でトルクは約2倍、しかも関節が最も弱い方向で、しかも警告が来ない。

ヒールフックが合法な部門で膝の傷害リスクが12倍になるという疫学の数字（[03_壊れる仕組み](03_壊れる仕組み.md)）は、
神秘的なものではなく、**てこの長さ × 弱い軸 × 警告の欠如**という3条件の積である。

### 関節ごとの弱い方向

| 関節 | 本来の動き | 弱い方向 | 代表的な技 |
|:---|:---|:---|:---|
| 肘 | 屈曲・伸展 | 過伸展、外反 | 腕十字、腕がらみ |
| 肩 | 多方向（最も自由） | 極端な内旋・外旋＋外転 | キムラ、アメリカーナ |
| 膝 | 屈曲・伸展 | **回旋（最弱）**、過伸展 | ヒールフック、膝十字 |
| 足首 | 背屈・底屈 | 過度の底屈、回旋 | アキレス腱固め、トーホールド |
| 手首 | 多方向 | 過度の掌屈・背屈 | リストロック |

覚え方はひとつでいい。**その関節が普段しない動きを、遠いところから、ゆっくり与える。**

## 7. 連鎖 — 戦術の実体

単発の効果ではなく、連鎖を設計する。これが戦術というものの中身である。

**カーフキックの連鎖**

カーフに当たると、前足に体重を乗せられなくなる。すると前後のステップが遅くなり、距離の管理が崩れる。
距離が崩れれば打撃をもらう頻度が上がる。さらに蹴られた脚では蹴り返せないし、タックルの踏み込みもできないし、
テイクダウン防御のスプロールも遅れる。
**ひとつの標的が、打撃・組み・防御の3系統を同時に劣化させている。**

**ボディの連鎖**

ボディに当たると呼吸が浅くなる。有酸素性の回復が落ちて疲労が加速する。
疲労すると首の筋肉が使えなくなり（§3の条件5）、回転加速度が増える。
つまり頭部への被弾がより危険になる。おまけに腹をかばってガードが下がる。
**ボディは、頭を効かせるための前工程である。**

**疲労の連鎖**

疲労すると反応時間が延び、判断の精度が落ちる。【A】
予測が外れるということは、見えていない状態が増えるということで、
そうなると回転加速度が最大29%増える。【A】
同じ打撃でKOされやすくなる。
**「後半にKOが増える」ことの生理学的な説明はこれである。**

**テイクダウンの連鎖**

倒されると上を取られる。上を取られると殴られる。しかも頭が床に固定されていて逃げが利かない。
逃げようと背を向けるとバックを取られ、その先にリアネイキッドチョークがある。
**倒されることの本当のコストは、倒された瞬間ではなく3手先にある。**

## 8. 組み合わせ — 守れない形を作る

単一の標的を攻めても防御される。だから、**防御が両立しない組み合わせ**を作る。

人間には同時に守れない組み合わせがある。上段を守ればガードが上がってボディが空く。
ボディを守れば肘が下がって頭が空く。ローを守れば脚が上がって上体の安定を失う。
タックルを守れば腰が落ちて頭が下がり、アッパーと膝が入る。
打撃を守って手を上げればアンダーフックを取られる。

これを踏まえた実装をいくつか挙げる。

| 組み合わせ | 狙い |
|:---|:---|
| カーフ → 腿 → ボディ（下から上へ積む） | 移動力を奪い、呼吸を削り、最後に頭を空ける |
| ボディ → 上段 | ボディで肘を下げさせ、顎が上がったところへ |
| ジャブ連打 → レベルチェンジ → タックル | 上への反応を作って下を空ける |
| タックルのフェイント → 膝／アッパー | 腰を落とさせて頭を下げさせる |
| ロー → 相手が下がる → 壁際 → ボディロック | 移動力を削って逃げ場を消す |
| グラウンドパウンドで手を使わせる → 脚を進める | 上を守らせて下を通す |
| バック → 相手が首を守る → 腕を取る | 防御の手を配分させて選択肢を割る |
| 足関節の脅威 → 相手が前に出られない → パスが通る | 抑止力としての足関節 |

### 効かせる順序

序盤は**累積型**に投資する（カーフ、腿、ボディ）。リターンは遅いが確実で、リスクが低い。

中盤に**位置**を取りにいく（組み、テイクダウン、パス）。
相手の移動力が落ちてから入るほうが成功率が上がる。

終盤に**即効型**を回収する（頭部、サブミッション）。
相手の疲労で回転加速度が上がり、防御の精度が落ちている。

これが [01_この競技の構造](01_この競技の構造.md) の「決着は累積で起きる」の具体形である。

## 9. 時間の設計 — 認知の負荷をどうかけるか

### 選択肢の数と反応時間

**ヒックの法則**によれば、反応時間はおおむね「a ＋ b × log₂(選択肢の数)」で表される。【A】
選択肢が増えるほど反応は遅くなるが、増え方は対数的である。
熟練した選手は、訓練によって最も出やすい反応を自動化し、実質的な選択肢の数を減らしている。【A】

ただし注意が必要で、**実戦におけるヒックの法則の説明力は限定的だという批判がある**。
ストレス下の生理反応と反射が、法則の予測するわずかな遅延を上書きしてしまうためである。【D】
「選択肢を減らすと速くなる」という方向性は正しいが、定量的な予測には使えない。

### 疲労と判断

精神的な疲労は反応時間を延ばし、注意の脱落を増やす。
テコンドー選手を対象とした研究では、認知課題のあとに反応時間の遅延と正答率の低下、
および事象関連電位の変化（認知処理そのものの障害を示す）が確認されている。【A】
疲労は**判断の速さと正確さの両方**を損なう。

### 時間帯別の設計

以下は上記の知見から組み立てた設計案であり、この配分そのものが検証されたわけではない。【C】

**開始から30秒 — 情報を集める。**
自分の認知負荷を低く保つため、選択肢を2つに絞る（たとえばジャブと前蹴りだけ）。
相手のスタンス、リーチ、後ろ手の癖、下がり方を採取する。
まだ手の内は見せない。ここでの被弾が最も高くつく。首も判断もまだ温まっていない。

**30秒から2分 — 負荷を投入する。**
相手の選択肢を増やして認知負荷を上げる。高さを変え、打撃と組みを混ぜ、同じ技を2回続けない。
同時に累積型（カーフ、腿、ボディ）に投資する。
相手が守るべき対象が増えるほど、ひとつひとつの対応が遅れる。

**2分からラウンド終了 — 回収する。**
相手の疲労で反応が遅れ、予測が外れ、見えていない被弾が増えている。
ここで即効型を狙う。ただし自分にも同じことが起きているので、自分の側は選択肢を絞る。

**ラウンド間 — リセットする。**
呼吸を整え、次のラウンドでやることを1つだけ決める。

### 自分の負荷を下げる方法

デフォルトの行動を決めておくこと（[11_判断フロー](../3_引く/11_判断フロー.md)）。
「迷ったら横に動く」「迷ったら立つ」「迷ったらアンダーフック」。

ラウンドごとに「やること」を1つに絞ること。「今ラウンドはカーフだけ」で十分で、3つ以上は回らない。

そして得意な組み立てを1本に確定させること。選択肢を減らすというより、
**最初に浮かぶ選択肢を固定する**という言い方のほうが近い。

## 10. 禁止標的 — なぜ禁止なのか

以下は競技で禁止されている。ここでは攻撃法を扱わず、理由だけを述べる。
知っておく目的は、事故として起きたときに理解できること、自分が守れること、そして反則を取られないことである。

| 禁止標的 | 医学的な理由 |
|:---|:---|
| 後頭部・頸椎 | 脳幹と小脳が浅い位置にあり、頸椎の保護も弱い。致死・重度障害のリスクが跳ね上がる |
| 脊椎 | 脊髄損傷は不可逆の麻痺につながる |
| 目 | 角膜・網膜・眼窩の損傷。MMAの眼部外傷では眼窩骨折が17%を占める【A】。失明のリスク |
| 喉 | 喉頭・気管の損傷は気道閉塞、すなわち即死につながりうる |
| 股間 | 精巣の損傷と、迷走神経反射によるショック |
| 指などの小関節 | 骨折・脱臼が容易で、競技的な利益が小さい |
| スラム（持ち上げて叩きつける） | 頸椎・脊椎の損傷。多くのルールで禁止される中心的な理由 |
| 倒れた相手への蹴り・膝（ルールによる） | 頭が床で固定され、逃げが利かない |

**自分の出る大会の禁止事項は暗記すること。**
[05_ロードマップ](../2_やる/05_ロードマップ.md) の段階0に「禁止技を10個以上そらで言える」という条件を入れているのはこのためである。

## この章の弱点

- 回転加速度の数値の多くはダミー人形やシミュレーション由来で、実際の試合の実測値ではない。
  桁の比較には使えるが、個々の打撃の予測には使えない
- レバーブローが迷走神経を介するという説明は、格闘技メディア由来のものが支配的である【B〜C】。
  血管迷走神経反射の生理学そのものは【A】だが、この因果を直接示した研究は確認できていない
- カーフキックについても同様で、総腓骨神経の解剖は【A】、MMAでの機序の説明は【C】
- 関節破壊の力学的な閾値（30〜40 N·m）は二次情報である
- §9の時間帯別の設計は本文書による統合であり【C】、構成要素（ヒックの法則、疲労と認知）は【A】だが、
  この配分そのものを検証した研究はない
- ヒックの法則の実戦への適用には批判がある【D】
