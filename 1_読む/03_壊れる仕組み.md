# 03. 壊れる仕組み

> **この章が答えること** — 何がどのくらいの頻度で壊れるのか。どこまでが取り返せて、どこからが取り返せないのか。
> **読了の目安** — 25分
>
> **要約**
> 傷害の3分の2以上は頭部に集中し、脳は累積で損なわれる。しかも累積を予測するのは脳振盪の回数ではなく総曝露量である。
> 絞めは、正しく行って即座に外すかぎり、現在の証拠では恒久的な障害の根拠がない。ただしその前提が崩れると話は変わる。
> 膝はヒールフックが合法な環境で12倍のリスクを負う。防御を先に完成させる理由がここにある。

> **この章は後回しにしないこと。**
> ヒールフックとチョークがあるルールでは、安全に関する知識の欠落は「上達が遅い」ではなく
> 「膝が壊れる」「意識が飛ぶ」に直結する。

## 1. 数字で見る — 何がどのくらい起きるのか

まず全体像を把握しておく。

MMAの傷害疫学を扱った体系的レビューとメタ分析によれば、
競技における傷害の発生率は**1000 athlete-exposure あたり 228.7**（95%信頼区間 110.4–473.5）である。【A】
athlete-exposure というのは「選手が1回試合に出ること」を単位にした指標で、
要するに試合に出るたびにかなりの確率で何かが起きる、という数字である。

問題はその中身で、**最も多く傷害を受ける部位は頭部で、全体の66.8〜78.0%**を占める。
次が手首と手で6.0〜12.0%。傷害の種類は、裂創が36.7〜59.4%、骨折が7.4〜43.3%、
脳振盪が3.8〜20.4%となっている。【A】

一方、打撃のないグラップリングの数字はまったく違う。
柔術の競技を対象にした研究では、5022 exposure に対して46件、
つまり**1000 exposure あたり 9.2** だった。整形外科的な傷害が78%を占める。【A】

```
  MMA（打撃あり）      228.7 / 1000
  柔術（打撃なし）        9.2 / 1000
```

**桁がひとつ違う。** リスクの主因が打撃、とりわけ頭部への打撃であることが、この対比から読める。

なお、練習中の傷害についてはデータが乏しい。上記はいずれも**試合**を対象にしている。
柔術の練習を含む調査では、対象期間中に85%が何らかの傷害を経験し、平均60日の離脱があった。
最も多いのは手指、肩、膝である。【A】

## 2. 脳 — 累積で損なわれる

### 分かっていること

クリーブランド・クリニックが2011年から続けている「プロ格闘家の脳健康研究」は、
現役および引退したボクサーと総合格闘家を長期追跡している。ここから出ている知見は明確である。

**累積の曝露量が多いほど、脳の容積が小さい。**
プロとしての試合数、競技年数、そしてそれらから算出される曝露スコアが高いほど、
**視床と尾状核の容積が小さく**、かつ容積の低下した人は**処理速度の認知テストで低いスコア**を示した。【A】

アメリカンフットボールの加速度計データを使った研究は、もっと踏み込んだことを示している。
**競技年数と累積の頭部衝撃曝露が慢性外傷性脳症（CTE）の有無と重症度に関連する一方、
診断された脳振盪の回数は関連しなかった。**【A】
さらに、病理学的にCTEが確認された元選手のうち**16%は脳振盪の既往がなかった**。【A】

累積の頭部衝撃曝露が、後年のうつ、意欲低下、実行機能の障害、認知障害を予測するという
閾値と用量反応の関係も報告されている。【A】

> **管理すべきは「脳振盪の回数」ではなく「総曝露量」である。**
> 「一度も脳振盪していないから大丈夫」は、根拠に反する。

### 分かっていないこと

現役のMMA選手について、**自己申告による週あたりのスパーリング回数は、
いずれの脳領域の容積低下とも有意に関連しなかった**という報告がある。【D】

ただしこの研究の曝露指標は「ラウンド数」だけで、
1ラウンドあたりの強度や被弾数、打撃の質を測っていない。
したがって「スパーは脳に安全だ」という結論をここから導くことはできない。

そして最も重要なこととして、**安全な閾値は確立していない**。
何発までなら大丈夫、という数字は存在しない。【D】

### だから、どうするか

分かっていることと分かっていないことを合わせると、対策の方向は次のようになる。

> **ラウンド数を減らすより、1ラウンドあたりの頭部への被弾を減らすほうが、根拠に沿っている。**【B】

具体的な練習設計は [04_うまくなる仕組み](04_うまくなる仕組み.md) にある。
[02_効く仕組み](02_効く仕組み.md) で見た「組み技の頭部負荷は打撃の1桁下」という数値も、ここに直結する。

なお、頸部の等尺性筋力（太さではなく筋力）が脳振盪のリスク低下と関連するという報告があるが、
**証拠は混在しており、最適な期間・強度・頻度は未確立**である。【D】
やらない理由はない（首相撲でもグラウンドでも必要になる）が、
「首を鍛えたから安全」と考えるのは誤りである。

### 脳振盪をどう扱うか

現在の国際的な基準は、2022年にアムステルダムで開かれた第6回国際スポーツ脳振盪会議の合意声明である。【A】

現場での評価には SCAT6、診察室では SCOAT6 というツールが使われる。
管理の枠組みは12の項目（認識する、リスクを減らす、競技から外す、再評価する、相対的に安静にする、
リハビリする、専門医に紹介する、回復させる、学業と競技に復帰させる、再考する、洗練する、引退を検討する）で構成される。

従来の指針から明確に変わった点がひとつある。
**症状が消えるまでの完全安静は、もはや推奨されていない。**
「暗い部屋で安静に」という昔の指導は現在の基準では否定されており、
症状を悪化させない範囲での早期の軽い有酸素運動が推奨される。

### 現場で判断するための徴候

次のいずれかがあれば、その場で練習・試合から外す。

意識の消失（時間の長短を問わない）。直前の記憶の欠損。バランスの障害やふらつき。
呂律が回らない。「頭がぼんやりする」「霧がかかった感じ」。光や音への過敏。
普段と違う情動の変化（苛立ち、涙もろさ）。

**迷ったら外す（When in doubt, sit them out）。**
これはすべての主要な脳振盪ガイドラインが一致している原則である。【A】

最も危険なのは、**回復していない状態での再受傷**である。
軽微な衝撃でも重篤な結果になりうる。「まだ症状はあるけど大丈夫」は最悪の判断になる。

### 公式の休養基準

参考として、ABC（Association of Boxing Commissions）の統一規則では次のように定められている。【A/B】

| 決着 | 最低の医学的出場停止 |
|:---|:---|
| 頭部打撃によるTKO負け | **最低30日** |
| KO負け | **最低60日** |
| 医師の裁量 | さらに長期を課しうる |

各コミッションは互いの停止処分を承認するので、他州や他国でも試合はできない。

これは**試合**の基準であって、練習で効かされた場合の公式基準は存在しない。
だが医学的には同じことが起きているので、自分に同じ基準を当てはめるのが合理的である。【C】

## 3. 首 — 絞めは何をしているのか

### 生理学的な事実

絞め技については、比較的しっかりした研究がある。

柔道家10名を対象に、絞めによる失神を7名で誘発し、脳波と局所脳血流を測定した研究では、
失神中の脳波は**前頭部優位の2〜3Hzの高振幅徐波**を示し、その後正常に回復した。
ベースラインの脳波と脳血流はいずれも正常であり、
**柔道の練習および絞めによる恒久的な中枢神経機能の変化を示す証拠は認められなかった**。【A】

血流の変化はかなり大きい。絞め技の適用時、内頸動脈系の血流は**80〜90%低下**し、脳の酸素化が急落する。
意識消失の際には強直間代性の痙攣を伴うことがある。
そして**頸動脈の血流が回復すれば、通常12秒以内に覚醒する**。【A】

### この根拠を誤読しないために

> **「絞めは安全だ」ではない。**
> 「正しく行い、即座に解除するかぎり、現在の証拠では恒久的な神経学的損傷の根拠がない」である。

前提条件が4つある。これが崩れると、上の根拠は無効になる。

血管を絞めているのであって、気道絞めを首に食い込ませていないこと。
タップまたは失神と同時に即座に解除していること。
落ちた相手を締め続けていないこと。
短時間であること（数十秒から分単位の圧迫は、上の研究の範囲外である）。

なお、失神時の強直間代性の痙攣は珍しいものではなく、それ自体はてんかん発作ではない。
慌てず、まず絞めを外し、気道を確保する。

### 血管絞めと気道絞めの区別

これは必須の知識である。

**血管絞め**は頸動脈を圧迫する。数秒で意識が落ち、痛みは少ない。
**気道絞め**は気管を圧迫する。苦しくて痛く、時間がかかり、喉頭を損傷するリスクがある。

競技で狙うのは血管絞めである。気道絞めは効率が悪く、危険度だけが高い。
「苦しくて痛い絞め」を使っているなら、技術が間違っている可能性が高い。【B】

### 落ちた場合の対応

```
1. 即座に絞めを解除する
2. 仰向けにして気道を確保する（顎を上げる）
3. 呼吸を確認する
4. 通常は血流の回復から12秒以内に覚醒する
5. 30秒以上覚醒しない、呼吸がない、痙攣が続く → 救急要請
6. 覚醒しても、その日の練習は終了。頭部を打っている可能性も考える
7. 記録する（誰が、どの技で、何秒、覚醒までの時間）
```

やってはいけないのは、揺さぶること、平手打ちすること、水をかけること。
いずれも医学的な根拠がなく、頸椎の損傷があれば有害である。
そして「よくあること」として練習を続けさせること、短期間に繰り返し落とすことも、上記の根拠の範囲外にある。

### 絞めてはいけない相手

頸動脈や脳血管の疾患の既往がある人。頸椎に問題がある人。原因不明の失神の既往がある人。
これは自己申告に頼るしかないので、**道場やチームで最初に確認する仕組みを作る**必要がある。

## 4. 膝 — ヒールフックの12倍

### 疫学

国際ブラジリアン柔術連盟は2021年1月1日から、道着なしの成年茶帯・黒帯部門で
ヒールフックとリーピング（相手の膝の外側を脚で跨ぐ配置）を解禁した。
その前後を比較した研究がある。【A】

対象は2021年の成年303名とマスターズ455名、および2009年の成年164名。結果は次のとおり。

| | 膝の傷害発生率 |
|:---|---:|
| ヒールフックに曝露した競技者 | **26.5 / 1000試合** |
| 曝露しなかった競技者 | **2.2 / 1000試合** |
| **相対リスク** | **12.0**（95%信頼区間 1.5–96.1、P<0.001） |

足関節の傷害には有意差がなく、また2009年と2021年を全体で比べても膝・足関節の傷害率に有意差はなかった。

### 数字の読み方

信頼区間が 1.5 から 96.1 と極めて広い。これは「12倍」という点推定が精密ではないことを意味する。
だが**下限が1.5で、区間が1をまたいでいない**ため、**リスクの上昇そのものは統計的に有意**である。

つまり「12倍かどうか」は不確かだが、「上がっている」ことは確かだと読むのが正しい。

もうひとつ重要なのは、**2021年全体では傷害率が上がっていないのに、曝露者に限れば上がっている**という構造である。
これはリスクが**技術そのものに局在している**ことを示唆する。

絶対リスクで見れば 26.5/1000試合、つまり1試合あたり約2.7%である。ゼロではないが、
過度に恐れる必要もない。原著の推奨も、**「急激なクランクではなく漸進的に力を加えること」と
「防御技術を習得すること」**であって、禁止せよとは言っていない。【A】

### なぜ危険なのか

[02_効く仕組み](02_効く仕組み.md) で見たとおり、**てこの長さ × 弱い軸 × 警告の欠如**の積である。

膝から踵までのてこは肘から手首までのおよそ2倍。
膝は回旋にもともと弱い。
そして膝の十字靱帯や側副靱帯は、損傷しうる力の大きさに比べて痛覚の受容が乏しく、
**「痛い」と感じたときには既に損傷していることがある**。【B】

内側へのヒールフックは脛骨を内旋させ、主に前十字靱帯と内側の構造に負荷をかける。
外側へのヒールフックは脛骨を外旋させ、主に後外側の支持機構（外側側副靱帯、膝窩筋腱、膝窩腓骨靱帯）に負荷をかける。【B】
実際には単一の靱帯だけが壊れることは少なく、複合損傷になりやすい。

### 受傷を疑うべき徴候

```
・「ポップ」という音がした      → 靱帯断裂を強く疑う。即座に練習中止
・数時間以内の急激な腫れ        → 関節内出血の可能性。整形外科へ
・膝が「抜ける」「ぐらつく」感覚 → 不安定性。整形外科へ
・膝が伸びない／曲がらない      → 半月板損傷の可能性
```

自己判断で練習を続けないこと。靱帯損傷を放置すると、二次的な半月板や軟骨の損傷を招く。

### 予防

タップの基準を「形が完成した時点」に置くこと。痛みを待たない。
クランク（急激にひねること）を禁止するプロトコルを、練習相手全員と共有すること。
防御技術を先に完成させること。これは原著の推奨そのものである。【A】
股関節の可動域を確保すること（脱出に直結する）。【C】
疲労時や体格差が大きいときは足関節の攻防をしないこと。

詳細な手順は [09_足関節](../2_やる/09_足関節.md) にある。

| 部位 | よくある傷害 | 対応 |
|:---|:---|:---|
| 手指 | 突き指、靱帯損傷、骨折 | テーピング。柔術では最も多い部位のひとつ【A】 |

| 頸椎 | スラム、倒立からの崩れ落ち | 首の痛みに手足のしびれが伴えば動かさず救急要請 |

## 6. 皮膚感染症 — 軽視されがちだが重要

グラップリングは皮膚の接触が長時間続くため、感染症の温床になりやすい。

| 疾患 | 特徴 | 対応 |
|:---|:---|:---|
| 白癬 | 円形の発赤、鱗屑 | 抗真菌薬。治癒まで練習休止 |
| とびひ（伝染性膿痂疹） | 水疱、びらん、黄色い痂皮 | 抗菌薬。練習休止 |
| 単純ヘルペス | 集まった小水疱、痛み | 抗ウイルス薬。練習休止 |
| MRSA | 膿瘍、急速な悪化 | すぐ医療機関へ。重篤化しうる |
| 疥癬 | 強い痒み（特に夜間） | 医療機関へ。周囲にも波及する |

予防は単純である。練習後すぐシャワーを浴びる。道着とラッシュガードとタオルは毎回洗う。
マットを拭く。爪を短くする。皮膚に病変があれば練習しない（覆えばいい、ではない）。傷は洗ってから覆う。

**うつすことのコストは、自分の1回の練習より高い。**

## 7. 受傷したときの判断

```
救急要請
  ・意識が戻らない（30秒以上）／呼吸がない
  ・首の痛みに手足のしびれ・脱力が伴う
  ・痙攣が続く
  ・激しい頭痛が悪化する、繰り返し嘔吐する
  ・瞳孔の左右差、呂律障害、片側の脱力

当日から翌日に受診
  ・脳振盪の疑い（症状がひとつでもあれば）
  ・関節の「ポップ」音、急激な腫れ
  ・関節の不安定感、伸びない・曲がらない
  ・骨折が疑われる変形や強い圧痛
  ・耳介血腫（早いほどよい）
  ・急速に広がる皮膚病変、発熱を伴う膿瘍
```

## 8. 練習環境のチェックリスト

- [ ] マットが清潔で、隙間やめくれがない
- [ ] 壁や柱に緩衝材がある
- [ ] 救急箱、氷、AEDの場所を知っている
- [ ] 救急要請の手順を全員が知っている（住所が言える）
- [ ] 既往歴（頸椎、脳、心臓、失神）を申告する仕組みがある
- [ ] タップの基準がチーム全体で共有されている
- [ ] 未経験者と経験者のスパーリングにルールがある
- [ ] マウスピースを全員が使っている
- [ ] 頭部への打撃を伴うスパーリングの頻度が管理されている

## この章の弱点

- 練習中の傷害疫学のデータが乏しい。ほとんどの研究は**試合**を対象にしている
- 絞めの安全性を扱った研究はサンプルが小さく（n=10）、かつ古い。
  長期にわたる反復曝露の影響を調べた研究は見つかっていない【D】
- ヒールフックの疫学は横断研究1本で、信頼区間が極めて広い。前向き研究がない
- 日本国内の格闘技傷害統計はほぼ整備されていない
- 頸部筋力の脳振盪予防効果は未確定である【D】
