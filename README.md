## 0. この文書の立ち位置

**目的**: 徒手格闘（unarmed combat / hand-to-hand combat）を、流派の寄せ集めではなく
**ひとつの意思決定システム**として記述する。

**方針**:

1. **原理 → 戦略 → 戦術 → 技術** の順に降りる。技の羅列から始めない。
2. 主張には必ず**根拠の等級**を付ける（後述）。
3. 「軍」と「競技」は目的関数が違う。**混ぜずに、並べて、差分を明示する**。
4. 実践投入する前に、**リスクの非対称性**（首・膝・脳）を先に理解する。
5. **「効く理由」を医学・物理で説明できないものは書かない。**

**この文書が扱わないもの**: 精神論、流派の優劣論、出典のない「実戦では〜」、
恒久的な障害を最大化する方法、禁止標的の攻撃法。

## 1. 根拠の等級（Evidence Tier）

各章の記述には以下のタグを付けている。**タグのない断定は書かない**のがルール。

| タグ | 意味 | 例 |
|:---|:---|:---|
| **【A】** | 査読付き論文、または公開されている公的教範に明記 | 「脳振盪の回転加速度閾値は約4,500 rad/s²」 |
| **【B】** | 公開競技統計・大規模データだが査読なし。または複数の一次資料からの合理的推論 | 「UFCの決着のうちサブミッションは約19%」 |
| **【C】** | 現場のコンセンサス・経験則。反証可能な形で書くが、実証データはない | 「ヒールフックの防御は攻撃より先に習うべき」 |
| **【D】** | 論争中／根拠が割れている。判断を保留して両論を示す | 「スパーリング量と脳容積の関係」 |

**重要**: 【C】が悪いわけではない。格闘技の技術知の大半は【C】である。
問題は【C】を【A】であるかのように語ることだ。この文書では等級を偽らない。

## 4. あなたのルール条件に対する要約（先に結論）

ヒールフック有・チョーク有・打撃有という条件は、**技術の優先順位を大きく歪める**。

1. **バックコントロール → RNC が依然として最大の勝ち筋**
   UFC全サブミッションの約39%がリアネイキッドチョーク。次点の2種を足したより多い。【B】
   → 背中を取る技術と、背中を渡さない技術に最大投資。

2. **足関節は「防御を先に」完成させる**
   ヒールフックが合法なIBJJF部門では、被曝露者の膝傷害率が非曝露者の**12倍**（26.5 vs 2.2 / 1000試合、RR 12.0）。【A】
   物理的な理由は明快で、**レバー長 約2倍 × 膝の最弱軸（回旋） × 痛覚警告の欠如** の積である（[13章 §4.2](13_標的と損傷の医学.md)）。
   → 攻撃側の技術は、防御が反射になってから解禁する。

3. **打撃は「精度」であって「手数」ではない**
   エリートMMAの勝敗を分けたのは有効打の**精度**とテイクダウン**成功率**であり、試行回数の多さは勝利に寄与しなかった。【A】
   テイクダウン成功率25%超が勝率を反転させる閾値として抽出されている。【A】

4. **頭部が最大の被害部位、そして曝露は「見えているか」で最大29%変わる**
   MMA競技傷害の66.8〜78.0%が頭部。【A】
   打撃の回転加速度は 3,000〜11,000 rad/s²（脳振盪閾値 4,500）に対し、
   **組技は 276〜2,434 と1桁下**。【A】
   さらに**衝撃を予期できているだけで頭部の角速度が最大29%下がる**。【A】
   → 「見る」技術と「組む」技術は、そのまま脳の保護策である（[13章 §1](13_標的と損傷の医学.md)）。

5. **序盤に累積型、終盤に即効型**
   カーフ・腿・ボディ（累積型）に序盤投資し、疲労で相手の反応が落ちた終盤に
   頭部・サブミッション（即効型）を回収する。疲労は反応時間と判断精度の両方を落とす。【A】
   → [13章 §7〜§8](13_標的と損傷の医学.md)
