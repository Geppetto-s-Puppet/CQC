# 徒手格闘

ヒールフックとチョークありのMMA系ルールで強くなるための資料。

---

## いま開いたなら

**[5_あなた](5_あなた.md)** を読む。あなたの体格と現状に対して、今週やることが書いてある。

そこに書いてある優先順位はこれ。

```
1  練習の3時間前に炭水化物を食う         → 3セット目で潰れるのが止まる
2  打つ瞬間に吐く。序盤は7割で打つ       → 意識が飛びかけるのが止まる
3  ウォームアップに4〜6分の追い込みを入れて25分空ける
4  首の配置ドリル5分                      → 「もっと強く」と言われなくなる
5  1日2,500kcalまで上げる                → 本丸。試合当日に5kg譲るのをやめる
```
