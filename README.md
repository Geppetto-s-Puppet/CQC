# 徒手格闘

ヒールフックとチョークが認められたMMA系ルールで戦うための技術体系を、
公開されている軍の教範と査読論文を土台に組み直したもの。

---

## この文書の構造

5つの部に分かれている。**性格がまったく違うので、同じように読まないこと。**

| 部 | 性格 | 読み方 |
|:---|:---|:---|
| **1_読む** | 読み物。なぜそうなるのかを説明する | 順番に、通して読む |
| **2_やる** | 実践。何をどの順でやるか | 自分の段階のところだけ |
| **3_引く** | 参照。辞書と索引 | 必要になったとき引く |
| **4_あなた** | 個別。あなたの身体と現在地 | 最初と、変化があったとき |
| **5_根拠** | 出典台帳 | 疑ったとき確認する |

「読む」と「引く」を分けたのが、この改訂でいちばん変えたところ。
用語辞典やフローチャートを通読しようとすると必ず挫折するし、
原理の章を必要なときだけ拾い読みしても意味が通らない。

## 根拠の等級について

この文書では、断定の強さを4段階で示している。
一文ごとに付けると読みにくいので、**議論の土台になっている主張にだけ**付けた。

| 表記 | 意味 |
|:---|:---|
| 【A】 | 査読論文、または公開された公的教範に明記されている |
| 【B】 | 大規模な競技統計だが査読はない。あるいは複数の一次資料からの妥当な推論 |
| 【C】 | 現場の共通見解。実証データはないが、反証できる形で書いた |
| 【D】 | 論争がある。結論を出さず、両論を示した |

格闘技の技術知の大半は【C】であり、それ自体は問題ではない。
問題は【C】を【A】のように語ることなので、**この文書では等級を偽らない**。

各章の末尾には「この章の弱点」を必ず置いた。**それが書かれていない章は信用しないでいい。**

## 用語について

この分野の用語は、日本語（柔道）・ポルトガル語（ブラジリアン柔術）・英語（レスリング、ボクシング）・
タイ語（ムエタイ）が混ざっている。**同じ技に3つも4つも名前がある**のが普通で、
全部知っている人は存在しない。

そのため本文では、**はじめて出てくる用語には必ずその場で短い説明を添えた**。
それでも分からなくなったら [10_用語と技の辞典](3_引く/10_用語と技の辞典.md) を開く。
用語が分からないことを恥じる必要はまったくない。
