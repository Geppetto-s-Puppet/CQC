### 1 カポエイラと相撲で使える技

カポエイラ。

| 技 | 扱い | 中身と理由 |
|:--|:--|:--|
| ベンサォン（足裏で押す前蹴り） | 【そのまま】 | ティープと同じもの |
| アルマーダ、メイア・ルーア・ヂ・フレンチ（手をつかない回転蹴り） | 【待つ】 | 後ろ回し蹴りと同系統。入りの軌道がムエタイ式と違うので読まれにくい。背中を見せる代償は同じ |
| ラステイラ（足払い） | 【待つ】 | 相手が蹴るか踏み込んで片脚に体重が乗った瞬間、自分の足裏で相手の軸足の外側を自分の内側へ払う。体重が乗った脚は動かせない。蹴りをキャッチした直後にも使える |
| ジンガ（左右に揺れる基本の動き） | 【変える】 | 上下動が大きいとタックルの的になり、予備動作を見せる。上下動を消し、打つ直前の1拍だけリズムを変えるフェイントに使う |
| メイア・ルーア・ヂ・コンパッソ（両手を床について回る蹴り） | 【捨てる】 | 手を床についても統一ルールでは「グラウンド」にならないので、相手は頭に膝を入れてよい。背中を見せて両手も塞がる |
| アウ（側転）、ネガチーヴァ（床に手をついて低く潜る） | 【捨てる】 | 同じ理由。床に手をついた時点でタックルも膝も防げない |

カポエイラから取るのは実質1つで、回転蹴りの軌道の作り方。既存の後ろ蹴り・後ろ回し蹴りに混ぜる。

相撲。

| 技 | 扱い | 中身と理由 |
|:--|:--|:--|
| おっつけ | 【そのまま】 | 相手が差しに来る腕の肘を、自分の前腕と手のひらで相手の体の中心へ押し込み、脇を閉じさせて差させない。押し合いに応じずに相手の組みを消せるので、細身のあなたに向く |
| はたき込み、引き落とし | 【そのまま】 | 前に出てくる相手の首の後ろか肩を両手で掴み、斜め前下（自分の足元の外側）へ一気に引き落とす。スナップダウンと同じ動きで、フロントヘッドロックへつながる |
| すり足、四股、鉄砲 | 【そのまま】 | 足を交差させない移動、片脚での安定と股関節の可動、押す動作の反復。体づくりに使える |
| 突っ張り（掌底で胸と肩を押す） | 【変える】 | 統一ルールで掌底は合法。威力はパンチに劣るので、当てる技ではなく距離を作る押しに使う。アマチュア修斗では掌打が反則 |
| 蹴手繰り | 【待つ】 | 立ち合いで相手の足を外から刈る。MMAではアンクルピックと足払いの位置づけ |
| 立ち合い（低く当たって腰で押す） | 【変える】 | 頭から当たるのは反則で、頭が下がればギロチンの餌。頭を上げ、肩と胸で当たり、ボディロックか壁への押し込みに置き換える |
| まわしを取る投げ（上手投げ、下手投げ、出し投げ） | 【捨てる】 | 帯がない。ショーツを掴むのは反則。同じ原理はボディロックで再現できる |

相撲の中心である「体重をぶつけて押す」は、60kgのあなたが最も避けるべき勝負。取るのはおっつけとはたき込みの2つで、どちらも押し合いを避けて相手の組みを消す技術。「腰高だと負ける」はテイクダウン防御の原則と同じ。

### 2 ギロチンで額を床につけると効かなくなる理由

ギロチンが極まるには4つ同時に要る。

| 条件 | 中身 | 欠けるとどうなるか |
|:--|:--|:--|
| 深さ | 自分の前腕の手首側の骨が、相手の顎の下を越えて喉の反対側まで出ている | 肘寄りの太い部分が顎に乗るだけ。顎の骨が壁になって首に届かない |
| 密着 | 自分の胸と相手の背中の間に隙間がない | 腕1本の力で引くことになる |
| 崩し | 相手の頭が、相手自身の腰より低い | 姿勢が立つと首が縮み、頸動脈が筋肉の奥に入る |
| 力の出所 | 背中を反らせて腰を前へ突き出す。脚（クローズドガード）で相手の腰を止める | 握力だけになり、20〜40秒で腕が終わる |

ギロチンは、相手の頭を自分の胸へ引き上げながら腰を反らし、頭と胴を相対的にずらして締める。額を床につけられると、そのズレが作れない。

1. 頭が床に固定される。相手が反っても頭は上へ動かず、腕の輪が首から顎の上（骨）へ滑って逃げる。
2. 体重が床に落ちる。ギロチンは自分の体重を相手の首に預ける技なので、床が体重を受けた時点で圧の元が消える。
3. 前後の空間が消え、深さを足せなくなる。

耐える側が同時にやること。顎を引いて前腕と喉の間に顎の骨を割り込ませる。絞められている側の肩を耳につくまですくめる。両手で相手の絞め腕の手首を掴み、自分の胸の方へ引き下げる（腕2本対1本）。自分の腰を、相手の絞め腕がある側へ歩かせて角度を変える。

そこから勝てるのは、相手が両腕を首1箇所に使っているから。絞め腕の側へ回り込んでサイドを取り、自分の肩を相手の腕と相手の首の間へ落とすと、相手自身の腕が相手の首を絞める（ヴォン・フルー・チョーク）。打撃ありなら、ギロチンを掛けている側は下で両手が塞がっているので、外した側はそのまま殴れる。

素人の極めが極まらない理由は3つに落ちる。挟む2点目（自分の胸、床、腿、腰）がない。隙間が1cm残っている。崩しの工程を飛ばして形だけ作っている。だから極められたときに最初に確かめるのは「痛いか」ではなく「何が、どこに乗っているか」。乗っていなければ時間は自分の味方で、かけている側が先に消耗する。
例外は足関節で、膝は痛みが出ないまま壊れる。首と腕は待てるが、膝は待たない。

### 3 三角絞めが極まらない

筋力の問題ではない。絞めは首を潰す技ではなく、頸動脈までの隙間を2〜3cm消す技で、脚が長いほど輪が長くなって遊びが増える。長い脚は本来は有利な条件で、いまは遊びの取り方が抜けているだけ。

「骨が折れそう」という感触が出ている時点で、絞めではなく首の骨を圧迫している。三角絞めは、片側の頸動脈を自分の腿の裏で、反対側を相手自身の肩で潰す。相手の肩が首に入っていないと片側しか潰れず、いくら締めても効かない。自分のすねの骨が相手の首の後ろに乗っていれば、それは首の関節技（ネッククランク）で、日本のアマチュアルールでは反則。

例として、相手の右腕が自分の脚の中、相手の左腕が外の形。

| 順 | 原因 | 直し方 |
|:--:|:--|:--|
| 1 | 正面のまま（角度ゼロ） | 自分の腰を、捕まえた腕の側（自分から見て左）へ45〜90度回す。外に出ている相手の左腕の側で、自分の左足の裏を床に着け、床を蹴って腰を左へ送る。角度が切れるまで締めない |
| 2 | 捕まえた腕が真ん中にある | 自分の両手で相手の右手首を掴み、自分の左の腰へ引く。相手の右肩が相手の首の右側に乗る。この1手で効かない三角が効く三角になる |
| 3 | 足首でロックしている | 自分の右足首（くるぶしの上）を自分の左の膝の裏に入れる。足先を引っ掛けるとロックが滑る |
| 4 | 遊びが残っている（脚が長い人の本命） | ロックしたあと、自分の右手で自分の右のすねを掴み、自分の胸の方へ2〜3cm引いてからロックを組み直す |
| 5 | 腰が床に落ちている | 尻を床から浮かせ、腰を天井へ突き上げる。三角は締めるより隙間を詰める技で、腰の突き上げが最大の力源 |
| 6 | 相手の頭が上がっている | 両手を相手の後頭部で組み、組んだ手で相手の頭を自分の胸へ引き下げる。押すのではなく引く |
| 7 | 相手が肩をすくめて顎を引いている | 頭を引き下げてから、相手の右腕をもう一度引き直す。順番が逆だと肩が入らない |

自分の膝を締めるのは最後。1〜6が揃っていれば締める力はほとんど要らない。

相手が亀で、頭が自分の股間の方を向いている形は、三角にとって最悪の条件が3つ揃っている。相手の背骨が丸まって首が縮み、頸動脈が奥に入る。相手が両肩をすくめて隙間がない。角度がゼロ。
先生の言う「相手の遠い側の脇の下に自分の腕を通してから組む」が効くのは、これを3つとも壊すから。脇の下に通した腕で相手の肩を上へ持ち上げると、相手の肩が相手の首へ回り込んで、潰れていなかった側の頸動脈が潰れる。組む位置が後頭部より遠いのでてこが長く、同じ力で相手の上体を大きく丸められる。相手が頭を引き抜く動きと立つ動きも同時に止まる。

順番を変えると速くなる。角度 → 相手の腕を引く → 脇の下から組む → 腰を突き上げる → 最後に膝。
血管が正しく潰れていれば5〜10秒で落ちる。10秒たっても相手が喋れる、苦しがるだけなら配置が違うので、締め続けずに切り替える。切り替え先は、相手が腕を抜こうとするなら腕十字、頭を引き抜いて姿勢を立てるならオモプラータかバック、亀のまま耐えるなら脚を解いてバック。
MMAではこの形は自分が下なので、相手は持ち上げて落とせる。時間をかけるほど不利になる。

診断ドリル（5分、抵抗なし）。パートナーに形を作らせて3択で答えてもらう。「首の後ろの骨に当たってる」ならすねが乗っているので膝裏まで深く掛け直す。「片側だけ効いてる」なら相手の腕を引いていない。「効いてる」が正解で、即外す。角度を10度ずつ変えて、効く角度を探す。片側5回。

### 4 クラッチ（手の組み方）

| 名前 | 作り方 | 主な使い道 |
|:--|:--|:--|
| 四の字（フィギュアフォー） | 片方の手で反対の腕の二頭筋を掴む。掴まれた側の手は相手の後頭部などに置く。腕が数字の4の形になる | 裸絞、ダース、アナコンダ、ニンジャチョーク、キムラ（相手の手首に対して作る） |
| ガブルグリップ | 手のひら同士を合わせて組む。指は絡めない | ダースの入り、ボディロック、ダブルレッグで膝裏を抱えるとき |
| パームトゥパーム | 同じ組み方で絞めを完成させる形。裸絞で四の字が組めないときに使う | 裸絞、ギロチン |
| Sグリップ | 両手の指を鉤のように曲げて引っ掛け合う。握力が要らない代わりに外れやすい | 相手の体が太くて手のひらが届かないとき |
| 手首クラッチ | 片手で自分の反対の手首を掴む | 三角絞めで頭を引くとき、ボディロック |

呼び名を調べた結果。

- **おにぎりグリップ＝ガブルグリップ**。柔術の黒帯の解説と教則動画で併記されている（ほぼ確実）。「おにぎりクラッチ」という言い方の定着度は確認できていない。
- **八の字クラッチは、格闘技の用語として見つからなかった**。日本語でも英語（figure eight grip）でも、グラップリングの手の組み方としての用例がない。ヒットするのはベンチプレスの握りとリストストラップだけ。「四の字」の聞き違いか、道場ローカルの呼び名の可能性が高い（未確定）。
- **マタレオンクラッチ**は実在する。裸絞と同じ組み方（絞め手を反対の腕の二頭筋へ、もう一方を相手の後頭部へ）を指し、ダースやアナコンダの説明でも使われる。

「四の字」は3つの別物を指す。手の組み方の四の字（フィギュアフォー）、脚で胴を挟むボディトライアングル、プロレスの四の字固め（脚の関節技）。区別は [8_辞典](8_辞典.md) の「別名の対応」。10種類のクラッチの作り方と、技ごとの標準は同じファイルの「動作の名前」。

### 5 ボディトライアングル（四の字）と、バックを取られたときの手の役割

ボディトライアングルは、バックを取った状態で相手の胴を自分の両脚で三角に組む形。例として、自分の右脚を相手の胴の前へ回す場合。

1. 自分の右脚を、相手のみぞおちの下（へその高さ）を通して相手の胴の前へ回す。
2. 自分の右の足首（くるぶしの上）を、自分の左の膝の裏に入れる。足先では外れる。
3. 自分の左の膝を自分の胸の方へ引きつけ、両脚で相手の胴を挟む。
4. 自分の右の足先を、相手の左の腿の下（腿と床の間）へ差し込むと外されにくい。メモの「足を相手の足裏に入れる」はこの差し込みと読んだ。違っていたら直す。

得るもの。両手が自由になるので絞めの攻防に集中できる。相手の腰の動きが止まる。締め続けると相手の呼吸が浅くなる。
代償。自分の足首が相手の前で交差しているので、相手に足首を取られうる。脚がフックとして働かないので、相手が回るとロックごと持っていかれる。MMAでは相手が立ち上がって背中から落とせる。

外し方（取られた側）。順番が決まっている。

1. 首が先。片手を自分の顎の下に入れ、相手の腕が顎と首の間に入る道を塞ぐ。
2. もう片方の手で、交差している相手の足首（甲の側）を掴み、自分の腰の方向へ引き下げる。
3. 体を倒す向きは、相手の組み方で変わる。倒して締まる側が間違いで、緩む側が正解。両方向を道場で試して、自分の言葉で決める。
4. 足首の交差が外れたら、自分の腰を相手の腰から外し、肩を床につける方向へ回る。
5. 小ネタ。相手の腿の、膝の少し上の内側（筋肉が薄く骨に近い部分）に自分の肘の先を当て、体重を乗せて押し込みながら擦る。痛みで脚の力が抜けた瞬間に足首を剥がす。これ単体では外れないので、剥がす動きとセットで使う。統一ルールでは、つねる・引っかくのは反則だが、肘や前腕の骨で押すことを禁じる条文はない（未確定）。

先生の「バックを取られたら、片手は防御、もう片方の手は外しに使う」は、次の形で使い分ける。

- シートベルトの肩越しの腕が絞め腕になる。その腕がまだ顎の下に入っていない間は、片手を自分の顎の下に置いて道を塞ぎ、もう片手でその腕の手首を掴んで剥がす。
- 前腕が顎を越えて首に入ったら、両手でその腕を剥がす。片手防御は捨てる。ここで優先順位が変わる。
- 首が安全になってから脚を外す。順番は首 → 脚。
- 倒れる方向は、相手の下の腕（自分の脇の下を通っている腕）の側の肩を床につける。肩越しの腕の側へ倒れると、そのまま絞めの角度に入る。

### 7 スパー動画を見ての疑問

ビーチでのスパーの動画を見ながら出た質問。聞かれた順に答える。名前や根拠が確かめられなかったものは、そう書く。

#### (a) 両手を頭の上に乗せ、肘を下へ向けるカバー

この形そのものの固有名は見つからなかった（未確定）。資料にあるのはハイガード（別名ヘルメットガード、シェル）で、定義は「両拳を眉からこめかみの高さに置き、顎をグローブの裏に隠し、肘で胴の正中線を塞ぐ」。拳はこめかみに当てるのであって、頭の上ではない。ロングガードは別物で、自分の腕を相手の方へ伸ばし、肘を少し曲げ、手のひらを相手へ向けて、相手を打撃の射程の外に留める形。頭に手は乗らない。

目的は4つ。どれも「時間を買う」に帰着する。

| 目的 | 中身 |
|:--|:--|
| 連打をしのぐ | 受け流しが間に合わない連打の間だけ、腕を頭に貼り付けて頭と肋骨を隠す。ロープ際・金網際の形 |
| 効かされた後の回復 | 足が流れている間、判断を要らなくする。圧力の下で気の利いた答えを考えずに済ませるための形 |
| 距離を詰める | リーチの長い相手の射程を通過する間の覆い |
| 空振りの立て直し | 自分が打って外し、体勢が崩れた1〜2拍を埋める |

外から見分ける手がかりは、足と、その直前の展開。

| 見えるもの | 読み |
|:--|:--|
| 足が止まる、または下がる。上体が丸い | 時間を買っている（しのぐ、回復） |
| 覆ったまま前へ出続ける | 距離を詰めている。出切った先で打つか組む |
| 直前に打たれている（膝が伸びる、足がもつれる） | 回復 |
| 腰が落ちて膝が曲がり、肘が開く | 組みに備える姿勢。ただし、この形でタックルを誘う（釣る）という解説は見つからなかった（確認できず） |

「舐めプ（見下し）」という評価も資料にはない。指導資料はどれもこの形を「時間を買う受け」として扱う。休憩と様子見は同じもので、目的の表の1行目と2行目に当たる。

渡しているものは5つ。

- 頭と胴へのダメージを、手と前腕へのダメージに交換している。腕の方が先に効く。
- 周辺視野が塞がれる。ボディへの打撃とフェイントが見えない。
- 直線のパンチには強いが、アッパーとフックのような角度のついた打撃には弱い。
- 両手が頭に貼り付くので、受け流し、カウンター、持ち替えができない。
- 肘が下を向いて正中線を塞いでいる限り、腹と肋骨は守れる。この形と膝・タックルの関係を述べた資料は見つからなかった（確認できず）。

MMAでの扱いは【変える】。変え方は [3_立ち技](3_立ち技.md) の「腕で覆う系」と同じで2つ。グローブが小さいので、手のひらで耳を覆うのではなく前腕を頭に密着させる。腕で受けたまま止まらない。止まると、相手は打撃をやめてローとタックルに切り替える。

自分が相手のこの形を見たときは、打ち続けない。ボディへ1発入れて手を下げさせるか、そのままレベルチェンジへ移る。

→ [3_立ち技](3_立ち技.md) の「防御」の「腕で覆う系」、[8_辞典](8_辞典.md) の「流派の言葉」の「ボクシング」

#### (b) ウィザー、ローシングル、タックルの危険、金的

ウィザー【そのまま】。相手の外側の腕を、自分の腕で上から抱え込んで制する形。きれいなスプロールが間に合わず、相手の腕がすでに自分の脚か腰に回ってしまった瞬間の即答として使う。

例: 相手が自分の右脚（サウスポーなので前足）に、相手の左腕で組み付いた。

1. 自分の右腕を、組み付いてきた相手の左腕の上から被せる。被せる位置は相手の肘より上（上腕）。肘より下に掛けると、腕を制する力はゼロになる。
2. 自分の右手を自分の右の腿の上に置き、自分の右の脇と肘で相手の左上腕を挟む（手の行き先は1つの資料しか書いていない。不確か）。
3. 自分の右肘を天井へ引き上げ、相手の左の脇の下を真上へ持ち上げる。速さは相手が頭を上げて立ち上がる前、力は腕力ではなく、肘に自分の体重を乗せた全力の等尺。
4. 同時に自分の両足の裏で床を踏ん張る。踏ん張らないと、相手に脚を持ち上げられる。
5. 取られた自分の右脚を、自分の外側後方へ抜く。

オーバーフックとの違いは圧力の方向。ウィザーは相手の脇の下を持ち上げ、オーバーフックは抱えた側の肩を下げる。同じ組みで力の向きが逆になる。

用途は3つ。どれも挟んだ腕を軸にする。

- 挟んだ相手の腕をまたいで背後へ回り、バックを取る。
- 自分の体重を相手の上へ落とし、相手を横向き（ヒップ）に転がす。
- 相手の頭側へ回り込んで、フロントヘッドロックへ移る。

「回転させるのに使うのか」の答えは、はい。ただし回すのは腕ではなく、自分の体重と腰。腕は相手の上腕を挟んで支点を作っているだけ。

うまくいかない条件は3つに決まっている。肘より下に掛けた、持ち上げていない（ただの弱いオーバーフック）、足を踏ん張っていない。

ローシングル【待つ】。低く飛び込んで相手の足首か足だけを捕る形。腰ではなく足首1本を孤立させて、相手の移動を殺す。ハイリスク・ハイリターンの技と位置づけられている。

姿勢（資料が具体的に指定しているもの）。

1. 自分の胸が自分の腿に付くところまで沈み、自分の後ろ足で床を押して前へ入る。
2. 自分の内側の手を、相手の両足の間の床へ突く。
3. 自分のこめかみを、相手の膝関節のすぐ上に当てる。
4. 取る側の手で相手のかかとを手のひらで包み、その前腕は床にべったり寝かせる。
5. 自分の尻はかかとの上に座り、足の甲を床へ向ける。

仕上げは3つ。いずれも低い位置のまま崩すもので、持ち上げない。

- ラッソ。自分の頭で相手の膝を外側へ押し出しながら、床に突いていた手を上へ伸ばし、相手を、捕っている脚の上へ倒す。そのあと、攻めている側と反対方向へ回り込んで床へ落とす。
- アウト・ザ・バックドア。相手の股の下を抜けて背後に出る（名前だけ確認。動作の細部は取れていない。不確か）。
- ランザパイプ。頭を相手の腰の外に置いた形からの仕上げで、シングルレッグの仕上げのうち成功率が最も高いとされる。手順は [4_組み技](4_組み技.md) の「ランザパイプ」。

「足を掴んだら全身ごと持ち上げるのがセオリーか」の答えは、違う。持ち上げが標準だと書いた資料はない。姿勢そのものが持ち上げ前提になっていない（胸は自分の腿に付き、尻はかかとの上、前腕は床）。ただし「ローシングルから絶対に持ち上げない」と書いた資料もないので、正しい言い方は「持ち上げは標準ではない」。持ち上げて倒すのは別の技で、ハイシングルと金網際の縦リフト。

タックルの危険を減らす条件は4つ。

1. 入る前に相手の反応を作る。ジャブを突いて一拍置き、相手がその空間を埋めに来た瞬間にレベルチェンジする。ボディを打っておくと、相手はレベルチェンジをボディ打ちと読んで反応が遅れる。逆に、タックルのフェイントで相手の手を下げさせてジャブを通す使い方もある。
2. 相手のパンチが完了する前に、自分が相手の腰へ届く。相手が打ち始めてから動き、レベルチェンジと前への爆発を同時に出す。相手の膝とアッパーの発射台になる後ろ足が床から離れている間が、その窓。
3. 金網で相手の逃げ道を消してから入る。
4. ルールの窓を短くする。自分の膝が床に着いた瞬間から、相手の頭への膝と蹴りは反則になる。手をついただけではグラウンドにならないので、被弾する窓は、自分が両足の裏だけで立っている間に限られる。版と州で定義が違うので、線は [8_辞典](8_辞典.md) の「ルールと反則」で確かめる。

雑なタックルへの罰はギロチン。頭が下がって首が出た瞬間に来る。上手い人がタックルをぽんぽん入れられるのは、1と2を先にやっているから。反応を作らずに入るタックルは、上の4条件のどれも満たさない。

金的。統一ルールでは金的への攻撃はすべて反則で、蹴る、打つ、掴む、つねる、ひねるの全部が入る。故意でない金的には、回復のための時間が与えられる。反則でも、膝と前蹴りの流れで偶然入るので、ファウルカップは着ける。段階0を抜ける条件にも入っている。

→ [4_組み技](4_組み技.md) の「テイクダウン防御」の「片脚を取られたら」、「組みの基本」の「胴を取る（アンダーフック、オーバーフック）」、「シングルレッグ」の「ローシングル」「ランザパイプ」「金網際の縦リフト」、「打撃から組みへ」の「合わせて入る」、[8_辞典](8_辞典.md) の「ルールと反則」、[0_あなた](0_あなた.md) の「装備」

#### (c) バックを取った側が上、下の相手が首や頭に腕を掛けてくる形

形の固有名は確定できなかった（未確定）。近いのは古いレスリングとキャッチレスリングの分類で、腕で相手の頭を側面から抱える形をリアチャンセリー（リバースチャンセリー）と呼び、これがヘッドロックに当たる。両手で抱える形はスリークォーターチャンセリー、クラヴァット。正面から抱える形（フロントチャンセリー）がフロントヘッドロック。動画で聞き取った「ニーブラ」に当たる技名は、検索では出てこなかった（確認できず）。

耐えられるかは、名前ではなく「何が、どこに乗っているか」で決まる。判定は1点だけ。

| 乗っているもの | 起きること | 結論 |
|:--|:--|:--|
| 相手の腕が自分の頭蓋、耳、顎の外側に乗っている | 左右どちらかの頸動脈しか潰れないか、気道が狭まるだけ | 落ちる機序が成立していない。時間切れがない |
| 相手の前腕が自分の顎の下を越え、さらに自分の肩が自分の首の反対側へ押し込まれている | 挟まれた側は自分自身の肩で、反対側は相手の肩と上腕で潰れる。気管は真ん中で空くので血液絞め | アームトライアングル（肩固め）と同じ機序。数秒で落ちる。耐える対象ではない |

落ちる条件は左右両方の頸動脈が同時に潰れることで、これは生理学の査読研究が土台にある。ヘッドロックの大半はこの条件を満たさない。2 でギロチンについて書いた「痛いかではなく、何がどこに乗っているか」と同じ判定をここでも使う。

抜ける手順。順番が決まっている。例: 自分が相手の背中側にいて、相手の右腕が自分の首に巻き付いている。

1. 自分の顎を自分の胸骨へ付ける。相手の前腕が顎の下へ入る道を消す。ここを飛ばすと、抜く動きの途中で絞めに変わる。
2. 自分の両肘を自分の腰に付ける。腕を伸ばしたままだと腕十字を取られる。
3. 自分の体を横向きにする。腰の回転の勢いを使って、自分の上腕三頭筋を床へ着ける。ここまで行けば完全に横向きになれる。
4. 自分の前腕を、相手の首の側面へフレームとして突く（肘を伸ばし、腕を突っ張り棒にして、骨で押す）。これで抱えの輪が保てなくなる。
5. 相手の右手首を自分の両手で掴み、自分の頭の上を通して反対側へ運ぶ。胸と背中の接触が切れる。
6. 抜ける方向は相手の背中側。抜けたらそのままバックへ戻る。

下の相手がこの形から攻めに転じる具体的な連携は、資料では確認できなかった（確認できず）。資料が言うのは「押さえて動きを制限する」「形によっては絞めへ移りうる」まで。

バックからボディロックで倒す形は、リアボディロック【そのまま】。相手の背後に立ち、両腕を相手の胴か腰に回して組む。相手の腰の動きと姿勢を無力化して、マットリターン、トリップ、スープレックスの入口になる。倒しは筋力ではなく、上半身の密着、角度、腰の連結で決まる。60kgのあなたには、この原則の方が重要。

「慌てた相手を後ろ斜め（右後方）へ倒す」という方向指定の有効性を述べた資料は見つからなかった（確認できず）。膝立ちの相手に対する個別の解説も見つからない（確認できず）。資料にある形は3つで、どれも「相手が立ち上がろうとする過程」に当てるもの。

- マットリターン。持ち上げて横倒しにしてから床へ下ろす。手順は [4_組み技](4_組み技.md) の「ダゲスタン式」の「マットリターン」。
- フロントトリップ。自分の脚を相手の脚の前へ踏み越えて引っ掛け、自分の体重を前方へかける。同時に自分の手を床へ突いて、倒しながらバックを保つ。
- ニーピンチ。相手の膝を自分の膝で挟んで固定し、立位の支えを崩す。低リスクの形として挙げられている（1つの資料のみ。不確か）。

後ろへ倒す形そのものは、後ろへ反るジャーマンスープレックス【待つ】。外すと自分が下になる。落とし方の線は、相手の足を上、頭を真下に向けて叩きつけるスパイクだけが反則で、弧を描く投げは頭が当たっても合法。

掬い投げとスープレックスは別物。

| | 掬い投げ（相撲） | スープレックス |
|:--|:--|:--|
| 相手との位置関係 | 正対。自分の差し手が相手の脇の下にある | 背後（ジャーマン）、正対（ベリートゥベリー）、横 |
| 自分の腕の位置 | 相手の脇の下へ下から差す。まわしは取らない | 相手の胴を抱えるか、頭を抱える |
| 上げる方向 | 下から上へすくう。相手の全身を空中へ上げるとは定義されていない | 相手を持ち上げることが定義に入っている |
| 自分の体の動き | その場で上体を回旋させる | 後ろへ反って倒れ込む（ブリッジ）か、回転する |
| 相手の落ちる先 | 横（自分の差し手と反対側） | 背中、上背部 |

掬い投げの定義は日本相撲協会の公式のもので、「まわしを取らずに差し手を返し、相手のわきの下からすくうように投げて勝つこと」。掬い投げのMMAでの扱いは【変える】。帯を取らないので形自体は成立するが、相撲の中でも、まわしを取る投げより威力が低いとされる。倒しきる技としてではなく、アンダーフックで相手の上体を横へ回す崩しとして使い、崩れたら追って上を取る（本書の判断）。スープレックスの手順は [4_組み技](4_組み技.md) の「上体で倒す」の「持ち上げ系」。

首の筋力で継戦できるかの答え。「首を鍛えると絞めに耐えられるようになる」を検証した研究は見つからなかった（確認できず）。根拠があるのは別の方向で、首の筋力と運動制御が高いほど脳震盪の発生が少ないという関連の報告が複数あり、系統的レビューとメタ分析にまとまっている（査読）。首が強い選手は、打撃を受けたときの頭の加速度が小さい。つまり首を鍛えて得られるのは「打撃で揺れにくくなる」ことで、「絞めが極まりにくくなる」ことではない。

だから「これは極まらない」と判断する材料は、首の太さではない。相手の前腕が自分の顎の下に入っているか、自分の肩が自分の首へ押し込まれているか、この2点だけ。入っていなければ落ちる機序がないので、続けられる。入っていれば、首の筋力にかかわらず数秒で落ちる。首は鍛える。理由は絞めではなく、首相撲と投げで頭を支えるため。

#### (d) 腿で腕を挟む形、クルシフィックス、ノースサウス、ヘッドロック

相手の片腕を自分の両腿の間に滑り込ませて固定する形は、サイドクルシフィックス【そのまま】。上の側が相手の側面にいて、相手の片腕を自分の両脚で挟み、もう片方の腕を自分の腕で制する。

入り方（1つの資料のみ。不確か）。例: 自分が相手の右側にいるサイドコントロール。

1. 自分のすねを、相手の遠い側（左）の腕の上へ滑らせる。
2. 自分の膝を車のワイパーのように左右へ払い、自分の内側のすねと腿の間に相手の左上腕を挟み込む。
3. 同時に自分の腕で、相手の近い側（右）の腕を制する。
4. 相手は両腕とも使えなくなる。

ここから出るのは、逆三角（リバーストライアングル）、キムラ、打撃。相手は手で抵抗できないので、顔を守れない。この形から肩固めへつなぐ解説は見つからなかった（確認できず）。あなたの場合、袈裟固で片手が塞がったときの移り先としてこれを使う流れが [5_寝技](5_寝技.md) の「袈裟固と崩袈裟固」に書いてある。

クルシフィックス【そのまま】。相手の背後に、相手に対して垂直に位置し、自分の胸を相手の背中に付け、相手の片腕を自分の脚で、もう片腕を自分の腕で制する形。相手は十字架に架けられた形になる。バックマウントとの違いは、相手の両腕を塞ぐので、絞めと関節への防御がさらに難しくなること。MMAで価値が高いのは、頭と首を腕でも脚でも打てるうえ、絞めと関節も残るから。「MMAで非常に多く出る」という記述はあるが、統計の裏づけはない（不確か）。日本語はそのままクルシフィックス。柔道ではこの形からの絞めが地獄絞。本書では [5_寝技](5_寝技.md) が「十字架固め」を併記しているが、この日本語名を裏づける資料は見つからなかった（未確定）。

ノースサウス（柔道の上四方固）【変える】。相手が仰向け、自分は逆向きにうつ伏せで上に乗り、およそ180度の角度で相手と並ぶ。価値は、下からの標準の逃げ方を2つとも同時に殺すこと。自分の腰を低く保ち、胸を相手の上半身に合わせて圧をかけ、自分の腕で相手の肩か腰を制すると、相手のブリッジとエビが止まる。この配置では、標準のサイドコントロール脱出は効かない。攻撃はノースサウスチョーク、キムラ、腕十字。

サイドからマウントではなく頭の上に回るのが強いか、という問いには、資料は優劣で答えていない（直接比較した資料は確認できず）。言えるのは用途が違うこと。ノースサウスは下からの打撃を受けにくく（相手の可動域と打撃角度が限られる）、マウントは打撃の破壊力が最大。MMAのノースサウスは、相手の顔が自分の腹の下にあるので殴れず、相手はグラウンドなので頭への膝も反則。だからノースサウスは、止まる場所ではなく、反対側のサイドへ抜ける通過点と、ノースサウスチョーク・キムラの入口として使う。相手が腰を切ってマウントへ行かせないときに頭側へ回る判断自体は正しい。

ヘッドロックを繰り返し抜けられる理由は5つ。

1. 落ちる機序が成立していない。頭蓋、耳、顎の外側を締める形は左右の頸動脈に乗っていない。片側だけか、気道が狭まるだけで終わる。時間切れがないので、抜ける側は落ち着いて手順を踏める。
2. 顎を引くと入口が消える。自分の顎を胸骨へ付けると、相手の前腕が顎の下へ入る隙間がなくなり、絞めへ変わる道が閉じる。
3. 構造が1点で壊れる。相手の首へ前腕をフレームで突くと、抱えの輪が保てない。腕力の勝負にならない。
4. 腰の回転で密着が切れる。自分の体を横向きにして上腕三頭筋を床へ着けると、胸と背中の接触が切れる。密着の切れた抱えは、腕だけで支えることになる。
5. 掛ける側が腕2本を使い切っている。抱えている間、掛ける側には打つ手も位置を直す手もない。対して抜ける側は両手が空いていて、相手の手首を掴む手とフレームを作る手に分けられる。

「掛ける側の腕が消耗するから抜ける」という説明は、資料には見つからなかった（確認できず）。上の1〜5はいずれも資料が一致する範囲（通説）。

掛けられる前の前兆を書いた資料も見つからなかった（確認できず）。機序から言える前兆は3つで、これは本書の判断。

- 自分の頭が自分の腰より前に出て、相手と胸を横に並べた瞬間。抱える腕の通り道ができる。
- 自分の顎が上がった瞬間。前腕の入る隙間ができる。
- 自分から相手の首か肩の上へ腕を掛けた直後。抱え返される。

3つとも「頭を自分の腰より高く保つ」「顎を引く」で消える。横から頭を抱える形（グラウンドヘッドロック、袈裟固系）のMMAでの扱いは【変える】で、理由は [5_寝技](5_寝技.md) の「袈裟固と崩袈裟固」と同じ。自分の両手が相手の頭と腕で塞がって打てない。首を抱えて投げる形（ヘッドロック投げ、腰車）は【捨てる】。

#### (a) アナコンダで、自分の顔の上に相手の肩が乗って痛い

耐えるものではなく、形の誤りの合図。正しい形で相手の肩に当たっているのは、自分の胸と絞め腕の上腕で、顔ではない。筋量が足りないから痛い、という根拠は見つからなかった。絞めは胸の圧と転がりで作る、という点で資料が一致する（通説）。

正しい形の要点（例: 自分の右腕が絞め腕。自分の右腕を相手の首の下から入れ、相手の左脇の下を通して出し、右手で自分の左の上腕二頭筋を掴む。相手の右腕が、自分の右腕と相手の首の間に挟まる）。

- 絞まる仕組み: 挟まれた相手の右肩が支点になって片側の頸動脈を押し、自分の右の上腕二頭筋がもう片側を押す。気道ではなく頸動脈。
- 頭: 自分の顔を相手の右腕（挟んだ腕）から背け、自分の右へ向ける。
- 胸: 自分の胸を相手の右肩に押し当て、自分の体を相手の体と直角にする。転がる間、この接触を切らない。
- 転がる向き: 挟んだ腕の側（相手の右肩が床に着く向き）。自分の右肩から床へ潜るように入り、背中を通って左肩まで、素早く転がり切る。逆へ転がると圧が抜ける。転がりで相手の右肩が相手自身の首へ押し込まれるので、転がりそのものが極めになる。
- 転がった後: 相手の頭が自分の腹の上に来るまで進める。自分の両足を相手の頭の方へ歩かせ、腰を相手から離して両脚を伸ばし、胸を床へ落とす。右肘を自分の右腰へ引き、胸を張る。

診断は3つ。上から順に確かめる。

| 何が起きているか | 見分け方 | 直し方 |
|:--|:--|:--|
| 自分の頭が、挟んだ腕と同じ側にある | 転がる途中で自分の顔がマットに向く | 顔を相手の右腕から背け、自分の右へ向けてから転がる |
| 頭が高く、自分の胸が相手の肩に乗っていない | 相手の肩が自分の顎か頬の下にある。回転が途中で止まる | 頭を下げ、胸を相手の右肩へ落とす。胸が乗ると、顔は肩の上から外れる |
| 転がりが途中で止まり、相手の頭が自分の腹まで来ていない | 相手の頭が自分の胸か顔の高さにある | 転がり切る。足を相手の頭の方へ歩かせ、相手の頭を自分の腹の上へ持ってくる |

腕が浅い（自分の肘が相手の首の真下まで来ていない）ときも、回転が途中で止まる。3つで直らなければ腕を深く入れ直す。痛みの原因をこの3つに絞るのは正しい形からの読み替えで、痛みそのものを扱った資料はない（未確定）。

#### (b) 三角絞めを掛けられてスラムしたら、ルール違反と言われた

言われたとおり。道場のスパーは道場の約束で動き、極めや位置から逃れるために相手を叩きつけない、というのが明文の規則（米国のジム）と国内道場の慣習の両方で一般的（通説）。場ごとの線はこう分かれる。

| 場 | 極めを掛けられた側が、持ち上げて落とす |
|:--|:--|
| 道場のスパー | 反則（約束違反）。テイクダウンでもガードの中でもスラムしない |
| IBJJF（柔術） | 反則。反則技の表の「スラム」で、全年齢・全帯、その場で失格。三角やギロチンから逃れるためでも同じ |
| アマチュア修斗 | 反則。「相手を持ち上げている状態から、頭頂部、後頭部、背中を床に叩きつけること」。立った状態で相手を腰より上に持ち上げて3秒以上保持するとブレイク（2024年改正） |
| アマチュアパンクラス | S級は背中から落とすスラムを禁じる条文がなく、主催者の判断で頭から落ちるスラムを反則にできる。A級・B級は、相手を頭からマットに落とすあらゆる行為が反則 |
| IMMAF ユース（12〜17歳） | 極めからの防御でも全面禁止 |
| 統一ルール、IMMAF成人 | 合法。反則はスパイク（相手の体を制御し、足を上、頭を真下にして頭を床へ強く落とす）だけ。弧を描く投げは頭が床に当たっても合法 |
| JMMAF | IMMAF準拠。独自の条文は確認できていない（未確定） |

統一ルールが合法とする理由は条文に書いてある。極めを掛けられている側が相手を持ち上げられるなら、相手の体を制御しているのは自分ではない。掛けている側は位置を変えるか、落とされる前に手を離せる。だから三角を掛ける側に回ったときの選択は2つ。持ち上げられたら、落ちる前に脚をほどいて受け身を取るか、落とされる前に絞め切るか。

実例3つ（どれも統一ルールかPRIDEルールで合法。道場なら約束違反、IBJJFなら失格、アマ修斗とアマパンA級以下なら反則）。

- UFC 34（2001年）マット・ヒューズ vs カーロス・ニュートン: 第2R、ニュートンが下から三角絞め。ヒューズが持ち上げてケージ際へ運び、叩きつけてKO（2R 1:27）。ヒューズ自身も絞められて朦朧としており、先に落ちていたのはヒューズだという論争が残る。
- PRIDE Critical Countdown 2004 クイントン・ジャクソン vs ヒカルド・アローナ: 三角絞めを掛けられたまま頭上まで持ち上げ、パワーボムの形で叩きつけてKO（1R 7:32）。当時のPRIDEは統一ルールを採用していない。
- UFC Vegas 109（2025年）イライジャ・スミス vs 風間敏臣: 三角絞めから持ち上げてパワーボム、失神後にパンチを追加してKO（1R 4:10）。サブミッションを掛けられた側の例外で合法。風間は病院へ搬送され、CTに異常はなかった。

3例とも、三角を掛けた側が、体格と力で上回る相手に下から掛け、相手が立ち上がれる姿勢にあった。脚の長いあなたは三角を掛けやすいぶん、この側に回る。

#### (c) 自分のパンチの威力が分からない。プロにマススパーで詰められ、クリンチ距離でフックを連打される

マススパーで分からないのは、マススパーがそう設計されているから。マスは力を抜き、寸止めか軽打で打ち合って、タイミングと距離を確かめるスパー。ダメージは基本的にない。相手の反応から自分の威力は判定できない。

威力の絶対値は機械でしか出ない。

| 方法 | 出るもの | 精度 |
|:--|:--|:--|
| フォースプレート（壁に縦付け） | 力（N） | 再現性 ICC 0.89〜0.99、変動係数3〜10%（査読） |
| 加速度計内蔵のサンドバッグ | 力（加速度から換算） | 相対誤差3%（査読） |
| スマホや腕の加速度計 | 拳の速度だけ。力は出ない | ICC 0.75〜0.79、誤差0.5〜0.9 m/s（査読） |
| ゲームセンターのパンチングマシン | 得点（バッグの速度と減速からの換算） | 校正の規格がない。営業者が感度を変えられ、部品の摩耗で値が動き、同じ機種でも機体ごとに違う |

パンチングマシンの限界。使えるのは、同じ機体で自分の推移を見ることだけ。別の機体、別の人との比較はできない。業者が言う誤差±5〜20%は根拠が示されていない（不確か）。

研究の値（査読）。フォースプレートで、シニアエリートのアマボクサー10人が、後ろ手フック2,624±581 N、前手フック2,524±532 N、ストレート2,425±545 N、ジャブ1,645±537 N。衝突ダミーで、五輪級ボクサー7人が3,427±811 N、拳の速度9.14±2.06 m/s、有効質量（衝突の瞬間に拳の後ろにつながっている質量）2.9±2.0 kg。重い階級ほど力が大きく、主因は有効質量の差。

力を決めるもの（査読の相関）。拳の衝突前の速度が力のばらつきの約4割を説明する（R²=0.38 フック、0.39 ストレート）。下肢の最大筋力は46%（r=0.68）で、体重で割った相対筋力は関係がない。上体の最大筋力は関係がなく、上体の爆発力（ベンチスロー）は関係がある（ジャブ r=0.75〜0.76、クロス r=0.78〜0.79）。

効くかどうかは、コントロールドスパーで初めて分かる。コーチの管理下で、相手と強度（50%超）を合意し、ヘッドギアと大きめのグローブで打つ区分。当たった音が聞こえるなら、マスとしては強すぎる（通説）。

プロに詰められてクリンチ距離でフックを連打されるのは、威力の問題ではなく距離と足の問題として扱う。リーチの長いあなたが相手の射程に入られた時点で、長い腕の利点は消えている。直すのは、詰められる前にケージを切らせない足と、入られた瞬間に組んで止める手。

#### (d) ミドルキックの高さは自分の腰くらい、と教わった

高さは自分の体ではなく、相手の体で決める。標的は相手の一番下の肋骨（浮遊肋）と肝臓で、高さは相手の骨盤の上縁（ベルトが乗る骨）と、みぞおちの骨の間。相手が肘を下げていれば「相手の肘先の下、ベルトの上」。そこへ自分の左脛の真ん中3分の1を、真横から当てる。サウスポーの左ミドルは、オーソドックスの相手の右脇腹、つまり肝臓に入る。肋骨は正面からの衝撃に比較的強く、横からの衝撃に弱い（通説）。

数字（統計。AIST人体寸法データベース1991-92、青年男性の平均、身長171cm）: 大転子（腰の横の骨の出っ張り）は床から約88cm、骨盤の上縁は約101cm、腕を下げた肘先は約104cm、みぞおちの骨の下端は約123cm。一番下の肋骨と肝臓の下縁は、この骨盤の上縁とみぞおちの骨の間に入る。

「自分の腰」がずれる理由（推定。身長を185cmと仮定した例）。身長比から自分の大転子は約95cm、骨盤の上縁は約110cm。自分の大転子の高さで蹴ると、171cmの相手には大転子と骨盤の上縁の間、つまり骨盤と下腹に当たり、肋骨より下になる。骨盤の骨に脛が当たると蹴った側が痛い。自分のベルトの高さなら相手の肋骨の下部に入る。相手が自分より低いほど、自分の感覚では低く蹴ることになる。自分の身長と大転子の高さは未測なので、メジャーで一度測って例の数字を置き換える。

高すぎると相手の肘先に脛か足の甲が当たり、蹴った側が痛める（通説）。

#### (e) 大外刈りが効かない。脇を差してクラッチし、頭を顎に付けても相手が動かず、上体を振り回して手首を捻挫した

診断は5つ。順位を数えた資料はなく、複数の資料が「最大の失敗」と名指しする順に並べた（通説）。上から疑う。例は資料の書き方の右組み（自分の右脚で相手の右脚を刈る）。サウスポーの構えで前足側から掛けるなら左右を入れ替える。

1. 崩しがない。相手の体重が、刈られる脚のかかとに乗っていない。乗せる先は相手の右かかとの斜め後ろ（右後ろ隅）。乗っていない脚を刈ると空を刈り、相手は片足立ちで耐えるか、脚を跳び越えるか、大外返で返す。目安は、相手の頭が相手の軸足より外（後ろ隅側）に出ていること。ノーギでは、相手が反射で後ろへ一歩下がった着地の瞬間に、その脚のかかとへ体重が落ちる。その着地が崩しそのもので、体重が乗る前に刈るのが最も多い失敗。
2. 刈る方向と部位が違う。当てるのは自分の太ももの裏（またはふくらはぎ）で、相手の太ももの裏、膝のすぐ上。相手のふくらはぎに当たると小外刈になる。足首では、てこが短い。動きは大きな振り子で、前へ振ってから後ろへ振り抜く。鋭く蹴らない。相手が倒れ始めても止めず刈り切る。
3. 頭と胸で押していない。自分の胸を相手の胸に付け、腰は相手よりやや低く、刈りと同時に上体を前へ、やや下へ押し続ける。押しを緩めた瞬間に相手は跳んで戻る。ノーギで資料が書くのは「自分の頭を相手の頭の横に付ける」。「自分の頭を相手の顎に付ける」形は資料で確認できなかった（未確定）。どちらが道場の指示かは確かめる。
4. 軸足が遠い。手を伸ばして届かせている時点で位置を失っている。軸足（左）を相手の右足のすぐ横まで踏み込む。軸脚の膝は曲げたまま。軸脚は振り子の支点で、近いほど弧が大きい。
5. 上体を左右に振るだけ。投げは幾何で効き、筋力の抵抗には効かない。左右に振る力は後ろ隅への崩しではなく、相手の体重は両足に割れて残る（資料の原則からの読み替え。不確か）。

あなたの例は1と5。脇を差したクラッチと頭の圧は、相手の上体を起こして体重をかかとへ移す道具にはなる。ただ真後ろへ均等に押すだけでは体重は両かかとに割れ、そこで上体を振り回したのは、崩しの代わりに力を出したということ。直し方は3つ。押す向きを斜め（刈る側の後ろ隅）に変える。相手が一歩下がった着地のかかとに刈りを合わせる。それでも動かなければ刈るのをやめて、下の切り替えへ行く。

手首を捻挫した理由。脇を差してクラッチした手は、握ったまま手首が固定される。その状態で相手の上体を左右に振ると、手首に「握ったまま回す、かつ小指側へ倒す」力が掛かる。手首の小指側にあるTFCC（三角線維軟骨複合体。靭帯と軟骨の複合体）は、捻りが加わり、小指側へ傾いた状態で圧縮されたときに損傷する。症状は小指側の痛みで、手首を小指側へ傾けると痛む。治ったと思ったら同じ場所がまた痛む経過が特徴（医療機関の解説。通説）。あなたの捻挫がこれだったかは確認できない。1週間で治ったなら軽度だった、ということだけ言える。起きていたのは、相手が動かなかった分の力が固定された手首に回ったということで、直すのは手首ではなく崩し（上の1と5）。

重い相手への切り替え。刈って動かない相手を刈り続けない。

- 小外掛へ。当てる場所を太ももの裏から相手のかかとの後ろ（足首からアキレス腱）へ下げ、刈らずに掛けて、両手で相手を真後ろへ倒す。前へ投げられるのを嫌って体重を後ろに乗せている相手に効く。足を掛けたまま自分の体重を掛けていく倒し方もある（空道の解説。通説）。
- ボディロックへ。組み手をオーバーアンダー（刈る側に脇を差し、反対側は上から腕を抱える）からもろ差しに変え、相手の腰を自分のへそへ引き付けて、アウトサイドトリップにする。大外刈からボディロックへの連絡を書いた資料は見つからなかった（未確定。本書の判断）。
- 大外刈が空振りしたときの受け皿として資料が挙げるのは、谷落、シングルレッグ、大内刈（通説）。

#### (f) 受け身で、まだ背中がドンと落ちる

原因は4つで、資料が一致する（通説）。

1. 叩くのが早すぎる。初心者は有段者より手で畳を叩くタイミングが早く、背中が着く瞬間には腕の仕事が終わっている。衝撃が大きくなり、頭も打ちやすくなる。
2. 叩かずに押している。釣込腰を受ける受け身を加速度計で測った研究（被験者は各1名。査読）では、受け身は約0.3秒で終わる。優秀な被験者は腕で畳を二度叩いていて、首の最大角速度は530度/秒。劣る被験者は腕で畳を「押して」いて、首の角速度は1,260度/秒に達した。本人の感覚と実際の動き（接地の順序、腕の角度、完了の時刻）は大きくずれていた。感覚で直さず、撮って見る。
3. 背中を一度に着けている。背中を丸めず板のまま落ちると、衝撃が背中一枚に乗る。悪い着地では肺に衝撃が伝わり、一瞬息ができなくなる。左右の肩が揃わず、衝撃が片方に集中するのも初心者の癖。
4. 怖くて体に力が入っている。恐怖で全身を固めると、かえって危険な動きになる。

直し方。

- 叩くのは、帯（腰）が畳に着く瞬間。それより前に手を出さない。
- 顎は、投げられた瞬間より先に引いておく。自分の帯の結び目（へそ）を最後まで見る。
- 背中を丸め、尻 → 腰 → 背中の順に着く。両肩を同時に着ける。
- 両腕は体側から30〜40度に開き、肘を伸ばして手のひらで叩く。狭いと自分の腕の上に落ち、広いと背中全体で落ちる。
- 脚は伸ばす。曲げると膝が顔に当たる。
- 筋肉は手が畳に当たる瞬間だけ硬くし、叩いた瞬間に首を緊張させて頭を上げる。
- しゃがんだ段階では、かかとと尻を付けたまま後ろへ転がる。離れると尻を強く打ち、頭まで打つ。

段階（順序は資料で一致。確実）。

1. 仰向けで叩く（5回ずつ）。
2. 長座（脚を伸ばして座る）から後ろへ転がる。
3. そんきょ（かかとと尻を付けてしゃがむ）から。
4. 中腰から。
5. 立位から。
6. 移動しながら。
7. 相手に、自分の片足を支点に横へゆっくり転がすように倒してもらう。倒す側は引き手を最後まで離さない。
8. 技で投げられる。全柔連の初心者基準では、乱取りと高い位置からの投げ込みは少なくとも3か月は行わず、大外刈の高い位置からの投げ込みは5か月以降。

各段階の判定は「顎を引き、頭が振れない受け身ができているか」の一点で、できてから1段上げる。背中がドンと落ちるなら、1段下げる。

側転ができたこと。側転は空間の中で自分の体の位置を知る能力を作り、柔術ではオモプラッタからの脱出やパスに使われる（1資料）。側転が受け身の上達に移ることを書いた資料は見つからなかった（未確定）。

#### (g) 学校でよく見る、同じ向きのサイドヘッドロックを素人にやられても抜けたい

聞いた形の名前。「相手の脚の後ろへ自分の脚を通し、腰を抱えて、軽ければ持ち上げ、重ければ後ろへ倒す」は、柔道では首投げ・釣腰に対する正式な返し技の後腰（相手の腰を抱えて自分の腹と腰で持ち上げ、前へ落とす）に当たる。持ち上げて後方へ投げ捨てる形は裏投。柔術の護身の指導ではリアボディロックのブロック仕上げ（後ろから腰を抱え、脚で相手の脚を止めて倒す）、レスリング系では「持ち上げて回して落とす」と「膝裏を掴んで後ろへ座る」の2本立て。技名の対応は確実、手順は指導資料による（通説）。

手順。例: 自分の頭が相手の右脇の下にあり、相手の右腕が自分の頭に巻き付き、相手の左手が相手自身の右手首を握っている。近い手・近い脚は自分の右。

1. 自分の顎を胸へ引く。自分の顔を相手の腹に向け、自分の頭（耳の上）を相手の右の腰骨に押し付ける。頭と相手の体の間に隙間を作らない。
2. 自分の両膝を曲げて腰を落とし、自分の重心を相手より低くする。足幅は肩幅より広く。
3. 自分の右手で相手の腰の後ろ（ベルトの位置）を抱える。自分の左手は、相手の右膝の裏をC字（親指と4本の指で挟む）で掴むか、相手の腰の前で右手と組む。
4. 自分の右脚を相手の両脚の後ろ側へ踏み込み、自分の右ふくらはぎから膝裏を相手の右膝裏に当てる。
5. 相手が軽い場合: 腕で持ち上げない。膝を伸ばし、腰を前へ突き出して、腹と腰で相手を浮かせる。浮いた相手を、自分の頭がある側（相手の右側）へ回して落とす。
6. 相手が重い場合: 持ち上げない。自分の左足で相手の左かかとを止め、腰を後ろへ引きながら座り込む。相手は膝裏を自分の右脚に遮られて後ろへ倒れる。
7. 着地は自分の尻から、上体を先に落とす。頭は最後まで相手の腰に付けたまま。倒れた後、自分の左前腕を相手の首に当てて枠を作り、上から体重を乗せて相手の腕を剥がす。

持ち上げない理由は3つ。腕で持ち上げると、頭が相手の脇に固定されたまま自分の体だけが動き、その差が全部首の曲げになる。持ち上げている間、相手はまだ頭を抱えている。重い相手は上がらず、上がらないまま粘ると相手に引き倒される。だから軽い相手でも腕ではなく腹と腰で浮かせ、重い相手は最初から座って倒す。

首の負荷を減らす要点（指導上の要点で、頸椎の荷重を測った資料はない。通説）。

- 顎を引く。引き倒されたときに首が伸展側（顎が上がる向き）へ行くのを防ぐ。伸展の靭帯損傷の閾値（56.9 Nm）は屈曲（88.1〜190 Nm）より低い（査読）。
- 頭を相手の腰に押し付け、顔を相手の腹へ向ける。頭が相手から離れるほど、てこの腕が長くなって首の曲げが大きくなる。相手から離れる方向へ回ると首の圧が増え、相手の側へ回ると減る。
- 上体を相手より先に落とす。相手が先に落ちると、自分の首が相手の腕に引かれてから体が着く。
- 後ろへまっすぐ引かない。締まる。腕力で頭を引き抜かない。
- 相手が上体を振り回したら、離れる方向へ踏ん張らない。頭を相手の腰に付けたまま相手と同じ方向へ足を運び、振りが止まった瞬間に手順3へ入る。
- 首の痛みに、片側の腕へ走る灼熱痛、しびれ、脱力が伴ったら、その場で止める（スティンガー。(h)）。

練習では、掛ける側に「振らない、引き倒さない」を約束してから始め、抜ける形が3回続けてできたら振りを足す。

ほかの抜け方は2つ。腰を落として後ろへ回る（自分の近い手で相手の上腕二頭筋の内側を押さえ、腰を肩の真下に入れて姿勢を立て、頭を相手の背中側へ抜き、相手の手首を両手で取って背後へ回る）。相手の腕を剥がす（相手の手首か肘を押さえ、姿勢を立てながら腕を下へ押し、角度を変えて緩める）。護身の資料にある股間への打撃は、MMAでは反則。

ルール。ヘッドロック自体はどのルールでも合法。統一ルールにはネッククランクを禁じる項目もない。IBJJFは絞めを伴わない脊椎ロックが反則。寝技で同じ形（袈裟固型）に入られたときは別の手順になる。MMAでの扱いは、抜ける側の手順が【そのまま】。

読み方は3つ。

1. 一撃で折れるのは、頭から落ちる圧縮だけ。1.7 kN以上が数ミリ秒で掛かり、反射で首の筋肉が縮む（約60 ms後）より先に終わる。原著は「重篤な頸部損傷の可能性は首の筋力とは無関係に存在する」と書く。0.5 mの落下（衝突速度3.1 m/s）から頸椎損傷が起こる（査読）。
2. 曲げとひねりは、生きた人間では順番に来る。屈曲なら、痛み（59.4 Nm）→ 数日残る痛み（88.1 Nm）→ 構造の破壊で、破壊は88.1 Nmのさらに先。「グキッといって数日痛い」は88.1 Nmの被験者が経験したことに当たり、後遺症は残らなかった。回旋の114°は生きた首が回る範囲を大きく超えるので、純粋なひねりなら壊れる前に痛みで動きが止まる（通説）。伸展は屈曲より弱い。顎を引くのはこのため。
3. 屍体の分節値（17〜43 Nm）は筋肉が全く働かないときの値。失神中と、不意を突かれた瞬間はこちらに近づく。屍体の提供者は平均50歳代が多く、若い骨は20〜30%強い。

ヘッドロックで何Nmが掛かるかを測った資料はない（確認できず）。表は「どの向きが、どの順で壊れるか」を読むためのもの。

現実の受傷。

- 捻挫（筋と靭帯）: 上の88.1 Nmの「数日痛い」に当たる。高校スポーツの頸椎の損傷は筋損傷が63.1%、神経損傷が20.5%で、この2つで8割を超える（査読）。
- スティンガー（バーナー）: 片側の腕に灼熱痛、しびれ、脱力が走る。首から腕へ行く神経（腕神経叢の上の幹か、第5・6頸神経の根）の損傷。機序は3つ。牽引（首を反対側へ側屈させられながら、同じ側の肩を押し下げられる）、圧迫（首を同じ側へ側屈させられながら、斜め後ろへ反らされる）、直接打撃（鎖骨の上のくぼみか首の外側の下部）。80%は1日以内に戻り、6%は2週間以上かかる。大学レスリングで1,000出場あたり0.14（査読）。サイドヘッドロックで頭を脇へ引き込まれる動きは、牽引型と圧迫型の両方の条件を作りうる。ただしヘッドロックでの発生率の資料はない（未確定）。
- 頭から落ちる圧縮: 骨折と脊髄損傷の典型。柔道の重傷頸部外傷64例では、投げた側の典型が「内股で頭から畳に突っ込む」過屈曲、投げられた側の典型が「低い背負投で顔面から突っ込む」過伸展だった。米国レスリングの重大事故の74%は、タックルを受ける側の防御姿勢で起きている（統計）。

ヘッドロックで頸椎が壊れた報告は見つかっていない。医学文献の検索で、ヘッドロックを機序とする頸椎骨折、脊髄損傷、頸動脈や椎骨動脈の解離の症例報告は出てこなかった。見つかったヘッドロック由来の外傷は、16歳男性の眼窩（目が入る骨のくぼみ）の内側の壁の骨折1件だけ（査読）。報告がないことは、起きないことの証明ではない（未確定）。

ヘッドロックがネッククランクに変わる線。ヘッドロックは頭蓋と顔を挟んで固定する技で、首は相手の体が動いた分だけ曲がる。相手が自分の頭を相手の胸へ巻き込んで首を曲げ始めたら、力学上はクランクで、屈曲の痛み（59.4 Nm）→ 数日残る痛み（88.1 Nm）の順で来る。そこでタップする。

#### (i) マットに飛び込める能力（後転倒立から歩く等）と、首の筋肉と、勇気が欲しい

マットへ頭から飛び込む動きは、受け身と後転の上に乗る。順序の原則は、易→難、低→高、遅→速、弱→強、その場→移動、単独→相対（全柔連）。

1. 単独の後ろ受け身: 仰向け → 長座 → そんきょ → 中腰 → 立位 → 移動。判定は「顎を引き、頭が振れない」。
2. 横受け身: 仰向け → 長座 → そんきょ → 立位。左右とも。脚を交差させない。
3. 前回り受け身: 肩から回る → 片膝つき → 立位。自分の肩から反対側の腰へ、背中の対角線を通す。頭を越えて回らない（前転になるのが典型の崩れ）。
4. 二人組で、片足を支点に横へゆっくり転がされる受け身。倒す側は引き手を離さない。
5. 後転（座位 → 立位）、肩倒立、体操のブリッジ（支えるのは首ではなく両手）。
6. 後転倒立。後転と、壁倒立10〜20秒の両方ができてから。
7. 後ろへ倒される技で投げられる練習。全柔連の初心者基準では、低い位置からが3か月以降、高い位置からが5か月以降。
8. 首の等尺性は1〜7と並行。

後転の要点（体操教室の資料。通説）。両手をパーにして手のひらを天井へ向け、耳の横に構える。目はへそを見る。尻 → 腰 → 背中 → 首の順に着き、頭が床に着く前に両手のひらで床を押して、足裏で着地する。足が天井へ向いたまま回れないと、首と頭に体重が乗る。後転倒立は、しゃがんで後ろへ転がり、両手が床に着いた瞬間に「両手で床を押す」と「両足を天井へ蹴り上げる」を同時に一気に行う。段階は、だるま（転がって足を上げる感覚だけ）→ 補助つき → 一人で。倒立から歩くのは、壁倒立と倒立歩行の段階の先に置く。

首の筋肉。首が守れるのは「予期した衝撃で頭が揺れにくくなる」ことで、頭から落ちる圧縮は守れない（(h) の読み方1）。初心者の大外刈の受け身では、首の屈曲筋力と首の角運動量の間に線形の関係がなかった（査読）。だから首は鍛えるが、飛び込みの許可証にはならない。2か月目で頸椎に荷重が集中しない方法は等尺性で、自分の手で頭を押す15秒の最大等尺性を前後左右、週3回、8週で、U18ラグビー選手28人の筋力が対照群より上がった（査読）。ネックブリッジは首を伸展の端に置いて頭に体重を乗せる動きで、荷重の実測がないまま行う根拠がない（未確定）。

勇気。怖くて体に力を入れると、受け身はかえって危険な動きになる（(f) の原因4）。恐怖を減らすために低い位置から始める、というのが受け身の段階の理由そのもの（通説）。飛び込む高さは、1段下の高さで「顎を引き、頭が振れない」ができたときだけ上げる。

長身の代償。落下高が高いほど頭の衝突速度が上がる。立位の頭の高さから頭が先に着く落ち方は、それだけで頸椎が壊れる速度域（0.5 mの落下から）に入る。身長別の受傷率の資料はない（対応づけ。未確定）。飛び込みでは頭ではなく、両手と肩から着く。

#### (j) 元柔道のMMA選手との柔軟で叫んだが柔らかくなった。股関節をもっと柔らかくしたい

痛みまで伸ばす必要はない、という研究が多い。

- 座りがちな若年成人21人のRCT（ハムストリング、60秒×3回、週3回、4週）では、張りと不快感の10段階で1〜2の低強度と9〜10の高強度を比べ、可動域の増加に有意差がなかった。低強度で12.8〜14.2度、高強度で16.6〜16.7度増えた（査読）。
- 189研究・6,654人のメタ分析でも、強度（低・中・高）で効果に差がなかった。先行研究をまとめて「不快感や痛みの点を越えて伸ばす必要はない」と書く（査読）。
- 続けて増えるのは主に「耐えられる伸張の限界」で、筋束の長さは変わらない（65研究のメタ分析。査読）。叫んだ日に柔らかくなったのは、この耐性の変化として説明できる（本書の読み替え）。

反対の結論のレビューもある。18研究の系統的レビューでは、全研究で可動域は増え、8研究では高強度のほうが増加が大きかった。結論は「不快・痛みを越える高強度は、可動域をより増やすかもしれない。追加研究が必要」で、高強度では筋力の低下が大きい可能性もある（4研究中2研究。査読）。強度の問題はまだ決着していない。言えるのは、痛みまで追い込む必要があるという証拠は弱い、ということまで。

用量（査読）。

- 頭打ちになる量は、1筋群あたり1回4分（1回きり）、週10分（続けるとき）。それ以上は上積みがない。
- 効果は強度、年齢、性別、週の回数、期間に左右されない。もともと硬い人ほど伸びる。
- 国際専門家20人の合意は、長期に柔軟性を上げるなら静的かPNFを優先し、1筋につき30〜120秒を2〜3セット、毎日。
- PNF（伸ばした筋を一度収縮させてから緩め、さらに伸ばす形）は、収縮が最大努力の20%以下・約3秒で足り、週1〜2回で効果が続く。静的との優劣は確定していない。
- あなたの処方: 1筋群につき60秒×3を週3回（週9分）。内転筋、ハムストリング、股関節屈筋、殿筋と外旋筋の4つ。張りを感じてから不快感の手前で止める。4週で角度が変わる。

パートナーが乗る形の条件。パートナー補助のPNF、ストラップで一人で行うPNF、静的の3つを比べた研究（13人）では、可動域の増加（2.6〜5.4%）に差がなく、全条件で四肢の動作速度が9.2%落ちた（査読）。だから大事な練習と試合の直前にはやらない。パートナーが乗る方が自分で伸ばすより効く、という根拠は見つからなかった（未確定）。何が壊れるかも分かっている。開脚でハムストリングの付け根（坐骨）が高度に断裂した症例報告があり、近位ハムストリングの断裂は、膝を伸ばしたまま股関節を急に深く曲げる動き（ハイキック、開脚、スライディング）で起きる。相撲の股割りも、完成まで数年が一般的で、経験のない者が無理に行うと靭帯損傷を招くとされる（通説）。乗ってもらうなら条件は3つ。

1. 乗る側は、自分の両手で伸ばされる側の骨盤か背中を押し、体重を2〜3秒かけて少しずつ預ける。一気に乗らない。急な深い屈曲が断裂の機序だから。
2. 伸ばされる側が「止めて」と言ったら、その位置で保持する。それ以上は押さない。
3. 骨盤を立ててから倒す。骨盤が後ろへ倒れたまま前屈すると、腰椎に負荷が集中する。

あなたがやった4種の一般名は、開脚前屈（パンケーキ）、開脚の側屈（股割りの横倒し）、90/90ストレッチ（対応は推定）、4つ目（開脚で伏せてパートナーが上に乗る形）は研究上の名称が確認できなかった。ハムストリングを目的にするなら、8週で最も伸びたのは受動的な直脚挙上（仰向けで膝を伸ばしたまま、ストラップかパートナーの手で脚を体の方へ引く）だった（100人のRCT。査読）。

#### (k) 四つ組みから、自分の手を相手の顎の下から回して掴み、大外刈りしつつしゃがんで背負い投げのように投げる技の名前

首投げ系。名前の対応は「首投げ（相撲・レスリング・プロレスの通称）＝ヘッドロックスロー（レスリング）＝head and arm throw（英語圏）＝柔道の分類では腰車（腰を使う場合）」でほぼ確実。腰車は柔道の腰技の1つで、どちらかの腕で相手の首を抱え、相手を腰に乗せて投げる。大腰との差は腕の位置で、大腰は相手の腰に、腰車は相手の首に回す。相撲では、首を抱えた深い腰車が腰投げ、浅いものが首投げと言われる。

あなたの記述との対応。「顎の下から腕を回す」が首を抱える動作、「しゃがむ」が膝を曲げて自分の重心を相手より下へぶつける動作、「背負い投げのように」が相手を自分の腰か背中に乗せて前へ落とす動作。「大外刈りしつつ」脚も使う混合形の名前は確認できなかった（未確定）。首投げ払腰という題名の動画はあるが、中身は確かめていない。

MMAでの扱い。

- 首だけを抱える型: 【捨てる】。代償が大きすぎる。相手に背中を向けなければならず、失敗すると相手はそのまま背中を取り、リアネイキッドチョークになる（複数の資料が一致。通説）。レスリングでもエリートレベルではほぼ廃れた、とされる。
- 腕ごと抱える型（ヘッドアンドアーム投げ）: 【待つ】。相手が腕を上げて自分の首を取りに来たとき、フックを打って腕が上がったまま頭の横にあるとき、相手がパンチで突っ込んできた組み際に使う。相手の腕が抱えの中にあると、相手はその腕で自分の腰を抱えて背中へ回れない。女子MMAではほぼ毎試合出るという記述がある（掲示板。通説）。
- ノーギの利点: 服を掴まなくてよい。首と腕は素手でもグローブでも抱えられる。

失敗の形。背中を向けたまま止まると、相手に腰を抱えられて後ろへ倒される（これは (g) の後腰と同じ形で、今度は自分が掛けられる側）。頭を下げて入るとギロチンに拾われる（一般論からの読み替え。不確か）。

#### (l) ギロチンを取られたときの後転

「ギロチンを掛けられた側が後転で抜ける」技を、その名で説明した資料は見つからなかった（確認できず）。転がる抜け方は、資料では3つの別の状況に分かれる。どれを教わったかは次の練習で確かめる。見分ける目印は、自分が相手のガードの中にいるか、自分が上で相手が肘を高く上げた握り（ハイエルボー）を取っているか、立っているか。

- A. 相手のガードの中で、絞め腕の側へ転がって上を取る（1資料）。相手の脚が開いていれば転がらず、絞め腕と反対側へ相手の脚を跳び越して抜ける。相手が脚で自分を制しているときは、相手の絞め腕の手首を握り、絞め腕の側（自分の頭がある側）へ素早く転がる。転がれる向きはこちらだけで、反対へ転がると輪が締まる。1回目の転がりで自分が下、相手がマウントに近い形で上に乗る。2回目に転がり、相手が横に落ちたらエビを繰り返して相手の脚を越え、サイドへ出る。前腕で相手の首に枠を作って姿勢を起こすと、相手は絞めを離すしかない。
- B. 自分が上（相手の横）にいて、ハイエルボー・ギロチンを取られたとき、前転してブリッジになる（1資料の要約。未確定）。前転して両足のつま先立ちで止まると、その姿勢が実質ブリッジになり、首の周りに大きな空間ができる。そこで体を回して上に戻る。出典は「最後の手段」と位置づけ、転がる向きは要約に明記がない。
- C. 立ちギロチン。立ちの資料はどれも転がる抜け方を載せていない。抜け方は3つ。ホップ（絞め腕と反対側の自分の腕を相手の肩の上へ越し、両脚を相手の遠い側へ跳んで移す）。テイクダウン（姿勢を立てたまま片手で絞め腕を押さえ、角度を変えてシングルレッグかボディロックへ）。両手で相手の腰を押して脚を後ろへ下げ、相手の腕が伸びたら絞め腕の側へ踏み込んで頭を抜き、腰を取ってバックへ回る。

共通の原則。顎を引く。顔を相手の胸へ向ける。頭を真後ろへ引かない（首が伸びて絞めが締まる）。体重を前へ掛ける。

首に掛かる向き。ギロチンは首に、前屈（顎を胸へ）、絞め腕側への側屈、軸方向の圧縮（ハイエルボー系で強い）を同時に掛ける（通説）。力の数値を示した資料も、転がる動作固有の首の負荷を測った資料もない（確認できず）。3つとも絞めが掛かったまま動く技なので、練習は抵抗なしで形を覚えてから、相手の絞めの強さを段階的に上げる。

#### (m) 10秒ずつ種目を変える高強度インターバル（ジャンプ、もも上げ、ジャンプスクワット、足踏み、片脚ジャンプスクワット、合図でバーピー、腕立て）

位置づけ。この「10秒ごとに種目を変えて休まない」形式そのものを検証した研究は見つからなかった（未確定）。比べられる研究は2つ。

- タバタの原著（自転車）: 最大酸素摂取量の約170%で20秒全力、10秒休息を7〜8セット、週5日、6週。最大酸素摂取量が7 mL/kg/分、無酸素性容量が28%上がった（査読）。
- 自重のタバタ（腕立て、スプリットスクワット、ボックスジャンプ、バーピー、縄跳び、ジャンピングジャックで20秒／10秒×8を4ラウンド）: 16人の平均で最大酸素摂取量の74%、最大心拍の86%、血中乳酸12.1 mmol/L（査読）。

道場の形式は休息がないぶん、1本あたりの強度はタバタの20秒全力より下がり、自重タバタに近い連続サーキットになる。

格闘技での効果（査読）。オリンピック系格闘技のHIITのメタ分析（20研究）では、最大酸素摂取量の効果量1.007、ピークパワー0.528、平均パワー0.871。介入は4〜12週、週平均2.68回（2〜4回）。武道系のRCTのメタ分析（14件・348人）でも、週2〜3回が主流だった。

週の上限。自重タバタの著者は週2〜3回、間に48〜72時間の回復を推奨している（査読）。商業サイトの目安は週2〜3回、最大心拍の90%を超える時間は週20〜30分（未確定）。道場のスパーと局面限定スパーはそれ自体が高強度のインターバルなので、道場でこの形式をやった日は1回に数え、全部で週2〜3回を超えない。効くまでの期間は4週以上。3セット目で潰れる原因が燃料なら、この形式では直らない。
