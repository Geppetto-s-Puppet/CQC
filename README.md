# 徒手格闘

ヒールフックとチョークのあるMMA系ルールで勝つための教科書。
読者は一人。サウスポーで、長身、腕と脚が長い。

---

## いま開いたなら

**[8_あなた](8_あなた.md) の「今週」** を読む。あなたの体と現在地に合わせて、今週やることを書いてある。

優先順位はこれ。

```
1  テイクダウン防御と、倒されたら3秒以内に立つ     → スタイル全体の前提
2  エビのドリルを毎日10分                         → 下から逃げる動きの土台
3  スパーの毎ラウンド、ボディを1回は打つ            → オーソ相手なら左が肝臓に入る
4  練習の3時間前に食べる。2,400kcalを割らない       → 3セット目で燃料が切れない
5  マウスピースとカップを揃え、出る大会を決める      → 使える技と必須の防具が決まる
```

## 約束

- 左右はサウスポー基準。前手・前足はあなたの右、後ろ手・後ろ足は左。
- 数字を出した箇所は [9_出典](9_出典.md) に元がある。
- 根拠の強さは4段階で書き分ける。査読、統計、通説、未確定。現場の技術の大半は通説で、それ自体は問題ない。通説を査読のように書かないのが約束。
- 安全と医学の話は [1_原理](1_原理.md) の「壊れ方」にだけ置いた。他の章では繰り返さない。
- 参照は「ファイル名の「見出し」」の形で書いた。見出しの名前で探せば見つかる。
