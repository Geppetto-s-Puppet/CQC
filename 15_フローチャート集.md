# 15. フローチャート集 — 迷ったら、ここを辿る

> **使い方**: 実戦中にこれを思い出す必要はない。
> **練習前に1つ選んで、その日はそのフローだけを回す。** 3ヶ月で身体に入る。
>
> **★印** = 迷ったときのデフォルト（何も考えられない時はこれをやる）

---

## 1. 最上位フロー — 格闘中、脳が回すべき順序

```
                        【いま、どこにいる?】
                                │
        ┌───────────────┼───────────────┐
        │               │               │
    離れている       組んでいる        寝ている
        │               │               │
        ▼               ▼               ▼
     §2 立ち技      §3 クリンチ    §5(上) / §6(下)
        │               │               │
        └───────────────┴───────────────┘
                                │
                     【常に並行して確認する3つ】
                                │
        ┌───────────────┼───────────────┐
        ▼               ▼               ▼
   呼吸してるか?   顎は引けてるか?   脚は安全か?
        │               │               │
   NO → 止まって    NO → 引く      NO → §7へ即座に
        呼吸を作る                    (ニーライン確認)
```

**この3つが崩れていると、上の技術は全部機能しない。**（[01章 5層モデル](01_原理.md)）

        │                   │                   │

        │                   │                   │
        ▼                   ▼                   ▼
   ★前に出るか        ★★長居しない！      どっちが有利?
   角度を作る          → 入るか出るか
        │              2択のみ                  │
        │                   │            ┌──────┴──────┐
        ▼                   ▼            │             │
   ジャブ/ティープで   ┌────┴────┐    自分が有利    相手が有利
   距離を測る         │         │        │             │
                    入る      出る       ▼             ▼
                     │         │    肘・膝・組み   ★離れる or
                     ▼         ▼                    アンダーフック

```

      両方取れた          片方ずつ            両方取られた

   or 壁へ押す         取りに行く              + 逃げるか、
        │                   │                   ウィザー1本
        ▼                   ▼
   テイクダウン         ペンメルで
   → §4へ              1本取りに行く

     → 手を内側から上げて外す + 腰を引く
     → または「タックルに入る」(首相撲は下がガラ空き)
```

## 11. 「上達しない」ときの診断フロー

```
        【何が起きているか?】
                │
    ┌───────────┼───────────┬───────────┐
  技が入らない  スタミナ切れ  怪我が続く   スパーで
    │            │            │        何もできない
    ▼            ▼            ▼            │
【位置は取れて  【力んでいる  【タップ基準  ┌──┴──┐
 いるか?】       か?】        は?】     考えすぎ  やられ放題
    │            │            │        │        │
 ┌──┴──┐        ▼            ▼        ▼        ▼
NO      YES   ★呼吸と      ★遅い    ★選択肢を  ★Phaseを
 │       │     フレームを   → Phase0  2つに減らす 1つ戻す
 ▼       ▼     再構築       に戻る    ([13章§8](13_標的と損傷の医学.md))
Phase2  セット                                  Phase1の
に戻る  アップが      ★相手選定も              防御を
(位置)  無い          技術の一部                完成させる
        → 反応を
          作る練習
```

**★最頻出の誤診**: 「技が足りない」と思って技を増やす。
実際の原因は9割**位置**。技を増やすと[13章 §8](13_標的と損傷の医学.md)の通り選択肢が増えて更に遅くなる。

## 12. 1枚まとめ（印刷用）

```
╔══════════════════════════════════════════════════════════╗
║  迷ったときのデフォルト行動                                ║
╠══════════════════════════════════════════════════════════╣
║  距離が分からない        → 横に動く（真後ろに下がらない）  ║
║  クリンチで劣勢          → アンダーフックを1本取る         ║
║  倒された直後            → 立つ                            ║
║  ガードの中（下）        → 立つ                            ║
║  ガードの中（上）        → 腰を落として姿勢を立てる        ║
║  スクランブル            → 相手の腰を追う／背を向けない    ║
║  位置が不明なグラウンド  → 一旦立つ                        ║
║  足関節が不明            → 踵を隠す＋止まる                ║
║  息が上がった            → クリンチする（打ち合わない）    ║
║  相手が読めない          → 前に出て先に動かせる            ║
╠══════════════════════════════════════════════════════════╣
║  常時確認する3つ                                          ║
║   1. 呼吸しているか                                       ║
║   2. 顎は引けているか                                     ║
║   3. 脚は安全か（ニーライン）                             ║
╠══════════════════════════════════════════════════════════╣
║  即タップする条件（痛みを待たない）                        ║
║   ・ヒールフックの形が完成した                            ║
║   ・RNCの腕が完全に組まれた                               ║
║   ・関節が可動域の端に達した                              ║
╠══════════════════════════════════════════════════════════╣
║  即座に練習を止める条件                                    ║
║   ・頭部の症状が1つでもある                               ║
║   ・関節から「ポップ」音がした                            ║
║   ・首の痛み＋手足のしびれ                                ║
╚══════════════════════════════════════════════════════════╝
```
